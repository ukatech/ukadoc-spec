# activeghostlist(ghost name/main character name/path).general property name

**カテゴリ:** Property system

Retrieves information using the ghost name (name), main character name (sakuraname), or path of a running ghost.<br />
\[SSP 2.9.35\] The ghost's [UUID](general-property/uuid.md) can also be specified. It is matched when there is no match for the ID, path, or name. If multiple ghosts with the same UUID are running, the first one in the list is used.

**対応:** SSP
