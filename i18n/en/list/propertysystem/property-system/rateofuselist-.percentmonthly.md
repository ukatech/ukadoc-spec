# rateofuselist(name).percentmonthly

**カテゴリ:** Property system

The proportion of running time for the ghost, as a decimal percentage, aggregated over the 30 days up to today for the monthly report.<br />
\[SSP 2.9.35\] The ghost's [UUID](general-property/uuid.md) can also be specified in parentheses instead of its name. If multiple ghosts have the same UUID, the one with a record is used.

**対応:** SSP 2.8.54
