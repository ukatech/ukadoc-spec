# currentghost.sound(element name).sound property name

**カテゴリ:** Property system

Gets information from the newest media item managed by the current ghost whose element name matches.<br />
The element name is the file name, path, or URL specified in commands such as `\![sound,play,～]`.<br />
Note that the parentheses follow directly without a dot (`currentghost.sound(～)`, not `currentghost.sound.(～)`).<br />
The sound property name is [described below](sound-property/sound.name.md). For writable properties and related notes, see [here](sound-property/sound.pause.note.md).

**対応:** SSP 2.8.72
