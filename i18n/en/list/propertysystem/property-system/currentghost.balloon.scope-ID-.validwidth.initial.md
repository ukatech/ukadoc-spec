# currentghost.balloon.scope(ID).validwidth.initial

**カテゴリ:** Property system

Width available for drawing text in the current balloon (taking basepos.x, the text starting point, into account).<br />
For [vertical writing](../../../descript/balloon/descript-txt/vertical.md), this is the width available in the direction the columns are arranged, taking the starting position of the first column (basepos) into account.

**対応:** SSP (2.3.72)
