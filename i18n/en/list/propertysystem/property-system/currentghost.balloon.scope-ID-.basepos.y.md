# currentghost.balloon.scope(ID).basepos.y

**カテゴリ:** Property system

Starting point for drawing text in the current balloon (Y coordinate). This is not necessarily the top edge of the drawing area. Coordinates are relative to the top-left corner of the balloon image.<br />
For [vertical writing](../../../descript/balloon/descript-txt/vertical.md), this indicates the starting position for character advance (the top edge of the first character, = [origin.y](../../../descript/balloon/descript-txt/origin.y.md)).

**対応:** SSP (2.3.72)
