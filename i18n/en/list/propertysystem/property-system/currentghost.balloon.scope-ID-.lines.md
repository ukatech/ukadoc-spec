# currentghost.balloon.scope(ID).lines

**カテゴリ:** Property system

Maximum number of lines that fit in the current balloon. Indicates the entire drawing area, regardless of basepos. Matches the number of displayed lines after scrolling.<br />
For [vertical writing](../../../descript/balloon/descript-txt/vertical.md), read “lines” as “columns”; this is the maximum number of columns that fit.

**対応:** SSP
