# baseware.windowmode

**カテゴリ:** Property system

SSP's window mode state. One of normal (normal mode), shared (window mode, with one container shared by all ghosts), or perghost (window mode, with one container per ghost).<br />
When it is switched, [OnWindowModeChange](../../shiori-event/os-state/OnWindowModeChange.md) occurs.

**対応:** SSP 2.8.93
