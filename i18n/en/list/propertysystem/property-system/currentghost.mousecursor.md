# currentghost.mousecursor

**カテゴリ:** Property System

Cursor filename (fingertip) indicating an area of the ghost that can be interacted with.<br />
The following also applies to properties beginning with currentghost.mousecursor / currentghost.balloon.mousecursor:<br />
Relative paths are searched in the shell, then in the ghost folder.<br />
If SET to an empty string, the definition is treated as deleted, and the display reverts to what it was before the set.<br />
The cursor can be specified in the same way as in the [cursor section of surfaces.txt](../../../descript/shell-surfaces/cursor-brace/introduction_cursorbrace.md).<br />
*\[SET enabled\]*

**対応:** SSP \[2.6.11\]
