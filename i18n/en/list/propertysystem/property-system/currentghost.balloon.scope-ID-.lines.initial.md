# currentghost.balloon.scope(ID).lines.initial

**カテゴリ:** Property system

Maximum number of lines that fit in the current balloon. Takes basepos.y, the text starting point, into account. Matches the number of displayed lines before scrolling.<br />
For [vertical writing](../../../descript/balloon/descript-txt/vertical.md), read “lines” as “columns”; this is the maximum number of columns that fit.

**対応:** SSP (2.3.72)
