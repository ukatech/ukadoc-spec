# currentghost.sound.count

**カテゴリ:** Property system

The number of media items managed by the current ghost.<br />
This includes all items opened with `\![sound,play]`, `\![sound,loop]`, `\![sound,preload]`, and similar commands that have not yet been closed. Note that this is not limited to items currently playing.<br />
Use [playing](sound-property/sound.playing.md) to determine whether an individual media item is playing.

**対応:** SSP 2.8.72
