# currentghost.balloon.scope(ID).validheight.initial

**カテゴリ:** Property system

Height available for drawing text in the current balloon. Takes basepos.y, the text starting point, into account. Matches the drawing height before scrolling.<br />
For [vertical writing](../../../descript/balloon/descript-txt/vertical.md), this is the length of one column and takes the starting position for character advance (basepos) into account.

**対応:** SSP (2.3.72)
