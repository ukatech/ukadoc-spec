# uuid_base

**カテゴリ:** Property system \> General property names

The value of [uuid_base](../../../../descript/ghost/descript-txt/uuid_base.md) in the target's descript.txt. Returns the string as written.<br />
Because the value is read from descript.txt, it is available when the ghost and balloon lists are loaded (it is not loaded lazily).<br />
Retrieval fails if it is not specified in descript.txt.

**対応:** SSP 2.9.35
