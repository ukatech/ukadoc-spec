# char\*.bind.menu

**カテゴリ:** Property System \> General Property Names

(Valid only for currentghost) The visibility state of items in the dressup menu for the \*-numbered scope of the target shell.<br />
When set to hidden, hidden; in automatic enumeration mode, auto; otherwise, none<br />
*\[SET enabled\]*The initial value is [char\*.menu](../../../../descript/shell/descript-txt/char-star-.menu.md) in the shell's descript.txt.

**対応:** SSP
