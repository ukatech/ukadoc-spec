# kero.bind.menu

**カテゴリ:** Property System \> General Property Names

(Valid only for currentghost) The visibility state of items in the dressup menu for the target shell's counterpart-side scope.<br />
Set to hidden to hide items, auto for automatic enumeration mode, or none otherwise.<br />
*\[SET enabled\]* The default value is shell-side descript.txt's [kero\*.menu](../../../../descript/shell/descript-txt/kero.menu.md)

**対応:** SSP
