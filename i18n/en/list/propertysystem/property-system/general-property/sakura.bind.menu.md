# sakura.bind.menu

**カテゴリ:** Property System \> General Property Names

(Valid only for currentghost) The visibility state of items in the dressup menu for the target shell's main scope.<br />
Set to hidden to hide items, auto for automatic enumeration mode, or none otherwise.<br />
*\[SET enabled\]* The default value is shell-side descript.txt's [sakura.menu](../../../../descript/shell/descript-txt/sakura.menu.md)

**対応:** SSP
