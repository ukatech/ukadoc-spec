# system.network.(key)

**カテゴリ:** Property System

Network connection status. The following strings can be used for (key).

- **status**: Network connection status: online (connected) or offline (not connected).
- **ipaddress**: Local IP address.
- **type**: Connection type: one of bluetooth, cellular, ethernet, none, wifi, wimax, other, or unknown.
- **cost**: Connection cost category: one of unknown, unrestricted, fixed, or variable.
- **downlink**: Maximum downstream link speed (Mbps).
- **downlink.estimate**: Estimated downstream link speed (Mbps). A more conservative estimate calculated from actual measurements.

**対応:** SSP 2.8.17
