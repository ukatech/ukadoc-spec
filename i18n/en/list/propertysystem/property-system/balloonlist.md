# balloonlist(balloon name/path).general property name

**カテゴリ:** Property system

Retrieves information using the balloon's name or path.<br />
\[SSP 2.9.35\] The balloon's [UUID](general-property/uuid.md) can also be specified. It is matched when there is no match for the ID, path, or name. If multiple balloons have the same UUID, the first one in the list is used.

**対応:** SSP
