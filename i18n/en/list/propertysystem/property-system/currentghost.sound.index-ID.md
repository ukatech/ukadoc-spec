# currentghost.sound.index(ID).sound property name

**カテゴリ:** Property system

Gets information from the media item at the specified ID among those managed by the current ghost.<br />
IDs are assigned in order from newest to oldest, starting at 0. An out-of-range ID causes the retrieval to fail.<br />
The sound property name is [described below](sound-property/sound.name.md). For writable properties and related notes, see [here](sound-property/sound.pause.note.md).

**対応:** SSP 2.8.72
