# currentghost.balloon.scope(ID).background.color

**カテゴリ:** Property system

Gets the balloon's background color as R,G,B values.<br />
The “background color” is either the color used most frequently in the balloon (the representative color) or the average color of the entire balloon. Possible uses include controlling the text color to provide sufficient contrast with this color.<br />
For reference: as of SSP 2.7.81, the implementation uses the “representative color.”

**対応:** SSP 2.7.81
