# currentghost.balloon.scope(ID).validheight

**カテゴリ:** Property system

Height available for drawing text in the current balloon. Indicates the entire drawing area, regardless of basepos. Matches the drawing height after scrolling.<br />
For [vertical writing](../../../descript/balloon/descript-txt/vertical.md), this is the length of one column (the length of character advance that can be written in one column) and does not change when scrolling.

**対応:** SSP
