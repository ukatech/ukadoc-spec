# currentghost.scope(ID).y

**カテゴリ:** Property System

The Y coordinate on the screen of the reference point of the surface for the current ghost's scope ID.<br />
For multiple monitors, the position in the entire virtual desktop, with the top-left of the primary monitor as the origin.<br />
The reference point is usually the bottom center of the surface. It can be configured in the descript.txt of GHOST and SHELL using [sakura(kero、char\*).defaulty](../../../descript/shell/descript-txt/sakura.defaulty.md).

**対応:** SSP
