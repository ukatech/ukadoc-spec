# meta.albumartist

**カテゴリ:** Property System \> Sound Property Names

The album artist name recorded in the tags of the target media.<br />
If multiple values are recorded, they are joined with "; " (a semicolon followed by a space).<br />
See [here](sound.meta.artwork.note.md) for behavior when tags are missing or cannot be retrieved.

**対応:** SSP 2.8.73
