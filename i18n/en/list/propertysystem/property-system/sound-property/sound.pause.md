# pause

**カテゴリ:** Property System \> Sound Property Names

1 if the target media is paused, or 0 otherwise.<br />
*\[SET enabled\]*Setting 1 has the same effect as [`\![sound,pause,～]`](../../../sakura-script/sound/bang-sound-pause.md), and setting 0 has the same effect as [`\![sound,resume,～]`](../../../sakura-script/sound/bang-sound-resume.md).

**対応:** SSP 2.8.72
