# currentghost.balloon.scope(ID).basepos.x

**カテゴリ:** Property system

Starting point for drawing text in the current balloon (X coordinate). This is not necessarily the left edge of the drawing area. Coordinates are relative to the top-left corner of the balloon image.<br />
For [vertical writing](../../../descript/balloon/descript-txt/vertical.md), this indicates the right edge of the first column (= [origin.x](../../../descript/balloon/descript-txt/origin.x.md)).

**対応:** SSP (2.3.72)
