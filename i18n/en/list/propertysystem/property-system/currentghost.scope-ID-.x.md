# currentghost.scope(ID).x

**カテゴリ:** Property system

The X coordinate on the screen of the reference point of the surface for the current ghost's scope ID.<br />
For multiple monitors, the position within the entire virtual desktop, with the top-left of the primary monitor as the origin.<br />
The reference point is usually the bottom center of the surface. This can be configured in the descript.txt of GHOST and SHELL using [sakura(kero、char\*).defaultx](../../../descript/shell/descript-txt/sakura.defaultx.md).

**対応:** SSP
