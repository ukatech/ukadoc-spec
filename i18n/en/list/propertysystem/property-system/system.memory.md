# system.memory.(key)

**カテゴリ:** Property System

Information about the physical memory in the running environment. The strings that can be used for (key) are as follows.

- **load**: Usage percentage (integer, averaged over a moving window of approximately one minute)
- **phyt**: Total physical memory (MB)
- **phya**: Available physical memory (MB)

**対応:** SSP 2.6.26
