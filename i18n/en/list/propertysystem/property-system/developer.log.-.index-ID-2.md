# developer.log.log type(name).index(ID).log property name

**カテゴリ:** Property system

Gets information from the entry at the specified ID among log entries whose name matches the specified name.<br />
IDs are assigned in order from newest to oldest, starting at 0. If `.index(ID)` is omitted (`developer.log.log type(name).log property name`), the newest entry is used.<br />
Note that the parentheses follow directly without a dot. The log property names are listed [here](developer.log.-.index-ID.md).

**対応:** SSP
