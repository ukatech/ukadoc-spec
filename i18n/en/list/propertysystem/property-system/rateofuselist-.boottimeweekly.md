# rateofuselist(name).boottimeweekly

**カテゴリ:** Property system

The number of times the ghost has been started (weekly report, aggregated from 7 days ago through today).<br />
\[SSP 2.9.35\] The ghost's [UUID](general-property/uuid.md) can also be specified inside the parentheses instead of its name. If multiple ghosts have the same UUID, the one with a record is used.

**対応:** SSP 2.8.54
