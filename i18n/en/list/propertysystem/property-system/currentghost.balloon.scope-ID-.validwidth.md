# currentghost.balloon.scope(ID).validwidth

**カテゴリ:** Property system

Width available for drawing text in the current balloon. Indicates the entire drawing area, regardless of basepos.<br />
For [vertical writing](../../../descript/balloon/descript-txt/vertical.md), this is the width available in the direction the columns are arranged (right to left), and matches the drawing width after scrolling.

**対応:** SSP
