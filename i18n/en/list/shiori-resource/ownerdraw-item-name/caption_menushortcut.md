# Shortcut keys

For SHIORI Resource events that retrieve the following item names, if the returned string contains a character preceded by &, such as &○, that character becomes the shortcut key for the item.<br />
For example, if you return “きほん(&P)” for [portalrootbutton.caption](portalrootbutton.caption.md), pressing the p key while the owner-draw menu is open selects the portal item (P is underlined in the display).

Half-width alphanumeric characters and symbols are valid. Characters that require the Shift key to type are also valid, but uppercase and lowercase letters are not distinguished.
