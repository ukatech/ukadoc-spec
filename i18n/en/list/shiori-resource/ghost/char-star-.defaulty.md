# char\*.defaulty

**カテゴリ:** Ghost information

\*The Y-coordinate of the default position of the character (`\p[*]`). The format and meaning are the same as [sakura.defaulty](sakura.defaulty.md).<br />
char0 and char1 are used when sakura and kero are not specified.<br />
If none are specified, the character is placed at the same height as the previous character.

**対応:** SSP
