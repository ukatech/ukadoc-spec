# char\*.popupmenu.applybindtoself

**カテゴリ:** Ghost information

Changes how the dressup menu behaves when the owner-draw menu type is changed.<br />
Change according to the menu type = 0　Show the dressup options for the scope (character ID) that owns the menu = 1<br />
The default setting is 1, which differs from the behavior before SSP 2.7.25. To restore the previous behavior, explicitly set this to 0.

**対応:** SSP 2.7.26
