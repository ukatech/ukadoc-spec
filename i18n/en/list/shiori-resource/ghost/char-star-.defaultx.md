# char\*.defaultx

**カテゴリ:** Ghost information

The default X coordinate of the \*th character (`\p[*]`). The format and meaning are the same as for [sakura.defaultx](sakura.defaultx.md).<br />
Used mainly for the third and later characters (char2 and later). char0 and char1 are used when sakura and kero are not specified.<br />
If none are specified, the character is placed to the left of the preceding character.

**対応:** SSP
