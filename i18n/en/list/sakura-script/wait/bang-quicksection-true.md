# `\![quicksection,true]`

**カテゴリ:** Wait command

Starts the quick section. `\![quicksection,1]` can also be used.<br />
It is mostly compatible with `\_q`; the difference is that it explicitly starts the section instead of using a switch.

**対応:** SSP / Ninix

## 記述例

```sakurascript
\![quicksection,1]文字を瞬間表示する。これもウェイトタグは実行される。
```
