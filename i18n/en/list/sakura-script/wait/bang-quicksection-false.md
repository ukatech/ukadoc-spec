# `\![quicksection,false]`

**カテゴリ:** Wait command

Ends the quick section. `\![quicksection,0]` can also be used.<br />
It is mostly compatible with `\_q`; the difference is that it explicitly ends the section instead of using a switch.

**対応:** SSP / Ninix

## 記述例

```sakurascript
\![quicksection,1]文字を瞬間表示する。これもウェイトタグは実行される。\![quicksection,0]また、クイックセクションのさくらスクリプトは\![quicksection,1]混ぜて使っても有効。\_q
```
