# `\_q`

**カテゴリ:** Wait command

Quick section.<br />
Messages are displayed without waiting until the next `\_q` or `\e`.<br />
However, Sakura Script commands that include waits still run, and their waits still apply during instant display.

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\_q文字を瞬間表示する。里々等、自動でウェイトが挿入される場合は注意。\_q
```
