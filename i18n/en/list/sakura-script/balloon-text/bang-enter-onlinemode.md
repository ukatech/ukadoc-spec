# `\![enter,onlinemode]`

**カテゴリ:** Balloon, text command

Force the online marker to be displayed. The main-character balloon is displayed even if the other character has content to display and the main-character balloon does not.

This remains in effect until the ghost exits.

**対応:** SSP

## 記述例

```sakurascript
\0\![enter,onlinemode]本体側のバルーンにオンラインマーカーが表示される。
```
