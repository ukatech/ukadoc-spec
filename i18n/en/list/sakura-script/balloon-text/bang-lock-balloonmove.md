# `\![lock,balloonmove]`

**カテゴリ:** Balloon, text command

Suppress user-dragging of the balloon until `\![unlock,balloonmove]` is called.<br />
This can be specified permanently in descript.txt, as with [sakura.balloon.dontmove](../../../descript/shell/descript-txt/sakura.balloon.dontmove_.md).<br />
Do not overuse this, as it interferes with user interaction.

**対応:** SSP 2.4.96
