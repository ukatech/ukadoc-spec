# `\_v[ファイル名]`

**カテゴリ:** Sound command

The baseware plays a WAV, MP3, or WMA file. The path can be relative to \[the folder of the executing ghost\]/ghost/master or absolute.<br />
Ignored if the file does not exist.

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\_v[se/test.wav]。[実行したゴーストのフォルダ]/ghost/master/seフォルダにあるtest.wavを再生する。
```
