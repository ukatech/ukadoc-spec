# `\![sound,loop,ファイル名]`

**カテゴリ:** Sound command

Play the file in a loop. It is not included in the target of `\_V`.<br />
To stop playback, execute `\![sound,stop]`.

**対応:** SSP / Ninix

## 記述例

```sakurascript
\![sound,loop,test.wav][実行したゴーストのフォルダ]/ghost/masterフォルダにあるtest.wavを再生する。\![sound,stop]ループ再生を停止する。
```
