# `\![enter,collisionmode]\![enter,collisionmode,rect]`

**カテゴリ:** Uncategorized command

Does the same thing as “Show hit regions” in the developer palette. If rect is specified as the third argument, only the region outlines are shown, without displaying collision names.

Remains in effect until the ghost ends.

**対応:** SSP / Ninix

## 記述例

```sakurascript
\![enter,collisionmode]コリジョンモードを開始する。
```
