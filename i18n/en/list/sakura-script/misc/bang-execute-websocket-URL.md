# `\![execute,websocket,URL,オプション,オプション,オプション...]`

**カテゴリ:** Unclassified command

Establish a WebSocket connection with [options](bang-execute-http-options-URL.note.md). SHIORI events are issued when the connection is established, when data is received, and when it is disconnected. The parameters are specified in the same way as for rss-get.

**対応:** SSP 2.8.05
