# `\![execute,rss-post,URL,オプション,オプション,オプション...]`

**カテゴリ:** Unclassified command

Make an HTTP POST request with [options](bang-execute-http-options-URL.note.md), parse the response as an RSS/Atom feed, and then notify the results as an event.<br />
The parsing, notification, and [filtering](bang-execute-rss-post-URL.note.md) specifications are the same as for [rss-get](bang-execute-rss-get-URL.md). The parameters are specified in the same way as for http-post.

**対応:** SSP
