# `\![execute,createnar,出力先ファイル]`

**カテゴリ:** Uncategorized command

Creates a NAR of the ghost that executed the script.<br />
Output file: Optional. Specify a path relative to the ghost's ghost/master folder, or an absolute path. \[2.8.98\]<br />
If specified, creates the file there without prompting for the destination. If a file with the same name already exists, it is overwritten. If the destination is inside the ghost's folder, the file itself is not included in the NAR.

**対応:** SSP 2.5.08
