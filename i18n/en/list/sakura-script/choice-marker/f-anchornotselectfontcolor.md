# `\f[anchornotselectfontcolor,色指定]`

**カテゴリ:** Choice marker modification command

Change the text color of an unselected anchor.<br />
For how to specify the color, see [※refer below](note-1.md#形状指定の方法).

**対応:** SSP

## 記述例

```sakurascript
\f[anchornotselectfontcolor,default.cursor]\_a[OnTest]アンカー\_a非選択のアンカーの文字色を選択中選択肢と同じ色に変更する。
```
