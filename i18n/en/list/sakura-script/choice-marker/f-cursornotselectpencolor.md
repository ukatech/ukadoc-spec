# `\f[cursornotselectpencolor,色指定]`

**カテゴリ:** Choice marker modification command

Changes the color of the rectangular border and underline of the unselected marker.<br />
For how to specify the color, see [below](note-1.md#形状指定の方法).

**対応:** SSP

## 記述例

```sakurascript
\f[cursornotselectpencolor,0,255,0]\q[選択肢,OnTest]非選択中の選択肢の形状がsquareかunderlineの場合、枠線の色が緑色になる。
```
