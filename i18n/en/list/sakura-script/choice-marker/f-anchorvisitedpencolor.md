# `\f[anchorvisitedpencolor,色指定]`

**カテゴリ:** Choice marker modification command

Change the color of the rectangular border and underline of a visited anchor.<br />
For how to specify the color, see [※refer below](note-1.md#形状指定の方法).

**対応:** SSP

## 記述例

```sakurascript
\f[anchorvisitedpencolor,0,255,0]\_a[OnTest]アンカー\_a訪問済みのアンカーの形状がsquareかunderlineの場合、枠線の色が緑色になる。
```
