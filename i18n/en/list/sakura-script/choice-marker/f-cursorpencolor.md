# `\f[cursorpencolor,色指定]`

**カテゴリ:** Choice marker modification command

Changes the color of the rectangular frame and underline of the selected marker.<br />
For how to specify this, see [※refer below](note-1.md#形状指定の方法).

**対応:** SSP

## 記述例

```sakurascript
\f[cursorpencolor,0,255,0]\q[選択肢,OnTest]選択中の選択肢の形状がsquareかunderlineの場合、枠線の色が緑色になる。
```
