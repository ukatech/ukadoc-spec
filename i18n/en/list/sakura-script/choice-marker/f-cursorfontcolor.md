# `\f[cursorfontcolor,色指定]`

**カテゴリ:** Choice marker change command

Change the text color of the selected marker using RGB (0–255).<br />
For the specification method, see [the note below](note-1.md#形状指定の方法).

**対応:** SSP

## 記述例

```sakurascript
\f[cursorfontcolor,default.anchor]\q[選択肢,OnTest]選択中の選択肢の文字色をアンカーと同じ色に変更する。
```
