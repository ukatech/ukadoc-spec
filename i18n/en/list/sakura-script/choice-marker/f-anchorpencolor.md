# `\f[anchorpencolor,色指定]`

**カテゴリ:** Choice marker modification command

Change the color of the rectangular border and underline of the selected anchor.<br />
For how to specify the color, see [※refer below](note-1.md#形状指定の方法).

**対応:** SSP

## 記述例

```sakurascript
\f[anchorpencolor,0,255,0]\_a[OnTest]アンカー\_a選択中のアンカーの形状がsquareかunderlineの場合、枠線の色が緑色になる。
```
