# `\f[cursornotselectfontcolor,色指定]`

**カテゴリ:** Choice marker modification command

Change the text color of the unselected marker.<br />
For how to specify it, [see below](note-1.md#形状指定の方法).

**対応:** SSP

## 記述例

```sakurascript
\f[cursornotselectfontcolor,default.anchor]\q[選択肢,OnTest]非選択中の選択肢の文字色をアンカーと同じ色に変更する。
```
