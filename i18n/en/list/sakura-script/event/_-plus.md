# `\_+`

**カテゴリ:** Event command

Switches to the next ghost in sequence (sequential change). This switches to the ghost below the current one in the Ghost Explorer.<br />
If the current ghost is at the bottom of the list, switches to the ghost at the top of the list.<br />
This script does not notify the SHIORI event [OnGhostChanging](../../shiori-event/boot-close-change/OnGhostChanging.md) when switching ghosts.

**対応:** Materia / SSP / Ninix

## 記述例

```sakurascript
リストの次のゴーストへチェンジ。\_+
```
