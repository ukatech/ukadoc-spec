# `\![updatebymyself(,オプション,オプション...)]`

**カテゴリ:** Event command

Starts a network update check event.<br />
The user can also initiate this from the right-click menu or Ghost Explorer.<br />
Options are supported only by SSP. See [Specifying update options](note-1.md#補足).

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
ネットワーク更新を開始。\![updatebymyself]
```
