# `\7`

**カテゴリ:** Event command

Starts a clock synchronization event.<br />
The SHIORI event [OnSNTPBegin](../../shiori-event/sntp/OnSNTPBegin.md) is notified, and once the time is obtained from the time server, the SHIORI event [OnSNTPCompare](../../shiori-event/sntp/OnSNTPCompare.md) is notified.

**対応:** Materia / SSP
