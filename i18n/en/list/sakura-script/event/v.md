# `\v`

**カテゴリ:** Event command

Displays the character in front. From this script onward, the character is always displayed on top.<br />
However, which scope is in front (the base character or the companion) depends on user interaction.

This remains in effect until the ghost exits.

**対応:** Materia / SSP / Ninix

## 記述例

```sakurascript
\vこのスクリプト以降、最前面に表示されるようになる。
```
