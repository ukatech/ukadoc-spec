# `\6`

**カテゴリ:** Event command

Performs the actual time adjustment during a clock synchronization event.<br />
This is generally done in the SHIORI event [OnSNTPCompare](../../shiori-event/sntp/OnSNTPCompare.md), which is notified when a time server is connected to.

**対応:** Materia / SSP / CROW

## 記述例

```sakurascript
時間をサーバと合わせる。\6
```
