# `\![set,windowstate,stayontop]`

**カテゴリ:** Event command

Keep the window in the foreground. From this point on in the script, it is always displayed on top.

Valid until the ghost ends.

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\![set,windowstate,stayontop]このスクリプト以降、最前面に表示されるようになる。
```
