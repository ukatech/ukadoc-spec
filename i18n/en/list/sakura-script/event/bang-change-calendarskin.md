# `\![change,calendarskin,カレンダースキン名]`

**カテゴリ:** Event command

Switch the calendar skin. This is the same as selecting a skin from the calendar menu.<br />
If the specified calendar skin does not exist, the command is ignored.<br />
If the calendar has never been opened, only the setting is changed; it takes effect the next time the calendar is opened.

Set the calendar skin name to lastinstalled to switch to the last installed calendar skin. However, this is disabled if SSP has been exited once.<br />
Set the calendar skin name to random to switch to a random skin.<br />
The calendar skin name is notified via [installedcalendarskinname](../../shiori-event/notify/installedcalendarskinname.md).

**対応:** SSP 2.8.93
