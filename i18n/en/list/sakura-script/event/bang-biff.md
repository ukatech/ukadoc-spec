# `\![biff(,アカウント名)]`

**カテゴリ:** Event command

Starts a mail-check event.<br />
Using `\![biff,アカウント名]` runs a mail check for a specific account name.<br />
The account name is provided by [configuredbiffname](../../shiori-event/notify/configuredbiffname.md).

**対応:** Materia / SSP (account name supported in 2.5) / CROW

## 記述例

```sakurascript
メールチェックイベントを開始。\![biff]
```
