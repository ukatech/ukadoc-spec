# `\![set,windowstate,!stayontop]`

**カテゴリ:** Event command

Do not keep the window in the foreground. From this point on in the script, it is stacked with other windows in the usual way.

Valid until the ghost ends.

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\![set,windowstate,!stayontop]このスクリプト以降、アクティブなウインドウが手前に表示されるようになる。
```
