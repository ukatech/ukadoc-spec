# `\![restore,wallpaper]`

**カテゴリ:** Event command

Restores the wallpaper saved with save,wallpaper.<br />
\[2.8.93\] In window mode, restores the background saved with save,wallpaper while in window mode as the window-mode background (the OS wallpaper is not changed). Does nothing if nothing was saved in window mode.

**対応:** SSP 2.8.11
