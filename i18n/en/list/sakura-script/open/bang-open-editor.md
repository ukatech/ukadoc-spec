# `\![open,editor,ファイル,表示行]`

**カテゴリ:** Open command

Edits the specified file using the editor configured in the baseware.<br />
This is the editor specified under "External Applications -> Editor Settings" in the baseware's owner draw menu settings.<br />
When opened with "display line", the cursor is moved to the specified line in advance.

If no editor is specified, the behavior is the same as right-clicking in Explorer and selecting "Edit". In this case, "display line" is ignored.

**対応:** SSP 2.5.16
