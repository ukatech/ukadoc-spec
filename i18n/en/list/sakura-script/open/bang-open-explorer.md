# `\![open,explorer,ファイル]`

**カテゴリ:** Open command

Opens the file manager configured in the baseware, with the specified file.<br />
This is specified under "External Applications -> File Manager Settings" in the baseware's owner draw menu settings.

If no file manager is specified, a specified folder is opened, or a specified file is selected in Explorer.

Specify `\![open,explorer,種類(ghost/shell/balloon/headline/plugin),名前]` to select the folder to open by type and name.<br />
Example: `\![open,explorer,ghost,Emily/Phase4]`

**対応:** SSP 2.5.12
