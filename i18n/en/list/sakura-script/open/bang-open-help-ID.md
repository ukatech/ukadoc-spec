# `\![open,help,ダイアログID]`

**カテゴリ:** Open command

Opens SSP Help.<br />
If the dialog ID is the ID name of a settings dialog (see [Reference0 of OnConfigurationDialogHelp](../../shiori-event/dialogbox/OnConfigurationDialogHelp.md)), help for that settings dialog is displayed. If omitted, the index page is opened.

**対応:** SSP

## 記述例

```sakurascript
\![open,help,talk]ブラウザで、https://ukatech.shillest.net/ukadoc-ssp/の喋り/バルーンのページを開く。
```
