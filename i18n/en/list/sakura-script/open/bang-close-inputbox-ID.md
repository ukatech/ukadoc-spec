# `\![close,inputbox,ID]`

**カテゴリ:** Open command

Close the InputBox specified by ID (including date, time, slider, and hidden-input boxes). To close all of them, specify \_\_SYSTEM_ALL_INPUT\_\_.

**対応:** SSP / Ninix

## 記述例

```sakurascript
\![close,inputbox,時間入力テスト]IDが「時間入力テスト」のInputBoxを閉じる。\![close,inputbox,__SYSTEM_ALL_INPUT__]その後、全てのInputBoxを閉じる。
```
