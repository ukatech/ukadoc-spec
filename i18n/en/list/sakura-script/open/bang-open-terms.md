# `\![open,terms]`

**カテゴリ:** Open command

Display the terms dialog using \[the folder of the executing ghost\]/terms.txt for the currently running ghost.<br />
If terms.txt does not exist, this has no effect (only an error sound is played).<br />
Because this forcibly interrupts the user's actions with a dialog, it should not be used excessively.

**対応:** SSP 2.5.33

## 記述例

```sakurascript
\![open,terms]terms.txtを開く。
```
