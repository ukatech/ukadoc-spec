# `\![open,ghostexplorer]`

**カテゴリ:** Open command

Opens the ghost explorer.<br />
It can also be opened from the owner draw menu.<br />
The explorers listed below can also be changed manually by selecting a type from the ghost explorer's Type (T) menu.

**対応:** Materia / SSP / CROW

## 記述例

```sakurascript
\![open,ghostexplorer]ゴーストエクスプローラを開く。
```
