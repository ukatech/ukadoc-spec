# `\![open,configurationdialog,ダイアログID]`

**カテゴリ:** Open command

Open the settings dialog ("Baseware Settings" in the owner-draw menu).<br />
The dialog ID can specify which screen to show initially (if omitted, the screen opened last time is used).<br />
See Reference0 of the SHIORI event ※[OnConfigurationDialogHelp](../../shiori-event/dialogbox/OnConfigurationDialogHelp.md).

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\![open,configurationdialog,talk]SSP本体設定ダイアログの喋り/バルーンのタブを開く。
```
