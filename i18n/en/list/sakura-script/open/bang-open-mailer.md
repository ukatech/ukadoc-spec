# `\![open,mailer,パラメータ]`

**カテゴリ:** Open command

Opens the mailer configured in the baseware.<br />
This is specified under "External Applications -> Mailer Settings" in the baseware's owner draw menu settings.

**対応:** Materia / SSP

## 記述例

```sakurascript
\![open,mailer,test@example.com]送信先アドレスにtest@example.comが入ったメーラーを開く。
```
