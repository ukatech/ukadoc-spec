# `\![set,alignmentondesktop,bottomまたはtop]`

**カテゴリ:** Surface command

Attaches the current scope's surface to the edge of the desktop in the specified direction. bottom attaches it to the bottom of the desktop, and top to the top.

Takes effect until the ghost ends.

※For SSP, also see alignment*to*desktop.

**対応:** Materia / SSP / CROW

## 記述例

```sakurascript
\![set,alignmentondesktop,bottom]本体側がデスクトップ下部(タスクバーの上)にくっつく。
```
