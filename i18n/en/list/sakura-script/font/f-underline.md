# `\f[underline,パラメータ]`

**カテゴリ:** Text change command

Specify true or 1 for the parameter to draw an underline.<br />
Specify false or 0 for the parameter to disable it.<br />
Specify default to restore the balloon's default setting.<br />
Specifying disable applies the same setting as displaying it as disabled.

**対応:** SSP / Ninix

## 記述例

```sakurascript
\f[underline,1]文字に下部線を引く。\f[underline,default]バルーンのデフォルト設定にもどす。
```
