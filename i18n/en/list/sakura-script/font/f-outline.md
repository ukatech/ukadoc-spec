# `\f[outline,パラメータ]`

**カテゴリ:** Text formatting command

Specify true or 1 for the parameter to render text as outline.<br />
Specify false or 0 for the parameter to disable it.<br />
Specify default to restore the balloon's default setting.<br />
Specify disable to use the same setting as disabled text display.

**対応:** SSP

## 記述例

```sakurascript
\f[height,30]\f[outline,1]白抜きにする。\f[outline,default]バルーンのデフォルト設定にもどす。
```
