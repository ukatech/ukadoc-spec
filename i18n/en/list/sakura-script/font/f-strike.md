# `\f[strike,パラメータ]`

**カテゴリ:** Text modification command

If the parameter is set to true or 1, a strikethrough is displayed. Sample.<br />
If the parameter is set to false or 0, it is disabled.<br />
If default is specified, it returns to the balloon's default setting.<br />
If disable is specified, it uses the same setting as disabled display.

**対応:** SSP / Ninix

## 記述例

```sakurascript
\f[strike,1]文字に打ち消し線を引く。\f[strike,default]バルーンのデフォルト設定にもどす。
```
