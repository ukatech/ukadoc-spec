# `\f[sup,パラメータ]`

**カテゴリ:** Text formatting command

Specify true or 1 as the parameter to display superscript text <sup>Sample</sup>.<br />
Specify false or 0 as the parameter to disable it.<br />
Specify default to restore the balloon's standard setting.<br />
Specifying disable produces the same display as when disabled.

**対応:** SSP / Ninix

## 記述例

```sakurascript
文字を\f[sup,1]上付き文字にする。\f[sup,default]バルーンのデフォルト設定にもどす。
```
