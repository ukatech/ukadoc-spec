# `\f[sub,パラメータ]`

**カテゴリ:** Text modification command

Specify true or 1 for the parameter to display subscript text <sub>Sample</sub>.<br />
Specify false or 0 for the parameter to disable it.<br />
Specify default to restore the balloon's standard setting.<br />
Specify disable to use the same setting as disabled display.

**対応:** SSP / Ninix

## 記述例

```sakurascript
文字を\f[sub,1]下付き文字にする。\f[sub,default]バルーンのデフォルト設定にもどす。
```
