# `\f[shadowstyle,形態指定]`

**カテゴリ:** Text rendering command

Changes the style of the text shadow. offset displays the text shifted down and to the right; outline displays it with an outline.

**対応:** SSP 2.5.27

## 記述例

```sakurascript
\f[shadowcolor,#ffff00]\f[shadowstyle,outline]文字の周囲を黄色で縁取りして表示。\f[shadowstyle,default]\f[shadowcolor,default]バルーンのデフォルトに戻す。
```
