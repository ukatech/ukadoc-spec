# `\f[valign,寄せる側]`

**カテゴリ:** Text change command

Sets bottom alignment (`\f[valign,bottom]`), vertical center alignment (`\f[valign,center]`), or top alignment (`\f[valign,top]`) for text.<br />
If this command is run while adding text or other content, it also moves text already added on the same line.<br />
Unlike align, it is not reset by `\n` or `\_l`.<br />
In vertical writing mode, top means left alignment, bottom means right alignment, and center means horizontal center alignment.

**対応:** SSP 2.6.19
