# Variable-name response event

**カテゴリ:** Ghost “Sounds of Everyday Life in Melody”

A ghost that receives OnKanadeTeaPartyInfomationRequest sends this event to *Sounds of Everyday Life in Melody* using *raiseother*.<br />
The event name is provided in reference2 of OnKanadeTeaPartyInfomationRequest.

- **Reference0**: The ghost’s supported tea party version number
- **Reference1**: The name of the ghost’s baseware
- **Reference2**: [※Information about tea party version support](note-1.md#補足)
