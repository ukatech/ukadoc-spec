# OnKanadeTeaPartyInfomationRequest

**カテゴリ:** Ghost “The Melody of Daily Life”

An event notified to each ghost by The Melody of Daily Life before the tea party begins.<br />
Ghosts participating in the tea party must immediately, in response to this event,<br />
`\![raiseother,かなで,返信イベント名,ゴーストの対応するお茶会バージョン番号,ゴーストの本体側名,※お茶会バージョンへの対応情報]`<br />
execute this Sakura Script.<br />
Talk other than executing this script during the event is deprecated.

- **Reference0**: Tea party version number.
- **Reference1**: Baseware-side name of the ghost receiving the reply event (fixed as “かなで”).
- **Reference2**: Reply event name.
