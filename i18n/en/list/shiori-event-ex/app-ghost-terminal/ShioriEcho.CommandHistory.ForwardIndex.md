# ShioriEcho.CommandHistory.ForwardIndex

**カテゴリ:** Interactive exe for ghost development "Ghost Terminal"

Event triggered when the index is updated after the user presses \`↑\`

- **Reference0**: Command history index (reverse order, starting value is 0)
- **Reference1**: Expected increase in the value of \`index\`.
- **Return value (optional): X-SSTP-PassThru-Index**: Update the index to this value
