# ShioriEcho.CommandUpdate

**カテゴリ:** Interactive exe for ghost development "Ghost Terminal"

Event triggered when a command is updated

- **Reference0**: Command collected by the terminal
- **Return value (optional): X-SSTP-PassThru-CommandForDisplay**: Replace the displayed command with this content.<br />
  The ghost can use this event to implement features such as masking password input and syntax highlighting during normal speech.
