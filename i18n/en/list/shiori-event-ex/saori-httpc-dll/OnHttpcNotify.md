# OnHttpcNotify

**カテゴリ:** SAORI "httpc.dll"

A return-value notification event sent via DirectSSTP by the same DLL after a function provided by httpc.dll is run with the asynchronous execution option.

- **Reference0**: The identifier passed as argument 1 when called.
- **Reference1**: Empty string
- **Reference\***: The return value of the executed function.
