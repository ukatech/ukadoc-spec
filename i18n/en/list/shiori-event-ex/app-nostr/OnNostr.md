# OnNostr

**カテゴリ:** Nostr notification event

## Notification information in Nostr/0.5

- **Reference0**: Version (Nostr/0.5)
- **Reference1**: Nostr event kind (number) (1:note, 7:reaction, ...)
- **Reference2**: Nostr event content
- **Reference3**: The kind0 name of the Nostr event signer
- **Reference4**: The kind0 display_name of the Nostr event signer
- **Reference5**: The kind0 picture of the Nostr event signer
- **Reference6**: The NIP-19-encoded Nostr event ID (note1... or nevent1...)
- **Reference7**: The NIP-19-encoded public key of the Nostr event signer (npub1...)
- **Reference8**: Value of the Nostr event's g tag
- **Reference9**: Value of the Nostr event's n tag
- **Reference10**: Value of the Nostr event's t tag
