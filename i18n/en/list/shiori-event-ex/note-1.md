# Notes

The following includes *events issued by external sources* and *events returned by their recipients*, such as events sent via SSTP by applications outside the baseware, and events issued by ghosts or plugins to other ghosts.

For the issuers of these events, this page is only unofficial documentation, and the information may be inaccurate due to subsequent updates to each item. See the official documentation for each item for details.

If you know of any events not listed here, please [report them](http://ssp.shillest.net/bts/?project=misc&action=top). We will add them.
