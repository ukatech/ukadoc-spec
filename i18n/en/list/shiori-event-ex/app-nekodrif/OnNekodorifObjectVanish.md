# OnNekodorifObjectVanish

**カテゴリ:** App "Nekodorif"

Occurs when a falling object that hit something disappears from the visible area.

- **Reference0**: Name of the falling object.
- **Reference1**: Name of the ghost targeted by the falling object.
- **Reference2**: Category of the falling object.
- **Reference3**: Mushroom flag. 1 if it was a mushroom; otherwise, 0.
- **Reference4**: Name of the target of the falling object.
