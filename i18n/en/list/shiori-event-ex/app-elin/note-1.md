# Notes

## Character and item information

## Item information

Items are separated by byte value 1. Example: dirt0x01gold nugget0x01iron pickaxe0x01…

## Character information

Each character's name and carried items are separated by byte value 1, and each character is further separated by byte value 2. Example: Yek0x02copper dagger0x01goblin0x02paper greatsword0x02coral light cloak0x01samurai…
