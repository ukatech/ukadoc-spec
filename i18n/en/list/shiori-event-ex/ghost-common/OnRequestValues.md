# OnRequestValues

**カテゴリ:** General cross-ghost event

Occurs when another ghost sends this event at its discretion.<br />
When this event is sent, an OnGetValues event must be sent using \\\[raiseother\].

- **Reference0**: Name of the sending ghost.
- **Reference1**: Name of the requested variable (key). Reference2 and subsequent references follow the same pattern for as many requested variables as exist.

**対応:** SSP
