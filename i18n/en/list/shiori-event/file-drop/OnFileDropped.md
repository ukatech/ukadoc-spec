# OnFileDropped

**カテゴリ:** File drop event

\[Legacy specification\] Occurs when a file is dragged and dropped.

- **Reference0**: Path of the dropped file.
- **Reference1**: Scope number of the character the file was dropped onto. The main character is 0, the partner is 1, and the third character onward are 2 and higher.
- **Reference2**: MIME type of the dropped file (SSP 2.7.98 and later).

**対応:** SSP / CROW
