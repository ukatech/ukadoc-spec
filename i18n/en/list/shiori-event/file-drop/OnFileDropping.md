# OnFileDropping

**カテゴリ:** File drop event

Occurs when the cursor, with a file being dragged, moves over a ghost.

- **Reference0**: Path of the file being dragged.
- **Reference1**: Scope number of the character the file is dropped onto. The main character is 0, the partner is 1, and the third character onward are 2 and higher.

**対応:** SSP / CROW
