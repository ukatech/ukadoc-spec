# OnWallpaperChange

**カテゴリ:** File drop event

Occurs when the wallpaper is changed by dragging and dropping an image file.<br />
To be notified when the wallpaper is changed by the OS, use [OnDesktopWallpaperChange](../os-state/OnDesktopWallpaperChange.md).

- **Reference0**: Path of the dropped file.
- **Reference1**: SSP only. Scope number of the dropped character (main character 0, partner 1, ...).

**対応:** Materia / SSP / CROW
