# OnNarCreating

**カテゴリ:** File drop event

Occurs when a ghost folder containing install.txt is dragged and dropped.

- **Reference0**: Name of the object to be made into a nar.
- **Reference1**: File name and absolute path of the nar to be created.
- **Reference2**: [※Identifier](../install/caption_install-identifier.md). See the installation identifier.

**対応:** Materia / SSP / CROW
