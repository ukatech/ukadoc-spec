# OnHeadlinesenseComplete

**カテゴリ:** Headline/RSS sensor event

Occurs when headline sensing completes successfully.<br />
Currently, successful headline sensing means that reading aloud has started, so this event is sent only when retrieval succeeded but there were no updates.
