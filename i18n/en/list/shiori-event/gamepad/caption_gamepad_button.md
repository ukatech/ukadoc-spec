# Button name list

- **A**: Bottom face button
- **B**: Right face button
- **X**: Left face button
- **Y**: Top face button
- **LB**: Left bumper (equivalent to L1)
- **RB**: Right bumper (equivalent to R1)
- **LSB**: Left stick click (equivalent to L3)
- **RSB**: Right stick click (equivalent to R3)
- **Start**: Start button
- **Back**: Back / Select button
- **DPadUp**: D-pad up
- **DPadDown**: D-pad down
- **DPadLeft**: D-pad left
- **DPadRight**: D-pad right

A diagonal D-pad input generates two separate button events (for example, DPadUp and DPadRight for up-right).
