# OnGamepadButtonDown

**カテゴリ:** Gamepad event

Occurs when a gamepad button is pressed.<br />
Does not occur while the button is held down; it occurs only at the moment of pressing.<br />
If multiple buttons change simultaneously, a separate event occurs for each button.<br />
The event is broadcast to all running ghosts simultaneously.

- **Reference0**: [Pad index](caption_gamepad_padindex.md).
- **Reference1**: [Button name](caption_gamepad_button.md).

**対応:** SSP 2.7.54
