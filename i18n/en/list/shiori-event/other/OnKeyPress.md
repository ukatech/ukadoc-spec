# OnKeyPress

**カテゴリ:** Other events

Occurs when a key is pressed while the baseware is active.

- **Reference0**: The key pressed. (The character printed on the key)
- **Reference1**: The key pressed. (Win32 virtual-key code)
- **Reference2**: SSP only. Key press-and-hold count.
- **Reference3**: SSP only. Character window ID where the key event occurred.
- **Reference4**: SSP only. Modifier keys, listed as comma-separated values. Example: "ctrl,alt"

**対応:** Materia / SSP / CROW / Ninix
