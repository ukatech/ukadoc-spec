# property.set

**カテゴリ:** Other events

Occurs when setting an extended property using [activeghostlist(ghost name/path/ID).ext](../../propertysystem/property-system/activeghostlist-.ext.md).<br />
Returns 204 on success, or an appropriate status code on failure.

- **Reference0**: Extended property name.
- **Reference1**: Value to set.

**対応:** SSP 2.7.85
