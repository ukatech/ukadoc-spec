# OnShellChanging

**カテゴリ:** Startup, shutdown, and switching events

Occurs when switching to another shell.

- **Reference0**: Name of the shell being switched to.
- **Reference1**: (SSP only) Name of the shell before switching (the current shell).
- **Reference2**: (SSP only) Path of the shell being switched to.

**対応:** Materia / SSP / CROW / Ninix
