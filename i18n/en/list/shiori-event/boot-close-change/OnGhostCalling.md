# OnGhostCalling

**カテゴリ:** Startup, shutdown, and switching events

Occurs when a request is made to call another ghost.

- **Reference0**: The name of the called ghost's main body.
- **Reference1**: If switched manually, manual<br />
  If switched by the system, automatic<br />
  is returned.
- **Reference2**: The name of the called ghost.
- **Reference3**: The path of the called ghost.

**対応:** SSP / Ninix
