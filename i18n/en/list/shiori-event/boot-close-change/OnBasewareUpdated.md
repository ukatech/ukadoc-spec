# OnBasewareUpdated

**カテゴリ:** Boot, close, and change events

Occurs when the ghost starts after a baseware update has completed. If this event is not handled, OnBoot occurs.

- **Reference0**: Version number after the update. Example: 2.3.59
- **Reference1**: Version number after the update, matching the version number shown in Windows Explorer properties. Example: 2.3.59.3000

**対応:** SSP
