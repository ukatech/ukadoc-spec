# OnOtherGhostBooted

**カテゴリ:** Startup, shutdown, and switching events

Occurs when another ghost is called and that ghost starts.<br />
In other words, it occurs for unrelated ghosts at the same time that OnGhostCallComplete occurs for the calling ghost.

- **Reference0**: Name of the started ghost's main body.
- **Reference1**: Startup script of the started ghost.
- **Reference2**: Name of the started ghost.
- **Reference7**: Shell name of the started ghost.

**対応:** SSP / Ninix
