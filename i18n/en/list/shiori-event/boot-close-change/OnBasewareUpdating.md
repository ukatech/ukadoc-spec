# OnBasewareUpdating

**カテゴリ:** Boot, close, and change events

Occurs during a baseware update, after the download is complete and before file updates begin. If this event is not handled, OnCloseAll and then OnClose occur.

- **Reference0**: Version number before the update. Example: 2.3.58
- **Reference1**: Version number before the update, matching the version number shown in Windows Explorer properties. Example: 2.3.58.3000

**対応:** SSP
