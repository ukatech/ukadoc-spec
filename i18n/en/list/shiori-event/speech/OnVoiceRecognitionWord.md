# OnVoiceRecognitionWord

**カテゴリ:** Speech recognition and synthesis events

Occurs when a word is recognized by voice recognition.

- **Reference0**: 0 for the main character, 1 for the partner. SSP/CROW may also use 2 or higher.
- **Reference1**: The recognized word. When the character is addressed by name for the first time, this is the character's name itself; in that case, it is preferable to display a menu.

**対応:** SSP 2.4
