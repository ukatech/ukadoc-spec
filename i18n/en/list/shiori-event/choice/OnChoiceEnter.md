# OnChoiceEnter

**カテゴリ:** Choice event

Occurs when the cursor enters *or leaves* a choice.<br />
OnChoiceEnter occurs without a Reference when the cursor leaves a choice.

- **Reference0**: Choice text (label).
- **Reference1**: Choice ID.
- **Reference\***: Extended information (third and subsequent arguments in the `\q` tag).

**対応:** Materia / SSP / CROW / Ninix
