# OnAnchorSelectEx

**カテゴリ:** Choice event

Occurs when a `\_a` hyperlink is clicked. OnAnchorSelect then occurs only if SHIORI returns nothing for this event.

- **Reference0**: Text of the selected hyperlink.
- **Reference1**: ID of the selected hyperlink.
- **Reference\***: Extended information (second and subsequent arguments in the `\_a` tag).

**対応:** SSP
