# OnSelectModeMouseDown

**カテゴリ:** Selection region mode events

Occurs when a mouse button is pressed while in rectangle selection mode.

- **Reference0**: 0 for the main character, 1 for the partner. SSP/CROW may also use 2 or higher.
- **Reference1**: Selection mode. Currently only "rect".
- **Reference2**: Mouse position. X (horizontal) and Y (vertical) coordinates, separated by a comma.

**対応:** SSP
