# Install identifiers

- shell
- ghost
- balloon
- plugin
- headline
- rss
- supplement

The following apply only to OnInstallComplete / OnNarCreated<br />
These are deprecated in SSP; ghosts and balloons are reported with separate identifiers.

- ghost with balloon
- shell with balloon

The following are SSP-specific

- calendar skin
- calendar plugin
- package
- language

In SSP, identifiers for items installed [simultaneously](../../../descript/install/install-txt/introduction_install_multi.md) are *dot-separated*, calendar.skin / calendar.plugin, just as they are specified in install.txt.<br />
The identifier on the archive's baseware side retains the form used for type in install.txt, so it is space-separated: calendar skin / calendar plugin.
