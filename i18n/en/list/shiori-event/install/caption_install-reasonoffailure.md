# Reasons for installation failure

- **unlha32**: Failed to load the DLL for extracting lzh-format files
- **extraction**: Extraction failed (corrupt file)
- **invalid type**: install.txt contains an error
- **artificial**: The user canceled installation (SSP only)
- **unsupported**: Another unsupported archive type
- **password**: The password was incorrect for a password-protected archive (SSP 2.5.09 and later)
