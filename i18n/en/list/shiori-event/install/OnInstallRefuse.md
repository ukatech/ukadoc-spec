# OnInstallRefuse

**カテゴリ:** Installation event

Occurs when the file being installed specifies another ghost as its intended recipient.

- **Reference0**: Baseware-side name of the specified ghost (the [accept](../../../descript/install/install-txt/accept.md) setting in install.txt, that is, the intended recipient).
- **Reference1**: [※Identifier](caption_install-identifier.md) of the item being installed.
- **Reference2**: Name of the item being installed.

**対応:** Materia / SSP; Reference1 and later: 2.4.85 / CROW / Ninix
