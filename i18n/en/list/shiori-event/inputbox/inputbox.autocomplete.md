# inputbox.autocomplete

**カテゴリ:** Input box event

Occurs when the box is expanded. If a list of text separated by the character with byte value 1 is returned for this event, autocomplete is enabled in the input box.<br />
(Windows Me/2000 or later)

- **Reference0**: Input box type: one of inputbox, teachbox, or communicatebox.
- **Reference1**: For inputbox only, the event name/identifier raised when input is submitted.

**対応:** SSP
