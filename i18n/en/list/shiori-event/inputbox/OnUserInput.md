# OnUserInput

**カテゴリ:** Input box event

Occurs when input is submitted in an InputBox.

See also [InputBox ID](../../sakura-script/open/bang-close-textareabox-ID.note-2.md).

- **Reference0**: InputBox ID.
- **Reference1**: Entered content.
- **Reference2**: Additional input information (for sliderinput only, minimum,maximum; empty otherwise)
- **Reference3～**: Additional information specified by --reference=

**対応:** Materia / SSP / CROW / Ninix
