# OnTabletMode

**カテゴリ:** OS state event

Occurs when the OS switches to a state optimized for tablet operation.<br />
Sent as NOTIFY (cannot speak) immediately after startup, and as GET (can speak) when the mode changes.

- **Reference0**: 0/1: 1 means tablet mode (the OS is optimized for tablet operation); 0 means the mode is off

**対応:** SSP 2.5.02
