# OnUpdateOtherBegin

**カテゴリ:** Network update event

Occurs when a network update for something other than a ghost is instructed to begin.

- **Reference0**: Ghost name.
- **Reference1**: Full path.
- **Reference3**: [※Update target type](caption_updatetype.md)
- **Reference4**: SSP 2.3: [※Reason for running the update](caption_updatereason.md).

**対応:** SSP
