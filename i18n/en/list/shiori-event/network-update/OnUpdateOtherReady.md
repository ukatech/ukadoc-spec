# OnUpdateOtherReady

**カテゴリ:** Network update event

Occurs when update files for something other than a ghost are found.

- **Reference0**: Total number of files to be updated minus 1 (sequential number starting from 0).
- **Reference1**: A comma-separated list of updated file names.
- **Reference3**: [※Update target type](caption_updatetype.md)
- **Reference4**: SSP 2.3: [※Reason for running the update](caption_updatereason.md).

**対応:** SSP
