# OnUpdateOther.OnDownloadBegin

**カテゴリ:** Network update event

Occurs when downloading a file other than a ghost begins.

- **Reference0**: Name of the file to download.
- **Reference1**: Number of the update file currently being downloaded (sequential number starting from 0).
- **Reference2**: Total number of files to be updated minus 1 (sequential number starting from 0).
- **Reference3**: [※Update target type](caption_updatetype.md)
- **Reference4**: SSP 2.3: [※Reason for running the update](caption_updatereason.md).

**対応:** SSP
