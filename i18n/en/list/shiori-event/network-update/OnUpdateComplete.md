# OnUpdateComplete

**カテゴリ:** Network update event

Occurs when the network update succeeds and completes.

- **Reference0**: [※Reason for success](caption_updateresultcomplete.md)
- **Reference1**: A comma-separated list of updated file names.
- **Reference3**: CROW: ghost when updating a ghost, baseware when updating the main program.<br />
  SSP: [※Update target type](caption_updatetype.md)
- **Reference4**: SSP 2.3: [※Reason for running the update](caption_updatereason.md).

**対応:** Materia / SSP / CROW / Ninix
