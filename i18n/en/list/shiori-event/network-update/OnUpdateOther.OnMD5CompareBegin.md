# OnUpdateOther.OnMD5CompareBegin

**カテゴリ:** Network update event

Occurs when MD5 comparison begins for something other than a ghost.

- **Reference0**: Name of the file to compare.
- **Reference1**: Correct MD5 value.
- **Reference2**: MD5 value of the downloaded file.
- **Reference3**: [※Update target type](caption_updatetype.md)
- **Reference4**: SSP 2.3: [※Reason for running the update](caption_updatereason.md).

**対応:** SSP
