# OnURLDropping

**カテゴリ:** URL drop event

Occurs when a URL has been dropped and the download is about to start.<br />
This event occurs before the download process. It does not occur for other types of installations (homeurl or feed (RSS) installation).

- **Reference0**: Dropped URL.
- **Reference1**: Scope number of the character the URL was dropped on. Main character is 0, partner is 1, and the third character onward are 2 and higher.

**対応:** Materia / SSP Ref1 is 2.6.36 / CROW
