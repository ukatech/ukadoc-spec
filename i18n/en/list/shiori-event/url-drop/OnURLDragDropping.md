# OnURLDragDropping

**カテゴリ:** URL drop event

Occurs when a URL is about to be dropped and the mouse cursor is over it.<br />
This event occurs for all URLs that can be accepted.

- **Reference0**: Dropped URL.
- **Reference1**: Scope number of the character the URL was dropped on. Main character is 0, partner is 1, and the third character onward are 2 and higher.

**対応:** SSP 2.6.37
