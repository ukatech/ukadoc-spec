# OnVanishButtonHold

**カテゴリ:** Vanish event

Occurs when the vanish event is canceled by double-clicking.

- **Reference0**: Script where the interruption action occurred.
- **Reference1**: Scope number of the balloon where the interruption action occurred. Main character is 0, partner is 1, and so on.
- **Reference2**: Interruption position, expressed as the number of characters from the start of the script. Sakura Script tags are included in the character count.<br />
  Example: If interrupted at the「あ」in `\s[2]`あいうえお, the value is 6.

**対応:** Materia / SSP / CROW / Ninix
