# OnNotifySelfInfo

**カテゴリ:** Notify event

Notifies information about the ghost itself. *\[NOTIFY\]*

- **Reference0**: Ghost name.
- **Reference1**: Name of the main character.
- **Reference2**: Name of the partner character.
- **Reference3**: Name of the currently used shell.
- **Reference4**: Absolute path to the currently used shell.
- **Reference5**: Name of the currently used balloon.
- **Reference6**: Absolute path to the currently used balloon.

**対応:** SSP / CROW
