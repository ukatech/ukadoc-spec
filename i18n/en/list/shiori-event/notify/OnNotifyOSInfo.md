# OnNotifyOSInfo

**カテゴリ:** Notify event

Notifies OS information. *\[NOTIFY\]*

- **Reference0**: OS system, version, and display name \[comma-separated\]
- **Reference1**: CPU type, clock speed in MHz, and additional information \[comma-separated\]
- **Reference2**: Physical and virtual memory (KB) \[comma-separated\]
- **Reference3**: Minutes since system startup.

**対応:** SSP
