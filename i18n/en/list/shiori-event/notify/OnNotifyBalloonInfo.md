# OnNotifyBalloonInfo

**カテゴリ:** Notify event

Notifies the information for the currently used balloon. *\[NOTIFY\]*

- **Reference0**: Name of the selected balloon
- **Reference1**: Full path of the selected balloon
- **Reference2**: List of surface numbers \[character ID + colon + comma-separated values + space\] Example: 0:0,1,2,3 1:0,1

**対応:** SSP
