# OnNotifyUserInfo

**カテゴリ:** Notify event

Notifies user input information. Notified at startup and when the information is updated. *\[NOTIFY\]*

- **Reference0**: Name to use when addressing the user.
- **Reference1**: Full name.
- **Reference2**: Birthday (comma-separated, such as 2003,5,5).
- **Reference3**: Gender. One of male (man), female (woman), or undef (undefined).

**対応:** SSP
