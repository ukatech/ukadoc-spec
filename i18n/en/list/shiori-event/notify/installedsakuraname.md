# installedsakuraname

**カテゴリ:** Notify event

Notifies the sakura.name of installed ghosts. *\[NOTIFY\]*<br />
Always notified before installedghostname.<br />
The Reference numbers for installedsakuraname, installedkeroname, and installedghostname, which refer to the same ghost, are guaranteed to match.

- **Reference\***: sakura.name of an installed ghost.

**対応:** SSP 2.6.47
