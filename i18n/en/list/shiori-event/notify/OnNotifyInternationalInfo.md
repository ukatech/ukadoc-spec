# OnNotifyInternationalInfo

**カテゴリ:** Notify event

Notifies internationalization-related information such as the time zone and locale (language) name. *\[NOTIFY\]*

- **Reference0**: Time offset from UTC, in minutes. Negative values = ahead; positive values = behind<br />
  For example, Japan Standard Time is 9 hours ahead, so the value is -540.
- **Reference1**: Whether daylight saving time is enabled. Enabled=1 Disabled=0
- **Reference2**: [Two-letter country code compliant with ISO3166](https://ja.wikipedia.org/wiki/ISO_3166-1).
- **Reference3**: [Two-letter language name compliant with ISO639](https://ja.wikipedia.org/wiki/ISO_639-1%E3%82%B3%E3%83%BC%E3%83%89%E4%B8%80%E8%A6%A7).

**対応:** SSP
