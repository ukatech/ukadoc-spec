# OnSchedulesenseBegin

**カテゴリ:** Calendar event

Occurs when a schedule sensor begins connecting.<br />
This event is sent to all running ghosts, not to a specific ghost.

**Occurs only during a manual update (when a sensor is selected from the calendar menu to update).** As [described below](caption_schedulesensetiming.md), it does not occur during periodic checks.

- **Reference0**: Schedule sensor name
- **Reference1**: Schedule sensor subscription URL

**対応:** SSP
