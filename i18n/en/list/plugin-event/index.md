# PLUGIN Event List

This page summarizes the events notified by the baseware *to* plugins.

For information about the PLUGIN/2.0 communication specification itself, see the [PLUGIN/2.0](../../spec/plugin.md) page.

Events marked *\[NOTIFY\]* are always notified with the NOTIFY command.<br />
Any script returned in response to an event notified with the NOTIFY command is ignored completely.

Events without a specific mark may be notified with either NOTIFY or GET, depending on the situation.
