# property.set

**カテゴリ:** PLUGIN Event

Occurs when setting an extended property using [pluginlist(plugin name/path/ID).ext](../../propertysystem/property-system/pluginlist-ID-.ext.md).<br />
Returns 204 on success, or an appropriate status code on failure.

- **Reference0**: Name of the extended property.
- **Reference1**: Value to set.

**対応:** SSP 2.7.85
