# installedghostname

**カテゴリ:** PLUGIN Event

Lists installed ghosts and notifies. *\[NOTIFY\]*

- **Reference0**: List of ghost names, delimited by byte value 1
- **Reference1**: List of `\0` names, delimited by byte value 1
- **Reference2**: List of `\1` names, delimited by byte value 1

**対応:** SSP
