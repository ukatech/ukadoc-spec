# internal_system

A list of built-in modules and how to call their functions. Use this to check from a script which functions are available and which options and algorithm names can be used.<br />
Only modules whose names begin with `internal_` appear in the list ([compatibility modules](../compat.md) do not appear).<br />
The results of `ListModules` / `ListFunctions` are comma-separated in `Result`, with one item each from `Value0` onward. The order has no meaning.
