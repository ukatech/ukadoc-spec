# SSTP/1.x

Reference: [SSTP](http://usada.sakura.vg/contents/sstp.html) (external site)

At present, DirectSSTP depends heavily on Windows specifications, and implementation on other operating systems is not anticipated.<br />
Since IPC mechanisms also exist on other operating systems, it would be preferable to define a separate specification.<br />
If a specification is established, we plan to publish it separately, so please contact the [Ukadoc Project](https://github.com/ponapalt/ukadoc).
