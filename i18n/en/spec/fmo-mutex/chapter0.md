# FMO/Mutex

Reference: [Memory Objects](http://usada.sakura.vg/contents/objects.html) (external site)

At present, this specification depends heavily on Windows-specific behavior and is not intended for implementation on other operating systems.<br />
Shared memory and Mutexes exist on other operating systems as well, so it would be preferable to define a separate specification for them.<br />
If a specification is established, we plan to publish it separately. Please contact the [Ukadoc Project](https://github.com/ponapalt/ukadoc).
