# seriko.sticky-window,scope ID,scope ID,...

**カテゴリ:** descript.txt

The descript equivalent of [`\![set,sticky-window,スコープID,スコープID,...]`](../../../list/sakura-script/surface/bang-set-sticky-window-ID-ID.md). This can be configured in advance without executing the tag.

This can also be specified in the ghost's descript.txt. The shell's setting takes precedence if present; otherwise, the ghost's value is used.

**既定値:** No value

**対応:** SSP 2.4
