# seriko.alignmenttodesktop,position information

**カテゴリ:** descript.txt

Default [※display position information](note-1.md#サーフェスの位置情報) for all surfaces.<br />
Takes precedence over ghost-side settings but has lower priority than individual shell-side settings (such as [sakura.seriko.alignmenttodesktop](sakura.seriko.alignmenttodesktop.md)).<br />
※Ghost-wide setting < per-scope ghost setting < this setting < per-scope shell setting

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** bottom

**対応:** SSP / CROW
