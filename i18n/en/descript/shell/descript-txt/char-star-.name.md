# char\*.name,name

**カテゴリ:** descript.txt

The name of `\p[*]`.

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell value takes precedence; otherwise, the ghost value is used. However, if the ghost's [name.allowoverride](../../ghost/descript-txt/name.allowoverride.md) is 0, the shell setting is not used.

**既定値:** Optional. Used to set the window title.

**対応:** SSP 2.6.66
