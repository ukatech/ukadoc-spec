# char\*.balloon.syncscale,true

**カテゴリ:** descript.txt

Forcibly enables synchronization of the balloon scale with the ghost scale for the second and subsequent characters (only true is valid).

This can also be written in the ghost's descript.txt. If specified in the shell, the shell setting takes precedence; otherwise, the ghost's value is used.

**既定値:** The [balloon.syncscale](balloon.syncscale.md) setting

**対応:** SSP 2.7 RC1
