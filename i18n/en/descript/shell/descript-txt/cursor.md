# cursor,filename / mousecursor,filename

**カテゴリ:** descript.txt

The cursor (pointing finger) used over interactive parts of the ghost. The mousecursor alias is available starting with SSP 2.5.41.

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell value takes precedence; otherwise, the ghost value is used.

**既定値:** The cursor (pointing finger) configured in the OS (system:finger)

**対応:** Materia / SSP / CROW
