# menu.foreground.alignment,position

**カテゴリ:** descript.txt

Specifies the position of the foreground image. See [Menu image positioning](note-1.md#メニュー画像の位置指定).

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** lefttop

**対応:** Materia / SSP / CROW
