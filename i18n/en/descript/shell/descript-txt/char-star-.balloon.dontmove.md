# char\*.balloon.dontmove,number

**カテゴリ:** descript.txt

Prevents users from moving the balloons of the second and subsequent characters. Set to 1 or true to prevent movement.

This can also be written in the ghost's descript.txt. If specified in the shell, the shell setting takes precedence; otherwise, the ghost's value is used.

**既定値:** The [balloon.dontmove](balloon.dontmove.md) setting

**対応:** SSP 2.4.96
