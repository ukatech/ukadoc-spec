# sakura.bindgroup\*.addid,ID

**カテゴリ:** descript.txt

Sets dressup items to run simultaneously. When the dressup for animation ID \* becomes active (is displayed), the dressup specified by addid also becomes active. Multiple values can be specified, separated by commas.<br />
A dressup running simultaneously is disabled when the dressup that activated it is disabled. If the same dressup is specified to run simultaneously by multiple addid entries, it remains active until all the dressups that activated it are disabled. (baseware side)

**既定値:** No operation

**対応:** SSP
