# uuid_base,string

**カテゴリ:** descript.txt

A base string for preventing UUID collisions. The format and meaning are the same as for [uuid_base in the ghost's descript.txt](../../ghost/descript-txt/uuid_base.md).<br />
The value can be retrieved through [uuid_base](../../../list/propertysystem/property-system/general-property/uuid_base.md) in the property system.

**既定値:** No value

**対応:** SSP 2.9.35
