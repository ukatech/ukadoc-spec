# char\*.balloon.offsety,coordinate

**カテゴリ:** descript.txt

The Y coordinate of the `\p[*]` balloon position.<br />
For the syntax for appending a single direction character (l / r / c / b), see [char\*.balloon.offsetx](char-star-.balloon.offsetx.md).

This can also be written in the ghost's descript.txt. If specified in the shell, the shell setting takes precedence; otherwise, the ghost's value is used.

**既定値:** No value

**対応:** SSP
