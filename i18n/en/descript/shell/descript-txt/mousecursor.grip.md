# mousecursor.grip,filename

**カテゴリ:** descript.txt

The cursor (closed hand) indicating that a grabbable part of the ghost is being grabbed. It is normally used automatically while the mouse button is held down over a Bust hitbox.

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** Closed-hand cursor (system:grip)

**対応:** SSP 2.6.11
