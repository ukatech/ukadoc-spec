# char\*.bindgroup\*.name,category name,part name,thumbnail name

**カテゴリ:** descript.txt

Defines a category name and part name for the part with animation ID \*. (Third character and later)<br />
The animation ID is the number represented by \* in the animation definition "animation\*.interval,bind" in surfaces.txt.<br />
Required for displaying the item in the dressup menu of an owner-draw menu.<br />
Also required to control it with Sakura Script [`\![bind,category name,part name,numeric value]`](../../../list/sakura-script/surface/bang-bind.md). (SSP only)

**既定値:** No behavior

**対応:** SSP
