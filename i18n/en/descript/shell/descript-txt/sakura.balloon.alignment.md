# sakura.balloon.alignment,position information

**カテゴリ:** descript.txt

[Position information](note-1.md#バルーンの位置情報) for the main character's balloon.

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** No value

**対応:** Materia / SSP / CROW
