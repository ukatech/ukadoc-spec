# balloon.syncscale,true

**カテゴリ:** descript.txt

Forcibly enables synchronization of the balloon's scale with the ghost's scale (only true is valid).<br />
Do not overuse this setting, as it restricts user control.

This can also be written in the ghost's descript.txt. If specified in the shell, the shell setting takes precedence; otherwise, the ghost's value is used.

**既定値:** false

**対応:** SSP 2.7 RC1
