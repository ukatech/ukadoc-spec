# char\*.seriko.alignmenttodesktop,position information

**カテゴリ:** descript.txt

The default [display position information](note-1.md#サーフェスの位置情報) for the second companion character onward.<br />
This takes precedence over the shell-wide setting ([seriko.alignmenttodesktop](seriko.alignmenttodesktop.md)). In other words, it has the highest priority of all alignmenttodesktop settings.<br />
Priority: ghost-wide setting < ghost per-scope setting < shell-wide setting < this setting

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell value takes precedence; otherwise, the ghost value is used.

**既定値:** No value

**対応:** SSP
