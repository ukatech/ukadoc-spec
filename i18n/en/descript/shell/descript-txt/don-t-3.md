# don't need seriko talk,number

**カテゴリ:** descript.txt

Set to 1 to disable the SERIKO talk method (lip-sync) feature.

`disable.seriko.talk` can also be used as an alias (SSP only).

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell value takes precedence; otherwise, the ghost value is used.

**既定値:** 0

**対応:** Materia / SSP
