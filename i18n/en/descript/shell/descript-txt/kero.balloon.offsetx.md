# kero.balloon.offsetx,coordinate

**カテゴリ:** descript.txt

The X coordinate of the kero balloon position.<br />
For the syntax that appends a single character indicating direction (l / r / c / b), see [sakura.balloon.offsetx](sakura.balloon.offsetx.md).

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** No value

**対応:** Materia / SSP / CROW
