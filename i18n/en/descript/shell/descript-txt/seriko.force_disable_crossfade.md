# seriko.force_disable_crossfade,value

**カテゴリ:** descript.txt

If 1 or true is specified, the crossfade effect when switching surfaces is forcibly disabled.

This can also be specified in the ghost's descript.txt. The shell's setting takes precedence if present; otherwise, the ghost's value is used.

**既定値:** 0

**対応:** SSP 2.8.43
