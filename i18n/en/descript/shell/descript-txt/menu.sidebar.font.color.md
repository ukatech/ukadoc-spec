# menu.sidebar.font.color,color

**カテゴリ:** descript.txt

The color of the text ([menu.sidebar.text](menu.sidebar.text.md)) displayed in the sidebar of the owner draw menu.<br />
Specify the color using a color name (such as `red`), `#RRGGBB`, or `#RGB` (the `#` can be omitted).<br />
Red, green, and blue can also be specified separately by writing values from 0 to 255 in `menu.sidebar.font.color.r` / `menu.sidebar.font.color.g` / `menu.sidebar.font.color.b`.

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** The same color as [menu.foreground.font.color](menu.foreground.font.color.r.md)

**対応:** SSP
