# kero.seriko.alignmenttodesktop,position information

**カテゴリ:** descript.txt

The default [display position information](note-1.md#サーフェスの位置情報) for kero.<br />
This takes precedence over the shell-wide setting ([seriko.alignmenttodesktop](seriko.alignmenttodesktop.md)). It has the highest priority of all alignmenttodesktop settings.<br />
Priority: ghost-wide setting < ghost scope-specific setting < shell-wide setting < this setting

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** No value

**対応:** SSP
