# kero.bindgroup\*.name,category name,part name,thumbnail name

**カテゴリ:** descript.txt

Define the category name and part name for the part with animation ID \*.<br />
The animation ID is the number represented by \* in the animation definition “animation\*.interval,bind” in surfaces.txt.<br />
This is required to display it in the dressup menu of the owner draw menu.<br />
It is also required to operate it using Sakura Script [`\![bind,カテゴリ名,パーツ名,数値]`](../../../list/sakura-script/surface/bang-bind.md). (SSP only)

**既定値:** No operation

**対応:** Materia / SSP
