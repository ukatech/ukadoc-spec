# menu.background.font.color.b,value

**カテゴリ:** descript.txt

The blue component of the background text color (0–255).

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** The menu text color configured in the OS

**対応:** Materia / SSP / CROW
