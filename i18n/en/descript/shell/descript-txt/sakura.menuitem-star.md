# sakura.menuitem\*,ID

**カテゴリ:** descript.txt

Displays the dressup for the specified animation ID at position \* in the dressup menu. \* is a sequential number starting from 0. (baseware side)<br />
Specify "-" instead of an ID to display a separator at that position.

**既定値:** No operation

**対応:** Materia / SSP
