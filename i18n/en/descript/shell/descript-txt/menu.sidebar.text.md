# menu.sidebar.text,string

**カテゴリ:** descript.txt

The string displayed in the sidebar of the owner draw menu. It is displayed to be read from bottom to top (rotated 90 degrees to the left).<br />
If a sidebar image ([menu.sidebar.bitmap.filename](menu.sidebar.bitmap.filename.md)) is present, the image is used and this string is not displayed.<br />
Specify the background color with [menu.sidebar.color](menu.sidebar.color.md) and the text color with [menu.sidebar.font.color](menu.sidebar.font.color.md). The same font is used as for menu items ([menu.font.name](menu.font.name.md) / [menu.font.height](menu.font.height.md)).

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** No value

**対応:** SSP
