# char\*.balloon.offsetx,coordinate

**カテゴリ:** descript.txt

The X coordinate of the `\p[*]` balloon position. `char0` and `char1` use the same settings as `sakura` and `kero`, respectively.<br />
The meaning of the coordinate and the syntax for appending a single direction character (l / r / c / b) are the same as for [sakura.balloon.offsetx](sakura.balloon.offsetx.md).

This can also be written in the ghost's descript.txt. If specified in the shell, the shell setting takes precedence; otherwise, the ghost's value is used.

**既定値:** No value

**対応:** SSP
