# kero.menuitemex\*,menu name,ID

**カテゴリ:** descript.txt

Displays the dressup for the specified animation ID at position \* in the dressup menu, under the hierarchy indicated by "menu name". \* is a sequential number starting from 0. (Partner side)<br />
Specify "-" instead of an ID to display a separator at that position.

**既定値:** No action

**対応:** SSP
