# sakura.bindoption\*.group,Category name,Option

**カテゴリ:** descript.txt

Sets options for the dressup category. \* is simply a sequential number starting from 0 (baseware side).<br />
mustselect requires exactly one part to be selected; multiple allows multiple parts to be selected.<br />
Multiple options can be specified, separated by +.

**既定値:** Selection can be cleared; multiple selection is not allowed

**対応:** SSP
