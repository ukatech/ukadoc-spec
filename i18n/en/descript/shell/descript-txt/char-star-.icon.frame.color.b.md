# char\*.icon.frame.color.b,number

**カテゴリ:** descript.txt

The blue component (0–255) of the frame around the partner icon (face thumbnail) for the second and subsequent characters when displayed in the [backlog (speech history) window](../../../list/sakura-script/open/bang-open-backlogviewer.md). [Note](note-1.md#アイコン枠色の明度調整について)

This can also be written in the ghost's descript.txt. If specified in the shell, the shell setting takes precedence; otherwise, the ghost's value is used.

**既定値:** No value

**対応:** SSP 2.8.53
