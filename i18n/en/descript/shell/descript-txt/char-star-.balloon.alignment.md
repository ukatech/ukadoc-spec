# char\*.balloon.alignment,position information

**カテゴリ:** descript.txt

The [position information](note-1.md#バルーンの位置情報) for the `\p[*]` balloon. `char0` and `char1` use the same settings as `sakura` and `kero`, respectively.

This can also be written in the ghost's descript.txt. If specified in the shell, the shell setting takes precedence; otherwise, the ghost's value is used.

**既定値:** No value

**対応:** SSP
