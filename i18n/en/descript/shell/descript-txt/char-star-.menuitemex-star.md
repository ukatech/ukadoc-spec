# char\*.menuitemex\*,menu name,ID

**カテゴリ:** descript.txt

Display the dressup for the animation ID at position \* in the dressup menu, under the hierarchy indicated by "menu name". \* is a sequential number starting from 0. (Third character and beyond)<br />
Specify "-" instead of an ID to display a separator at that position.

**既定値:** No action

**対応:** SSP
