# kero.bindgroup\*.addid,ID

**カテゴリ:** descript.txt

Configures dressups to run concurrently. When the dressup for animation ID \* becomes active (visible), the dressup specified by addid also becomes active. Multiple values can be specified, separated by commas.<br />
A concurrently activated dressup becomes inactive when the dressup that activated it becomes inactive. If the same dressup is specified for concurrent activation by multiple dressups, it remains active until all of those dressups become inactive. (Partner side)

**既定値:** No action

**対応:** SSP
