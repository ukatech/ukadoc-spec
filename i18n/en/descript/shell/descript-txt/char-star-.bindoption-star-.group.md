# char\*.bindoption\*.group,category name,option

**カテゴリ:** descript.txt

Sets options for the dressup category. \* is simply a sequential number starting from 0 (third character and later).<br />
mustselect requires one part to be selected; multiple allows multiple parts to be selected.<br />
Multiple options can be specified, separated by +.

**既定値:** Selection can be cleared; multiple selections are not allowed

**対応:** SSP
