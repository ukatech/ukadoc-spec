# id,ID name

**カテゴリ:** descript.txt

The shell's ID name. Use only half-width alphanumeric characters. (SSP allows all characters)<br />
Currently, it is only used in displays such as the console shown at startup.<br />
In SSP, it is not visible unless Settings-General-Enable transparent status display window is turned ON.

**既定値:** No value

**対応:** Materia / SSP / CROW
