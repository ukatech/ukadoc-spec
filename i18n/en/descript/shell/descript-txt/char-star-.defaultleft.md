# char\*.defaultleft,X coordinate

**カテゴリ:** descript.txt

The X coordinate of the default position of character \* (`\p[*]`). Equivalent to [sakura.defaultleft](sakura.defaultleft.md).

This can also be written in the ghost's descript.txt. If specified in the shell, the shell setting takes precedence; otherwise, the ghost's value is used.

**既定値:** No value (placed immediately to the left of the preceding character)

**対応:** SSP
