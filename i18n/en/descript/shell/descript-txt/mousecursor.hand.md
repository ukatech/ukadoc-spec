# mousecursor.hand,filename

**カテゴリ:** descript.txt

The cursor (open hand) indicating a grabbable part of the ghost. It is normally used automatically over a Bust hitbox.

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** Hand-shaped cursor (system:hand)

**対応:** SSP 2.6.11
