# mousecursor.text,filename

**カテゴリ:** descript.txt

The cursor (I-BEAM) used for the ghost's input boxes.

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** The cursor configured in the OS (I-beam) (system:text)

**対応:** SSP 2.5.41
