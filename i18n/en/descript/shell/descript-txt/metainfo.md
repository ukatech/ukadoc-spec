# metainfo,URL

**カテゴリ:** descript.txt

The URL of the metainfo folder containing the shell's information. The format and meaning are the same as for [metainfo in the ghost's descript.txt](../../ghost/descript-txt/metainfo.md).<br />
The value can be retrieved through [metainfo](../../../list/propertysystem/property-system/general-property/metainfo.md) in the property system.

**既定値:** No value

**対応:** SSP 2.9.35
