# balloon.defaultsurface,number

**カテゴリ:** descript.txt

The default surface number for balloons. This applies to all characters.<br />
If specified per character using [sakura.balloon.defaultsurface](sakura.balloon.defaultsurface.md), [kero.balloon.defaultsurface](kero.balloon.defaultsurface.md), or [char\*.balloon.defaultsurface](char-star-.balloon.defaultsurface.md), those settings take precedence, whether specified in the ghost or the shell.

This can also be written in the ghost's descript.txt. If specified in the shell, the shell setting takes precedence; otherwise, the ghost's value is used.

**既定値:** 0

**対応:** SSP
