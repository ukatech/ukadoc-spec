# sakura.name,name

**カテゴリ:** descript.txt

The name of the main character of the ghost.

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used. However, if the ghost's [name.allowoverride](../../ghost/descript-txt/name.allowoverride.md) is 0, the shell's value is not used.

**既定値:** Required

**対応:** Materia / SSP / CROW
