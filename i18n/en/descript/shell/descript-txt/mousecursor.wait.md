# mousecursor.wait,filename

**カテゴリ:** descript.txt

The cursor (watch-shaped) used when the ghost is processing something and cannot respond.

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** The cursor configured in the OS (watch) (system:wait)

**対応:** SSP 2.5.43
