# kero.bindoption\*.group,category name,options

**カテゴリ:** descript.txt

Sets options for the dressup category. \* is simply a sequential number starting from 0. (Partner side)<br />
Use mustselect to require exactly one part to be selected, or multiple to allow multiple parts to be selected.<br />
Multiple options can be specified, separated by +.

**既定値:** Selection can be cleared; multiple selections are not allowed

**対応:** SSP
