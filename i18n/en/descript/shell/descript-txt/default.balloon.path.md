# default.balloon.path,Path

**カテゴリ:** descript.txt

The relative path to this shell's default balloon. It is treated the same as [balloon](balloon.md); see [balloon](balloon.md) for the order in which the balloon to switch to is determined.<br />
The [default.balloon.path](../../ghost/recommended-balloon/default.balloon.path.md) in the ghost's descript.txt is used as the ghost's default balloon, with lower priority than the shell's setting.

**既定値:** ghost's descript setting

**対応:** SSP
