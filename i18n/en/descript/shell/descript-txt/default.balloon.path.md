# default.balloon.path,path

**カテゴリ:** descript.txt

The relative path to this shell's default balloon. Like [balloon](balloon.md), this is used when the user has not explicitly switched balloons. See [balloon](balloon.md) for precedence and other details.<br />
This can also be specified in the ghost's descript.txt as [default.balloon.path](../../ghost/recommended-balloon/default.balloon.path.md). The shell's setting takes precedence if specified; otherwise, the ghost's value is used.

**既定値:** The ghost's descript setting

**対応:** SSP
