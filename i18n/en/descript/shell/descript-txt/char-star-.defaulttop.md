# char\*.defaulttop,Y coordinate

**カテゴリ:** descript.txt

The Y coordinate of the default position of character \* (`\p[*]`). Equivalent to [sakura.defaulttop](sakura.defaulttop.md).

This can also be written in the ghost's descript.txt. If specified in the shell, the shell setting takes precedence; otherwise, the ghost's value is used.

**既定値:** No value (placed at the same height as the preceding character)

**対応:** SSP
