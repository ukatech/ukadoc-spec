# sakura.balloon.syncscale,true

**カテゴリ:** descript.txt

Forcibly enables synchronization of the main character's balloon scale with the ghost's scale (only true is valid).<br />
Do not overuse this setting, as it restricts user operations.

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** The [balloon.syncscale](balloon.syncscale.md) setting

**対応:** SSP 2.7 RC1
