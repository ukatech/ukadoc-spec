# shiori.logo.align,position

**カテゴリ:** descript.txt

Specifies the reference point for the coordinates specified by shiori.logo.x,y. Normally the top left.<br />
The available values are top left (lefttop), bottom left (leftbottom), top right (righttop), and bottom right (rightbottom).

This can also be specified in the ghost's descript.txt. The shell's setting takes precedence if present; otherwise, the ghost's value is used.

**既定値:** lefttop (top-left reference point)

**対応:** Materia deprecated / SSP
