# kero.defaultx,X coordinate

**カテゴリ:** descript.txt

The X coordinate of the default position of kero (`\1`). See also [sakura.defaultx](sakura.defaultx.md). \[2.9.13\]

This can also be specified in the ghost's descript.txt. If specified in the shell, the shell's value takes precedence; otherwise, the ghost's value is used.

**既定値:** No value (placed to the left of sakura)

**対応:** SSP
