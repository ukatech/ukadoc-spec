# sakura.bindgroup\*.name,Category name,part name,thumbnail name

**カテゴリ:** descript.txt

Define the category name and part name for the part with animation ID number \*.<br />
The animation ID is the number corresponding to \* in “animation\*.interval,bind” in the animation definitions in surfaces.txt.<br />
This is required to display the item in the dressup menu of the owner-draw menu.<br />
This is also required to operate it using Sakura Script [`\![bind,カテゴリ名,パーツ名,数値]`](../../../list/sakura-script/surface/bang-bind.md). (SSP only)

**既定値:** No action

**対応:** Materia / SSP
