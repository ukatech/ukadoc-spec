# default.balloon.path,path

**カテゴリ:** descript.txt - Recommended balloon

The relative path to the default balloon.<br />
This can also be specified in the shell's descript.txt as [default.balloon.path](../../shell/descript-txt/default.balloon.path.md). When switching to that shell, the shell's setting takes precedence if the user has not explicitly switched balloons.

**既定値:** Unknown | The SSP balloon or the default balloon configured by the user (on SSP)

**対応:** SSP
