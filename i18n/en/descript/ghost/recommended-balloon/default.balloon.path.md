# default.balloon.path,Path

**カテゴリ:** descript.txt - Recommended balloon

The relative path to the balloon used by default.<br />
It can also be specified in the shell's descript.txt as [default.balloon.path](../../shell/descript-txt/default.balloon.path.md), and the shell's setting takes precedence. See the shell's [balloon](../../shell/descript-txt/balloon.md) for the order in which the balloon to switch to is determined.

**既定値:** Unknown | SSP balloon or the default balloon configured by the user (on SSP)

**対応:** SSP
