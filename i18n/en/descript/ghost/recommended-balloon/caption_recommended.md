# Using the Default and Recommended Settings

- **Default**: The one to select on first launch or when resetting settings.<br />
  The user can change it freely later.
- **Recommended**: Behaves the same as “Default,” but *indicates a stronger dependency*.<br />
  A warning may appear when trying to switch to another balloon.<br />
  Setting this casually takes away the user's choices, so *do not specify it lightly* unless there is a strong dependency.<br />
  If you only want to prevent certain balloons from being deleted, specifying “Default” will also show a warning.
- **Other**: The balloon can also set a “Recommended” relationship. For details, see [Writing a Balloon's descript.txt](../../balloon/index.md).
