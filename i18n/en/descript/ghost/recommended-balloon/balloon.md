# balloon,balloon name

**カテゴリ:** descript.txt - Recommended balloon

The name of the balloon used by default.<br />
\[SSP 2.9.35\] The balloon's [UUID](../../../list/propertysystem/property-system/general-property/uuid.md) can be specified instead of its name. The referenced balloon remains the same even if it is renamed or another balloon has the same name.

**既定値:** Unknown | The SSP balloon or the default balloon configured by the user (on SSP)

**対応:** Materia / SSP
