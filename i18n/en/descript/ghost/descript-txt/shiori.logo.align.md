# shiori.logo.align,Position information

**カテゴリ:** descript.txt

Specifies the reference point for the coordinates set by shiori.logo.x,y. Normally, this is the top left.<br />
You can specify top left (lefttop), bottom left (leftbottom), top right (righttop), or bottom right (rightbottom).

**既定値:** lefttop (top-left reference point)

**対応:** Materia deprecated specification / SSP
