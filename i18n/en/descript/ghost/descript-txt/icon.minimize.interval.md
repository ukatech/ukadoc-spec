# icon.minimize.interval,Playback interval

**カテゴリ:** descript.txt

The timing of the animation in the animated image displayed when minimized, as specified by [icon.minimize](icon.minimize.md).
The allowed values are the same as for [icon.interval](icon.interval.md). For example, playback can be stopped only while minimized (`never`).

**既定値:** No value (uses the loop count in the file)

**対応:** SSP 2.9.40
