# icon,File name

**カテゴリ:** descript.txt

The ghost's task tray icon.

In SSP, animated images (ANI, GIF, APNG, or WebP) and still images (such as PNG) can also be specified in addition to .ico. Animated images animate the task tray icon according to the frame delays and loop count in the file. Playback can be changed with [icon.interval](icon.interval.md). For details on file specification and animation, see [\![set,tasktrayicon]](../../../list/sakura-script/event/bang-set-tasktrayicon-.ico-duration-eq-runcount-eq.md). Other baseware can only read .ico files. \[SSP 2.9.40 and later\]

**既定値:** No value (SSP displays its standard icon)

**対応:** Materia / SSP / CROW
