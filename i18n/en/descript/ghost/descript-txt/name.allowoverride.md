# name.allowoverride,number

**カテゴリ:** descript.txt

Set to 0 to ignore names specified in the shell. This applies to the shell's `sakura.name` / `kero.name` / `char*.name` / `sakura.name2` / `sakura.friend.name`. The default is 1.<br />
The shell's `name` (shell name) is used regardless of this setting.

**既定値:** 1

**対応:** SSP
