# cursor,File name / mousecursor,File name

**カテゴリ:** descript.txt

Cursor (pointing hand) used over parts of the ghost that can be interacted with. The name mousecursor can be used starting with SSP 2.5.41.

**既定値:** Cursor set in the OS (pointing hand) (system:finger)

**対応:** Materia / SSP / CROW
