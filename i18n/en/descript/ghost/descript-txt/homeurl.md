# homeurl,URL

**カテゴリ:** descript.txt

URL for network updates.<br />
While the ghost is running, the SHIORI-side definition takes precedence. For updates from Explorer or calls via the property system, this setting takes precedence (to avoid the cost of loading SHIORI).<br />
Be sure to include a trailing / in the URL.

**既定値:** No value

**対応:** SSP
