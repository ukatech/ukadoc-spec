# icon.minimize,File name

**カテゴリ:** descript.txt

The ghost's icon when minimized.
An animated image can be specified in addition to .ico, as with [icon](icon.md). Playback can be changed with [icon.minimize.interval](icon.minimize.interval.md). \[SSP 2.9.40 and later\]
