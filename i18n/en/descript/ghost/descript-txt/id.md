# id,ID name

**カテゴリ:** descript.txt

ID name of the ghost. ASCII alphanumeric characters only. (SSP allows all characters.)<br />
At present, it is only used in displays such as the console shown at startup.<br />
In SSP, it is visible only when Settings - General - Enable transparent status display window is turned ON.

**既定値:** No value

**対応:** Materia / SSP / CROW
