# mouserightdown\*,hit region ID,file name

**カテゴリ:** cursor brace

Sets the cursor file to display when the right mouse button is pressed over a hit region.<br />
The \* must be a number not already used by another mouserightdown definition in the same scope.<br />
The hit region name is the name set in the collision definition.<br />
Specify a cursor file name (cur/ani) as the file name. Instead of a file name, you can use one of the system cursor specifications described below.

**既定値:** system:finger

**対応:** SSP 2.6.14
