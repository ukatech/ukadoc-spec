# mousewheel\*,hit region ID,file name

**カテゴリ:** cursor brace

Sets the cursor file to display when the mouse wheel is rotated over a hit region.<br />
The \* must be a number not already used by another mousewheel definition in the same scope.<br />
The hit region name is the name set in the collision definition.<br />
Specify a cursor file name (cur/ani) as the file name. Instead of a file name, you can use one of the system cursor specifications described below.

**既定値:** system:arrow

**対応:** SSP
