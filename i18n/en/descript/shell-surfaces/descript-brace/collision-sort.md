# collision-sort,sort order

**カテゴリ:** descript brace

Sorts hit regions by evaluation order. Determines the order in which they are displayed, from front to back.<br />
ascend sorts in ascending order (1,2,3...); descend sorts in descending order (10,9,8...)

**既定値:** none (the one written first is in front, regardless of ID)

**対応:** SSP
