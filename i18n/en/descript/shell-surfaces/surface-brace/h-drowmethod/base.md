# base

**カテゴリ:** surface brace \> Drawing method

Completely replaces the [base surface](../caption_basesurface.md) with the *new layer*. Collision information is also updated to match the one defined for the frame's surface.<br />
By stacking patterns using this method, an animation that redraws the entire surface (like a flipbook) can be created.<br />
For a pattern definition that specifies this drawing method, the XY coordinates are ignored.<br />
For dressups and elements, the base method can only be used first (element0, pattern0). In all other cases, it is interpreted as overlay.

**対応:** Materia / SSP / CROW
