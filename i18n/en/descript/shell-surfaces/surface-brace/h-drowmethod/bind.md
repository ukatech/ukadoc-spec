# bind

**カテゴリ:** surface brace \> Drawing method

Uses the *new layer* as a dressup part.<br />
This was the only method available when a dressup part could only be a simple overlay of a single surface; add is now its compatible equivalent.<br />
The processing is equivalent to [overlay](overlay.md).<br />
Use in non-dressup animations or elements is undefined.

**対応:** Materia / SSP
