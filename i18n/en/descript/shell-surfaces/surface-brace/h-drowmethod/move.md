# move

**カテゴリ:** surface brace \> Drawing Methods

Offsets the display position of the *base layer* by the specified coordinates from its original position.<br />
Changes to the display position using move are instantaneous, not continuous.<br />
The positive direction of the x-axis is right, and the positive direction of the y-axis is down.<br />
The surface ID is ignored in a pattern definition that specifies this drawing method.<br />
Cannot be used in dressup or elements.<br />
Note: The move behavior can be disabled in the user settings.

**対応:** Materia / SSP / CROW
