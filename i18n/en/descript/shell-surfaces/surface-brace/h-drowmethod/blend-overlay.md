# blend-overlay

**カテゴリ:** Surface Brace \> Drawing Method

Stack the *new layer* using overlay compositing.<br />
Equivalent to the Overlay layer blend mode in image-editing software such as Photoshop.<br />
It is unrelated to the [overlay](overlay.md) method; dark areas use multiply compositing, while light areas use screen compositing.<br />
Can also be used with dressup and element.<br />
It is recommended to set [`seriko.use_self_alpha,full`](../../../shell/descript-txt/seriko.use_self_alpha.md) in the shell's descript.txt.

**対応:** SSP 2.8.36
