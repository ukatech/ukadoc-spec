# blend-color-dodge-glow

**カテゴリ:** surface brace \> drawing method

Overlay the *new layer* using Color Dodge (Glow) blending.<br />
This corresponds to the Color Dodge (Glow) layer blending mode in image-editing software such as CLIP STUDIO PAINT (the processing is based on Color Dodge (Glow)).<br />
It can also be used with dressup and element.<br />
It is recommended to set [`seriko.use_self_alpha,full`](../../../shell/descript-txt/seriko.use_self_alpha.md) in the shell's descript.txt.

**対応:** SSP 2.8.46
