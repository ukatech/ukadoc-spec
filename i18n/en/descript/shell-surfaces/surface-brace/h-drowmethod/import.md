# import,file name,weight msec,X,Y

**カテゴリ:** surface brace \> Drawing methods

Import the specified APNG, animated GIF, or animated WebP so that it can be played with an initial wait time of weight msec and display position (X,Y).<br />
The imported animation is composited using the overlay method.<br />
This animation runs alongside and can coexist with existing animation definitions.<br />
Only frames and wait times are imported; the “number of repetitions” defined in the original file is ignored.

**対応:** SSP
