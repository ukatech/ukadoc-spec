# starttalk

**カテゴリ:** surface brace \> Animation interval

Runs when a talk event begins for the relevant scope.<br />
Specifically, it runs when text starts being spoken in a balloon. (This includes synchronized display using the `\_s` tag.)<br />
Note that in scripts where the scope switches frequently over a short period, the animation may not run because it cannot keep up.

**対応:** SSP 2.7.26
