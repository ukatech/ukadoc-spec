# kero.balloon.offsety,coordinates

**カテゴリ:** surface brace

The Y coordinate of the partner's balloon position for this surface only.<br />
For syntax that appends one character indicating direction (l / r / c / b), see [sakura.balloon.offsetx](sakura.balloon.offsetx.md).

**既定値:** When displayed on the left or right: position where the balloon's top edge aligns with the surface's top edge<br />
When displayed above the head: position where the balloon's bottom edge aligns with the surface's top edge<br />
When displayed at the feet: position where the balloon's top edge aligns with the surface's bottom edge

**対応:** Materia / SSP / CROW
