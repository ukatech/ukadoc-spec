# sakura.balloon.offsety,coordinate

**カテゴリ:** surface brace

The Y-coordinate of the main character's balloon position, only for this surface.<br />
For how to append a single direction character (l / r / c / b), see [sakura.balloon.offsetx](sakura.balloon.offsetx.md).

**既定値:** When displayed to the left or right: aligned with the top edge of the surface<br />
When displayed above: aligned with the top edge of the surface and the bottom edge of the balloon<br />
When displayed below: aligned with the bottom edge of the surface and the top edge of the balloon

**対応:** Materia / SSP / CROW
