# balloon.offsety, coordinates

**カテゴリ:** surface brace

The Y coordinate of the balloon position for this surface only (for either the main character or the partner).<br />
Can also be written as offset.y.<br />
For a format with a single direction character (l / r / c / b) appended, see [sakura.balloon.offsetx](sakura.balloon.offsetx.md).

**既定値:** When displayed to the left or right: a position where the top edge of the balloon aligns with the top edge of the surface<br />
When displayed above: a position where the bottom edge of the balloon aligns with the top edge of the surface<br />
When displayed below: a position where the top edge of the balloon aligns with the bottom edge of the surface

**対応:** SSP
