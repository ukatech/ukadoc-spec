# charset,character encoding

**カテゴリ:** surfaces.txt or surfaces\*\*.txt (SSP only)

The character encoding to use for display. Shift_JIS is recommended for compatibility with older environments; otherwise, UTF-8 is recommended.

When using SSP and providing multiple [surfaces\*\*\*.txt files](../introduction_surfaces.txt.md), you must configure each file separately (in other words, you can use different settings in each file).

**既定値:** (OS default or SSP -> Internationalization -> Default character encoding -> Text definitions)

**対応:** SSP / CROW
