# Relative path,ignore

**カテゴリ:** updates_def.txt

Specify options separated by commas for files specified by relative paths from the ghost's home folder.<br />
Per-folder specifications are not supported.<br />
If the ignore option is present, the target is excluded from the update targets when updates2.dau (updates.txt) is created.

**既定値:** No effect

**対応:** SSP
