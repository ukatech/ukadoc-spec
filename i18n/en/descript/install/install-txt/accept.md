# accept,Baseware-side name

**カテゴリ:** install.txt

The *baseware-side* name of a ghost that can receive archives (= the `\0` name, sakura name).<br />
Alternatively, the name set in the ghost's descript.txt [install.accept](../../ghost/descript-txt/install.accept.md) can also be used.<br />
This must always be used for content intended for a specific ghost, such as additional shells or additional files (supplements).

**既定値:** No behavior

**対応:** Materia / SSP / CROW
