# arrow.filename,filename

**カテゴリ:** balloons\*s.txt/balloonk\*s.txt/balloonc\*s.txt (individual setting)

Specifies the filename of the image used for the scroll arrows. The extension is not required.<br />
For example, if set to arrow, arrow0 (up) and arrow1 (down) are loaded automatically.

**既定値:** arrow / individual: arrows,arrowk,arrowp\*def

**対応:** SSP 2.5.51
