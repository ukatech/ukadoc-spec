# onlinemarker.filename,filename

**カテゴリ:** balloons\*s.txt/balloonk\*s.txt/balloonc\*s.txt (individual setting)

Specifies the filename of the image used to indicate online status. The extension is not required.<br />
For example, if set to online, images are loaded in the order online0, online1, online2, ... and animated while online.

**既定値:** online / individual: onlines,onlinek,onlinep\*def

**対応:** SSP 2.5.51
