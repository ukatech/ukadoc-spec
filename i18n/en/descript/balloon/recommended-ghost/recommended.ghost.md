# recommended.ghost,ghost name

**カテゴリ:** descript.txt - Recommended ghost

The name of the recommended ghost for use with this balloon. A strong warning is displayed if the balloon is used with another ghost.<br />
\[SSP 2.9.35\] The ghost's [UUID](../../../list/propertysystem/property-system/general-property/uuid.md) can be specified instead of its name. The warning is also determined by the specified UUID (in the list of recommended ghosts shown in the warning, entries specified by UUID are displayed by ghost name if found).

**既定値:** Not specified

**対応:** SSP 2.4
