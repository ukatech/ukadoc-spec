# metainfo,URL

**カテゴリ:** descript.txt

The URL of the metainfo folder containing the balloon's information. The format and meaning are the same as [metainfo in the ghost's descript.txt](../../ghost/descript-txt/metainfo.md).<br />
The value can be obtained through the property system's [metainfo](../../../list/propertysystem/property-system/general-property/metainfo.md).

**既定値:** No value

**対応:** SSP 2.9.35
