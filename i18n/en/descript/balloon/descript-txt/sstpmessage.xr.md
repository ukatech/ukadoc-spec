# sstpmessage.xr,coordinate [\*1](../index.md#balloon設定)

**カテゴリ:** descript.txt

X coordinate where the SSTP message display ends. Measured from the left. (If a negative value is specified, measured from the right.)<br />
Used only for horizontal writing ([vertical](vertical.md) is 0). For vertical writing, use [sstpmessage.yb](sstpmessage.yb.md).

**既定値:** unknown

**対応:** SSP
