# number.font.name,font name

**カテゴリ:** descript.txt

The font used for the counter number.<br />
A font file placed in the balloon's folder can also be specified as the font name (SSP only).<br />
Multiple font names can be specified, separated by commas. One is selected from the fonts installed automatically, in the order listed (SSP only).

**既定値:** MS Gothic

**対応:** Materia / SSP / CROW
