# cursor.blendmethod,command

**カテゴリ:** descript.txt

Raster operation command for the choice marker.<br />
none means no operation.<br />
notmaskpen means r2_notmaskpen.<br />
mergepennot means r2_mergepennot.<br />
SSP allows all operators supported by the Win32 API SetROP2 function (reference: [SetROP2 function (external site)](https://learn.microsoft.com/ja-jp/windows/win32/api/wingdi/nf-wingdi-setrop2))<br />
In this case too, specify the lowercase mode name without the "R2\_" prefix.

**既定値:** none

**対応:** Materia / SSP / CROW
