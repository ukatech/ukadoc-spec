# origin.y,coordinate [\*1](../index.md#balloon設定)

**カテゴリ:** descript.txt

The Y coordinate of the text start position.<br />
In vertical writing ([vertical](vertical.md) is 1), this is the starting position for character progression.<br />
This is usually left unspecified, allowing validrect to define it.

**既定値:** validrect.top

**対応:** Materia / SSP / CROW
