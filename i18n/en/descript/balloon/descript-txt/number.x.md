# number.x,coordinate [\*1](../index.md#balloon設定)

**カテゴリ:** descript.txt

The X coordinate of the counter number. Same as [number.xr](number.xr.md); this is an alias for specifying the position from the left.<br />
In horizontal writing ([vertical](vertical.md) is 0), this indicates the right edge of the number (that is, the edge toward which the number extends). In vertical writing, it indicates the position of the column containing the number; [number.yb](number.yb.md) determines the edge toward which the number extends.

**既定値:** Unknown

**対応:** SSP 2.8.83
