# sstpmessage.font.name,font name

**カテゴリ:** descript.txt

Font used for SSTP messages. The default is MS Gothic.<br />
You can also specify a font file placed in the balloon folder as the font name (SSP only).<br />
Multiple font names can be specified as a comma-separated list. The fonts are selected from those installed on the system in the order written, from highest to lowest priority (SSP only).

**既定値:** MS Gothic

**対応:** Materia / SSP / CROW
