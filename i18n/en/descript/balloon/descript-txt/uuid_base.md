# uuid_base,string

**カテゴリ:** descript.txt

A base string used to prevent UUID collisions. The format and meaning are the same as [uuid_base in the ghost's descript.txt](../../ghost/descript-txt/uuid_base.md).<br />
The value can be obtained through the property system's [uuid_base](../../../list/propertysystem/property-system/general-property/uuid_base.md).

**既定値:** No value

**対応:** SSP 2.9.35
