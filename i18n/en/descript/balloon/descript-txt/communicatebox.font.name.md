# communicatebox.font.name,font name

**カテゴリ:** descript.txt

Font used in the input box.<br />
A font file placed in the balloon folder can also be specified as the font name (SSP only).<br />
Multiple font names can be specified, separated by commas. They are selected from those installed automatically in the order listed, which determines priority (SSP only).

**既定値:** ＭＳ ゴシック

**対応:** SSP
