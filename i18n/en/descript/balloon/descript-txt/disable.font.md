# disable.font.(font definition),(value)

**カテゴリ:** descript.txt

Defines a light-colored text style to indicate that an operation is disabled. Use it with `\f[disable]` (or `\f[color,disable]`, etc.).<br />
For 「font definition」, you can define any of the definitions beginning with font. as-is. The definition method is the same.<br />
Example: disable.font.color

**既定値:** Only disable.font.color is a color mixed with the balloon's image color; the others are the same as the font. definitions.

**対応:** SSP 2.5.51
