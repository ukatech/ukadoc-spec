# number.yb,coordinate [\*1](../index.md#balloon設定)

**カテゴリ:** descript.txt

The Y coordinate of the counter number, measured from the bottom. Same as [number.y](number.y.md); this is an alias for explicitly specifying that, in vertical writing, the bottom edge is the reference point.

**既定値:** Unknown

**対応:** SSP 2.8.83
