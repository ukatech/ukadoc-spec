# anchor.blendmethod,command

**カテゴリ:** descript.txt

Raster operation command for anchors.<br />
none means no operation.<br />
notmaskpen means r2_notmaskpen.<br />
mergepennot means r2_mergepennot.<br />
SSP allows all operators available through the Win32API SetROP2 function (see: [SetROP2 function (external site)](https://learn.microsoft.com/ja-jp/windows/win32/api/wingdi/nf-wingdi-setrop2)).<br />
In this case as well, specify the lowercase mode name without the "R2\_" prefix.

**既定値:** none

**対応:** SSP
