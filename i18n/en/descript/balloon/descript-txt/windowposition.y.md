# windowposition.y,coordinate

**カテゴリ:** descript.txt

Adjusts the balloon's position along the y-axis from its default position.<br />
Specify a numeric value in pixels. Positive is down and negative is up.

The default position changes according to the windowposition.x setting:<br />
center,top……the bottom edge of the balloon meets the top edge of the shell image<br />
bottom……the top edge of the balloon meets the bottom edge of the shell image<br />
Numeric value……the top edges of the balloon and shell image overlap

Only in SSP, this can also be specified in descript.txt.

**既定値:** 0

**対応:** Materia / SSP / CROW
