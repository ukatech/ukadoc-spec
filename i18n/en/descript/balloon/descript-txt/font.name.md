# font.name,font name

**カテゴリ:** descript.txt

Font to use. The default is ＭＳ ゴシック.<br />
You can also specify a font file placed in the balloon's folder as the font name (SSP only).<br />
Multiple font names can be specified, separated by commas. They are selected from those installed automatically in the order listed (highest priority first) (SSP only).

**既定値:** ＭＳ ゴシック

**対応:** Materia / SSP / CROW
