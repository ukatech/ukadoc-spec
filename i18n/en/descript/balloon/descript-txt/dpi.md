# dpi,recommended DPI

**カテゴリ:** descript.txt

The recommended screen DPI value for this balloon. If not specified, it defaults to the fixed Windows standard of 96.<br />
Check Scale under System - Display in the Windows settings of the environment where the balloon was created, then select a value from the conversion table below.

- 100% - 96
- 125% - 120
- 150% - 144
- 175% - 168
- 200% - 192

Guideline: 144 (150%) for a 4K monitor, 120–144 (125–150%) for a recent laptop

**既定値:** 96

**対応:** SSP 2.7.21
