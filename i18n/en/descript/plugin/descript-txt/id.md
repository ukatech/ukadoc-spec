# id,ID

**カテゴリ:** descript.txt

A string that serves as the plugin's ID and is as unlikely as possible to duplicate.<br />
The string must consist only of single-byte characters and be no longer than 63 bytes. GUIDs/UUIDs are generally used.<br />
Once set, it must not be changed.<br />
Matching IDs indicate compatibility, even between plugins with different names.<br />
<br />
※Generation method: [http://www.famkruithof.net/uuid/uuidgen](http://www.famkruithof.net/uuid/uuidgen).<br />
Alternatively, if you have a reasonably complete development environment, the Registry Format in guidgen.exe can be used.<br />
A [tool](http://ssp.shillest.net/docs/guid.zip) is also available.

**既定値:** Cannot be omitted

**対応:** Materia / SSP / CROW
