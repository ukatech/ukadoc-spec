# surface\* brace 中可用的 ID 指定方式

以下写法可以组合使用，且都仅适用于 SSP。

- **枚举指定「,」**:

  ```
  surface1,3,4,6,12
  {
  // 略
  }
  ```

  通过使用「,」分隔并指定 ID，可以为多个 surface 定义相同的内容。

- **范围指定「-」**:

  ```
  surface1-12
  {
  // 略
  }
  ```

  通过使用「-」指定 ID，可以为编号连续的一系列 surface 定义相同的内容（本例中为从 surface1 到 12）。

- **范围指定的排除项「!」**:

  ```
  surface1-30,!15,!20-25
  {
  // 略
  }
  ```

  对于在「!」后指定的单个 ID 或范围，该定义会将其排除在适用对象之外（本例等同于指定 surface1-14,16-19,26-30 等）。<br />
  另外，无论「!」排除项写在什么位置，它的优先级都高于其他指定（例如，即使在 surface1-10,!2-4 后追加 3，3 仍会被排除）。

在 Materia 原本的规格中，只允许使用以下这种带有 surface 的枚举指定方式。

```
surface1,surface3,surface4
{
// 略
}
```
