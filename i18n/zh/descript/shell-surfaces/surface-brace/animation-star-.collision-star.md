# animation\*.collision\*, hit-test definition animation\*.collisionex\*, hit-test definition (ex)

**カテゴリ:** surface brace

Definitions that apply only while an ordinary [collision](collision-star.md) or [collisionex](collisionex-star.md) is animating. They also apply to interval binds.<br />
The \* following animation is the animationID (the same as the \* in animation\*.interval).<br />
The \* following collision is a number that must be unique within the set of animation\*.collision definitions.

**既定値:** No effect

**対応:** SSP
