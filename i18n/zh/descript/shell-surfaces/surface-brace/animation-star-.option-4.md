# animation\*.option, options

**カテゴリ:** surface brace

The exclusive, background, and shared-index options can be specified together, and multiple options can be listed separated by +. Example: exclusive+background<br />
The \* following animation is the animationID (the same as the \* in animation\*.interval).<br />
For example, animation\*.option,exclusive+background,(1,3,5) affects *only exclusive*.<br />
Note that the exclusive option is undefined for animations whose interval is a bind.

**既定値:** No effect

**対応:** SSP
