# balloon.offsety,坐标

**カテゴリ:** surface块

仅对此surface生效的balloon位置Y坐标（本体、搭档均适用）。<br />
也可以写作offset.y。<br />
关于在后面附加表示方向的单个字符(l / r / c / b)的写法，请参见[sakura.balloon.offsetx](sakura.balloon.offsetx.md)。

**既定値:** 显示在左右时：balloon的上边缘与surface的上边缘对齐的位置<br />
显示在头上时：balloon的下边缘与surface的上边缘对齐的位置<br />
显示在脚下时：balloon的上边缘与surface的下边缘对齐的位置

**対応:** SSP
