# mousedown\*,Collision ID,File name

**カテゴリ:** cursor braces

Set the cursor file to display when a mouse button is pressed over a collision region.<br />
The \* portion is a number that does not duplicate another mousedown definition in the same scope.<br />
The collision name is the name set in the collision definition.<br />
Specify a cursor file name (cur/ani) as the file name. Instead of a file name, you can use the system cursor specification described below.

**既定値:** system:finger (system:grip only when the collision name is bust)

**対応:** SSP
