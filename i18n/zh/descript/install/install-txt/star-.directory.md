# \*.directory,目录名

**カテゴリ:** install.txt

同时安装的内容在安装后的目录名。建议使用半角英数字。<br />
关于 \*部分的写法，以及同时附带多个相同种类内容时的编号方式，请参阅[「同时安装」](introduction_install_multi.md)。<br />
此处只能指定*单层目录名*，不能使用路径分隔符（会被替换为「\_」）。<br />
无论归档自身的 [type](type.md) 如何，都可以使用此功能；但实际使用时，通常用于 type 为*ghost*或*shell*的归档。

**既定値:** 无效果

**対応:** SSP
