# 相对路径,选项1,选项2,...

**カテゴリ:** developer_options.txt

对于以ghost主目录为基准、通过相对路径指定的文件或文件夹，可用逗号分隔指定选项。<br />
相对路径的层级使用「/」而不是「\\」分隔。<br />
指定文件夹时，请在末尾添加/。<br />
可以使用\*和?作为通配符（从SSP 2.5.17开始）<br />
选项如下。

- **nonar**: 创建nar时，不将此对象包含在nar中。
- **noupdate**: 创建updates2.dau（updates.txt）时，不将此对象列为更新对象。

<br />
请注意，这些选项都是在创建文件时进行控制，因此仅在*使用SSP或能够识别本文件的应用创建nar或更新文件时*有效。

**既定値:** 无行为

**対応:** SSP
