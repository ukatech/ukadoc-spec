# id,ID

**カテゴリ:** descript.txt

A string serving as the plugin's ID, chosen to minimize the possibility of duplication.<br />
The string must consist only of single-byte characters and be no longer than 63 bytes. Typically, use what is called a GUID/UUID.<br />
Once assigned, it must not be changed.<br />
Matching IDs indicate compatibility, even for plugins with different names.<br />
<br />
※Generation method: [http://www.famkruithof.net/uuid/uuidgen](http://www.famkruithof.net/uuid/uuidgen).<br />
Alternatively, if you have a reasonably complete development environment, the Registry Format of guidgen.exe can be used.<br />
A [tool](http://ssp.shillest.net/docs/guid.zip) is also available.

**既定値:** Required

**対応:** Materia / SSP / CROW
