# char\*.bindgroup\*.name,类别名,部件名,缩略图名

**カテゴリ:** descript.txt

为动画 ID 为 \* 的部件定义类别名和部件名。（第 3 人及之后）<br />
动画 ID 是 surfaces.txt 中动画定义“animation\*.interval,bind”的 \* 所对应的数字。<br />
要在 owner draw 菜单的 dressup 中显示，必须设置此项。<br />
使用 Sakura Script 的[`\![bind,类别名,部件名,数值]`](../../../list/sakura-script/surface/bang-bind.md)进行操作时也必须设置此项。（仅 SSP）

**既定値:** 无行为

**対応:** SSP
