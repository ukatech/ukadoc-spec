# seriko.dpi,推荐DPI

**カテゴリ:** descript.txt

此 shell 推荐的屏幕 DPI 值。如果未指定，则固定为 Windows 标准值 96。<br />
建议在创建 shell 的环境中，查看 Windows 设置的“系统-显示-缩放”，并根据下表选择对应的值。

- 100% - 96
- 125% - 120
- 150% - 144
- 175% - 168
- 200% - 192

参考：4K 显示器使用 144(150%)，较新的笔记本电脑使用 120-144(125-150%)

也可写在 ghost 侧的 descript.txt 中。如果 shell 侧已指定，则优先使用 shell 侧的值；否则使用 ghost 侧的值。

**既定値:** 96

**対応:** SSP 2.7.21
