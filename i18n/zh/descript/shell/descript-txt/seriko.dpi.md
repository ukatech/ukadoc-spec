# seriko.dpi,推荐DPI

**カテゴリ:** descript.txt

此 shell 推荐的屏幕 DPI 值。若未指定，则固定为 Windows 标准的 96。<br />
建议查看创建 shell 时所用环境的 Windows 设置中的“系统-显示-缩放”，并根据下表选择数值。

- 100% - 96
- 125% - 120
- 150% - 144
- 175% - 168
- 200% - 192

参考值：4K 显示器可设为 144(150%)，较新的笔记本电脑可设为 120-144(125-150%)

**既定値:** 96

**対応:** SSP 2.7.21
