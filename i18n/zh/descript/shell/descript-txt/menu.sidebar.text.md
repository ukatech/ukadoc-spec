# menu.sidebar.text,字符串

**カテゴリ:** descript.txt

owner draw 菜单侧边栏中显示的字符串。以从下往上阅读的方向（向左旋转 90 度）显示。<br />
如果有侧边栏图像（[menu.sidebar.bitmap.filename](menu.sidebar.bitmap.filename.md)），则使用图像，不显示此字符串。<br />
背景色由 [menu.sidebar.color](menu.sidebar.color.md) 指定，文字颜色由 [menu.sidebar.font.color](menu.sidebar.font.color.md) 指定。使用与菜单项相同的字体（[menu.font.name](menu.font.name.md) / [menu.font.height](menu.font.height.md)）。

也可以写在 ghost 的 descript.txt 中。如果 shell 中有此设置，则优先使用 shell 的值；否则使用 ghost 的值。

**既定値:** 无值

**対応:** SSP
