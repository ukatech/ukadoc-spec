# char\*.balloon.offsetx,坐标

**カテゴリ:** descript.txt

`\p[*]`的 balloon 位置的 X 坐标。`char0`与`sakura`、`char1`与`kero`的指定方式相同。<br />
坐标的含义以及在后面附加一个表示方向的字符（l / r / c / b）的写法，与[sakura.balloon.offsetx](sakura.balloon.offsetx.md)相同。

也可以写在 ghost 侧的 descript.txt 中。如果 shell 侧有此设置，则优先使用 shell 侧的值，否则使用 ghost 侧的值。

**既定値:** 无值

**対応:** SSP
