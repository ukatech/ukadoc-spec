# kero.icon.frame.color.r,数值

**カテゴリ:** descript.txt

搭档侧的图标（面部缩略图）显示在[日志（发言历史）窗口](../../../list/sakura-script/open/bang-open-backlogviewer.md)中时，边框颜色的红色分量(0～255)。[※注意](note-1.md#アイコン枠色の明度調整について)

也可写在 ghost 的 descript.txt 中。如果 shell 侧有设置，则优先使用 shell 侧的值；否则使用 ghost 侧的值。

**既定値:** 无值

**対応:** SSP 2.8.53
