# balloon.defaultsurface,数值

**カテゴリ:** descript.txt

balloon 的默认 surface 编号。所有角色共用。<br />
通过[sakura.balloon.defaultsurface](sakura.balloon.defaultsurface.md)、[kero.balloon.defaultsurface](kero.balloon.defaultsurface.md)、[char\*.balloon.defaultsurface](char-star-.balloon.defaultsurface.md)为各角色指定时，优先使用各角色的设置（无论是在 ghost 侧还是 shell 侧指定）。

也可以写在 ghost 侧的 descript.txt 中。如果 shell 侧有此设置，则优先使用 shell 侧的值，否则使用 ghost 侧的值。

**既定値:** 0

**対応:** SSP
