# menu.sidebar.font.color,颜色

**カテゴリ:** descript.txt

owner draw 菜单侧边栏中显示的文字（[menu.sidebar.text](menu.sidebar.text.md)）的颜色。<br />
颜色可以用颜色名（如 `red`）、`#RRGGBB` 或 `#RGB` 指定（`#` 可以省略）。<br />
也可以在 `menu.sidebar.font.color.r` / `menu.sidebar.font.color.g` / `menu.sidebar.font.color.b` 中填写 0～255 的数值，分别指定红、绿、蓝。

也可以写在 ghost 的 descript.txt 中。如果 shell 中有此设置，则优先使用 shell 的值；否则使用 ghost 的值。

**既定値:** 与 [menu.foreground.font.color](menu.foreground.font.color.r.md) 相同的颜色

**対応:** SSP
