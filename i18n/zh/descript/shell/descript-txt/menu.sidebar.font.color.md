# menu.sidebar.font.color,颜色

**カテゴリ:** descript.txt

owner draw 菜单侧边栏中显示的文字（[menu.sidebar.text](menu.sidebar.text.md)）的颜色。<br />
颜色可指定为颜色名称（如 `red`）、`#RRGGBB` 或 `#RGB`（可省略 `#`）。<br />
也可以在 `menu.sidebar.font.color.r` / `menu.sidebar.font.color.g` / `menu.sidebar.font.color.b` 中填写 0～255 的数值，分别指定红、绿、蓝分量。

也可写入 ghost 侧的 descript.txt。如果 shell 侧已指定，则优先使用 shell 侧的值；否则使用 ghost 侧的值。

**既定値:** 与 [menu.foreground.font.color](menu.foreground.font.color.r.md) 相同的颜色

**対応:** SSP
