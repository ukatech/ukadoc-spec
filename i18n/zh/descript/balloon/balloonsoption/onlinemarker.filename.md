# onlinemarker.filename,Filename

**カテゴリ:** balloons\*s.txt/balloonk\*s.txt/balloonc\*s.txt (individual setting)

Specifies the image filename for the online indicator. The extension is not needed.<br />
For example, setting this to online loads images in the order online0, online1, online2, … and displays them as an animation while online.

**既定値:** online / individual: onlines,onlinek,onlinep\*def

**対応:** SSP 2.5.51
