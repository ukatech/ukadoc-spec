# arrow.filename,Filename

**カテゴリ:** balloons\*s.txt/balloonk\*s.txt/balloonc\*s.txt (individual setting)

Specifies the image filename for the scrolling arrows. The extension is not needed.<br />
For example, setting this to arrow automatically loads arrow0 (up) and arrow1 (down).

**既定値:** arrow / individual: arrows,arrowk,arrowp\*def

**対応:** SSP 2.5.51
