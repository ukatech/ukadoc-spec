# cursor.blendmethod,Command

**カテゴリ:** descript.txt

Raster operation command for choice markers.<br />
none means none.<br />
notmaskpen means r2_notmaskpen.<br />
mergepennot means r2_mergepennot.<br />
Only in SSP, all operators usable with the Win32API SetROP2 function can be specified (reference: [SetROP2 function (external site)](https://learn.microsoft.com/ja-jp/windows/win32/api/wingdi/nf-wingdi-setrop2))<br />
In this case too, specify the mode name in lowercase without including "R2\_".

**既定値:** none

**対応:** Materia / SSP / CROW
