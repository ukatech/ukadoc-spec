# disable.font.(font definition),(value)

**カテゴリ:** descript.txt

Defines light-colored text to indicate that an operation is disabled. Used with `\f[disable]` (or `\f[color,disable]`, etc.).<br />
For 「font definition」, any definition beginning with font. can be specified as-is. The definition method is also the same.<br />
Example: disable.font.color

**既定値:** Only disable.font.color is mixed with the balloon's image color; the rest are the same as the font. definitions.

**対応:** SSP 2.5.51
