# origin.y,coordinate [\*1](../index.md#balloon設定)

**カテゴリ:** descript.txt

Y coordinate of the text start position.<br />
In vertical writing ([vertical](vertical.md) is 1, this indicates the starting position for character progression.<br />
This is usually left unspecified, with the position determined by the validrect definition.

**既定値:** validrect.top

**対応:** Materia / SSP / CROW
