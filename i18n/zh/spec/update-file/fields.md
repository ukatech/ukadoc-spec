# 字段详情

updates2.dau和updates.txt的 `file,` 行共用的字段定义。

- **必需字段**:

  - **文件路径 (位置\[0\])**: 更新目标文件的相对路径。使用斜杠 (`/`) 分隔。
  - **MD5哈希 (位置\[1\])**: 文件内容的MD5哈希。由32个十六进制字符组成。

- **扩展字段 (位置\[2\]以后)**: 使用 `key=value` 格式填写。均可省略。

  - **size=数值**: 文件大小（字节）。
  - **date=字符串**: ISO 8601格式的日期时间字符串。示例: `2024-01-15T12:34:56`
  - **charset=字符串**: 字符编码名称。仅附加在updates2.dau首个条目的末尾。仅用于判断字符编码，作为定义文件读取时会被忽略。
