# ListModules

**カテゴリ:** internal_system

返回内置模块的名称列表（也包括 `internal_system` 本身）。

- **参数**: 无

## 記述例

```
Argument0: ListModules

→ Result: internal_crypto,internal_random,internal_time,internal_data,internal_text,internal_jwt,internal_system,internal_file
→ Value0: internal_crypto
→ Value1: internal_random
…
```

**対応:** SSP 2.9.14
