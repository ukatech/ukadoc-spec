# internal_system

列出内置模块并说明函数的调用方式。可用于从脚本中确认哪些函数可用，以及可使用哪些选项或算法名称。<br />
列表中仅显示名称以`internal_`开头的模块（不包括[兼容模块](../compat.md)）。<br />
`ListModules` / `ListFunctions`的结果以逗号分隔放在`Result`中，并从`Value0`开始逐项放置。排列顺序没有意义。
