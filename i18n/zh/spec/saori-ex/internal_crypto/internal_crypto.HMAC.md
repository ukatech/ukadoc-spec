# HMAC

**カテゴリ:** internal_crypto

Calculate an HMAC.

- **Argument1**: algorithm name
- **Argument2**: key (default format is `text`)
- **Argument3**: data (default format is `text`; `file` can also be used)
- **Options**: `--key-in=` / `--data-in=` / `--out=` (default is `hex`) / `--charset=`

**対応:** SSP 2.9.13
