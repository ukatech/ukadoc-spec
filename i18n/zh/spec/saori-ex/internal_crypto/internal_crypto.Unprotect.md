# Unprotect

**カテゴリ:** internal_crypto

Restore data wrapped with [Protect](internal_crypto.Protect.md). If it cannot be restored, the result is 500 (`authentication failed`).

- **Argument1**: data (default format is `base64`)
- **Options**: `--data-in=` / `--out=` (default is `text`) / `--charset=`

**対応:** SSP 2.9.13
