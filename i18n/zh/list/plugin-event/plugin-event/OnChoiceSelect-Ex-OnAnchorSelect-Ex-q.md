# OnChoiceSelect(Ex)/OnAnchorSelect(Ex)/`\q`等指定的任意名称事件

**カテゴリ:** PLUGIN Event

在选择选项或锚点时发生的 SHIORI Event 的 plugin 侧钩子。<br />
当 plugin 发送给 ghost 的脚本，以及 ghost 对 plugin 通知的事件所回复的脚本中包含选项或锚点类的 Sakura Script 标签时，仅在该次选择选项或锚点时，plugin 侧也会收到转发通知，内容与通知给 SHIORI 侧的事件相同。

- **Reference\***: 已发生的选项或锚点类 SHIORI Event 的 Reference。

**対応:** SSP
