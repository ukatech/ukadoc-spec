# OnGhostBoot

**カテゴリ:** PLUGIN Event

ghost 启动时发生。

- **Reference0**: 以字节值1分隔，启动的 ghost 的`\0`之后各角色窗口的 HWND。<br />
  在窗口尚未创建等情况下，值可能为0。
- **Reference1**: 启动的 ghost 名称。
- **Reference2**: 启动的 ghost 当前的 shell 名称。
- **Reference3**: 启动的 ghost 的 ID（与 Owned SSTP 发送的相同）。
- **Reference4**: 启动的 ghost 的完整路径。

**対応:** SSP
