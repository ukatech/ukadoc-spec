# `\_a[OnID,r0,r1...]`

**カテゴリ:** 选项命令

将`\_a`之前的范围设为锚点。选项不会超时，但与普通对话一样会触发气球超时。<br />
如上所述，如果 ID 以“On”开头，点击时会触发 SHIORI 事件 OnID（即所写的事件）。<br />
ID 后的参数依次存入 Reference0 及之后的项目。

**対応:** SSP / Ninix

## 記述例

```sakurascript
\_a[OnHint,0]ヒント\_aが欲しいならクリックしよう。\_a[OnHint,1]ほらほら早く\_a。この2つのアンカーは、クリックするとSHIORIイベントOnHintが通知されるが、クリックしたものによってReference0の値が「0」か「1」に変わる。
```
