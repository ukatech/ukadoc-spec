# `\f[align,寄せる側]`

**カテゴリ:** 文字更改命令

设置文本右对齐(`\f[align,right]`)、居中对齐(`\f[align,center]`)或左对齐(`\f[align,left]`)。<br />
此设置会持续生效，直到遇到下一个`\n`或`\_l`等“有意换行”。<br />
此外，在添加文字等内容的过程中执行此命令时，同一行中已添加的文字也会移动。<br />
遇到`\_l`标签时，会恢复左对齐。<br />
此外，通过`\_l`标签移动后，再通过`\f[align]`标签设置居中对齐时，会假定已按`\_l`标签的 X 坐标进行缩进，并据此执行居中对齐。<br />
在竖排模式下，left＝上对齐、right＝下对齐、center＝垂直居中对齐。

**対応:** SSP 2.5.31

## 記述例

```sakurascript
\f[align,center]これは中央揃え。\n\f[align,right]これは右揃え。\n\f[align,left]左揃えのつもりが\w9\w9\f[align,right]右揃えに。
```
