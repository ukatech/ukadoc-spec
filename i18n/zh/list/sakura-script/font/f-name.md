# `\f[name,フォント名]`

**カテゴリ:** 文字更改命令

将文本字体更改为指定的字体名称。<br />
指定 default，或者指定的所有候选字体都不存在时，会恢复为 balloon 设置的默认值（如果 SSP 设置中覆盖了 balloon 字体，则恢复为该字体）。<br />
指定 disable 时，会设置为与无效显示相同的字体。<br />
字体名称也可以指定放置在\[已执行 ghost 的文件夹\]/ghost/master 下或当前 balloon 文件夹中的字体文件。<br />
可以用逗号分隔指定多个字体名称，程序会按书写顺序（优先级顺序）从已安装的字体中自动选择（仅限 SSP）。<br />

**対応:** SSP

## 記述例

```sakurascript
\f[name,メイリオ,meiryo.ttf]メイリオがインストール済みならメイリオ、そうでなければmeiryo.ttf、それもなければデフォルトフォントで表示される。
```
