# `\![open,help,ダイアログID]`

**カテゴリ:** 打开命令

打开SSP帮助。<br />
将对话框ID设为设置对话框的ID名称（※参见[OnConfigurationDialogHelp的Reference0](../../shiori-event/dialogbox/OnConfigurationDialogHelp.md)），即可展开该设置对话框的帮助。省略时打开索引页。

**対応:** SSP

## 記述例

```sakurascript
\![open,help,talk]ブラウザで、https://ukatech.shillest.net/ukadoc-ssp/の喋り/バルーンのページを開く。
```
