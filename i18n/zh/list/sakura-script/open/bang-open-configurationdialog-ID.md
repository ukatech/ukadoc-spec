# `\![open,configurationdialog,ダイアログID]`

**カテゴリ:** 开放命令

打开设置对话框（owner draw 菜单中的“baseware 设置”）。<br />
可以通过对话框 ID 指定初始显示的页面（省略时显示上次打开的页面）。<br />
请参阅 SHIORI Event ※[OnConfigurationDialogHelp](../../shiori-event/dialogbox/OnConfigurationDialogHelp.md) 的 Reference0。

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\![open,configurationdialog,talk]SSP本体設定ダイアログの喋り/バルーンのタブを開く。
```
