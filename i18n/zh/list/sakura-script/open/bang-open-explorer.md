# `\![open,explorer,ファイル]`

**カテゴリ:** 打开命令

打开baseware中设置的文件管理器，并附带指定文件。<br />
在owner draw菜单的baseware设置中，通过“外部应用程序 -> 文件管理器设置”指定。

如果没有指定文件管理器，指定的对象为文件夹时会打开该文件夹；为文件时则会在资源管理器中选中该文件。

指定为 `\![open,explorer,種類(ghost/shell/balloon/headline/plugin),名前]` 时，可以通过类型和名称指定要打开的文件夹。<br />
示例：`\![open,explorer,ghost,Emily/Phase4]`

**対応:** SSP 2.5.12
