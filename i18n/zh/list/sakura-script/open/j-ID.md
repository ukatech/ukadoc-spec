# `\j[ID]`

**カテゴリ:** Open 命令

跳转到 ID。<br />
使用 http://～ 跳转到 URL。<br />
使用 file:///～ 通过操作系统关联的扩展名打开文件。文件名可使用绝对路径，也可使用相对于\[执行该脚本的 ghost 文件夹\]/ghost/master 的路径。<br />
※仅限 SSP：使用 mailto:～ 创建发往该地址的新邮件

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\j[http://ssp.shillest.net/]ばぐとら研究所をブラウザを立ち上げて表示する。
```

```sakurascript
\j[file:///descript.txt][実行したゴーストのフォルダ]/ghost/masterフォルダにあるdescript.txtを開く。
```
