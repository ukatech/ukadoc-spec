# `\![quicksection,false]`

**カテゴリ:** Wait commands

End the quick section. `\![quicksection,0]` can also be used.<br />
This is almost equivalent to `\_q`, but differs in that it explicitly ends the section instead of using a switch.

**対応:** SSP / Ninix

## 記述例

```sakurascript
\![quicksection,1]文字を瞬間表示する。これもウェイトタグは実行される。\![quicksection,0]また、クイックセクションのさくらスクリプトは\![quicksection,1]混ぜて使っても有効。\_q
```
