# `\f[anchornotselectcolor,色指定]`或`\f[anchornotselectbrushcolor,色指定]`

**カテゴリ:** 选择标记更改命令

更改未选中锚点矩形内的颜色。请注意，颜色由`\f[anchornotselectmethod,描画方法]`的效果决定。<br />
关于指定方法，请参阅[※下文](note-1.md#形状指定の方法)。

**対応:** SSP

## 記述例

```sakurascript
\f[anchornotselectbrushcolor,red]\_a[OnTest]アンカー\_a非選択のアンカーの形状がsquareの場合、背景色が赤色になる。
```
