# `\![set,alignmentondesktop,bottomまたはtop]`

**カテゴリ:** Surface command

Attaches the current scope's surface to the specified edge of the desktop: bottom attaches it to the bottom of the desktop, and top to the top.

Effective until the ghost ends.

※See also alignment*to*desktop in SSP.

**対応:** Materia / SSP / CROW

## 記述例

```sakurascript
\![set,alignmentondesktop,bottom]本体側がデスクトップ下部(タスクバーの上)にくっつく。
```
