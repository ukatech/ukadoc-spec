# `\s[ID番号]`

**カテゴリ:** Surface commands

Change the surface of the current scope to the surface with the specified ID number.<br />
Use `\s[-1]` to display a hidden surface.<br />
A string defined by surface.alias or name in surfaces.txt can be used instead of an ID.

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\s[100]本体側にサーフェス100番を表示。
```
