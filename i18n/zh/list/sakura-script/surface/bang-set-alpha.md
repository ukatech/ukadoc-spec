# `\![set,alpha,数値,オプション]`

**カテゴリ:** surface 命令

将当前 scope 一侧的 surface 透明度设为0～100。0表示完全透明，100表示不透明。超过100的值会被限制为100。负值只会重新绘制，不会更改数值。<br />
可通过选项指定动画时长，或等待动画完成。<br />
在 ghost 结束前有效。

- --time=毫秒……动画时长（毫秒）。省略时或取负值时为0（立即生效）。也可作为位置参数指定（为保持向后兼容）。
- --wait……等待动画完成后再继续执行脚本。省略时为异步执行（立即进行下一项处理）。适用于 SSP 2.7.52 及更高版本。

**対応:** SSP

## 記述例

```sakurascript
\0\![set,alpha,0]本体側が透明になり見えなくなる。\1\![set,alpha,50]相方側がだいたい半透明になる。
```

```sakurascript
\![set,alpha,50,--time=1000]1秒かけて透過度50へ変化する（非同期）。
```

```sakurascript
\![set,alpha,50,--time=2000,--wait]2秒かけて透過度50へ変化する（完了まで待機）。
```

```sakurascript
\![set,alpha,100,--time=1000,--wait]1秒かけて不透明に戻す（完了まで待機）。
```
