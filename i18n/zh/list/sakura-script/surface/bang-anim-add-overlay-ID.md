# `\![anim,add,overlay,ID]`

**カテゴリ:** Surface command

Overlay the surface with the specified ID onto the current surface.

- **`\![anim,add,overlay,ID]`**: Overlay the surface with the specified ID onto the current surface.
- **`\![anim,add,overlayfast,ID]`**: Overlay the surface with the specified ID onto the current surface using overlayfast.
- **`\![anim,add,base,ID]`**: Change the current base surface to the surface with the specified ID.
- **`\![anim,add,move,x,y]`**: Move and display the current surface at the XY coordinates.
- **`\![anim,add,overlay,ID,x,y]`**: Move the surface with the specified ID to the XY coordinates and overlay it onto the current surface.
- **`\![anim,add,overlay,ID,x,y,表示時間,ID,x,y,表示時間,ID,x,y,表示時間...]`**: Animate the overlaid surfaces. (Time is in ms)
- **`\![anim,add,overlay,ID,x,y,表示時間,ID,x,y,表示時間,ID,x,y,表示時間,アニメーションタイミング]`**: The animation timing can be set to runonce or always.

**対応:** CROW
