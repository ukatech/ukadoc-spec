# `\![anim,add,overlay,ID]`

**カテゴリ:** 表面命令

将ID编号的表面叠加到当前表面上。

- **`\![anim,add,overlay,ID]`**: 将ID编号的表面叠加到当前表面上。
- **`\![anim,add,overlayfast,ID]`**: 使用overlayfast将ID编号的表面叠加到当前表面上。
- **`\![anim,add,base,ID]`**: 将当前基础表面更改为ID编号的表面。
- **`\![anim,add,move,x,y]`**: 将当前表面移动到XY坐标并显示。
- **`\![anim,add,overlay,ID,x,y]`**: 将ID编号的表面移动到XY坐标并叠加到当前表面上。
- **`\![anim,add,overlay,ID,x,y,表示時間,ID,x,y,表示時間,ID,x,y,表示時間...]`**: 对叠加的表面进行动画播放。（时间单位为ms）
- **`\![anim,add,overlay,ID,x,y,表示時間,ID,x,y,表示時間,ID,x,y,表示時間,アニメーションタイミング]`**: 动画时机可以指定为runonce或always。

**対応:** CROW
