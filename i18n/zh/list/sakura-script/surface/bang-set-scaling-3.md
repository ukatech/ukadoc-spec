# `\![set,scaling,横倍率,縦倍率,オプション]`

**カテゴリ:** surface 命令

精细调整 surface 的缩放倍率。倍率单位为%。<br />
可通过选项指定动画时长，或等待动画完成。

- --time=毫秒……动画时长（毫秒）。省略时或取负值时为0（立即生效）。也可作为位置参数指定（为保持向后兼容）。
- --wait……等待动画完成后再继续执行脚本。省略时为异步执行（立即进行下一项处理）。适用于 SSP 2.7.52 及更高版本。

**対応:** CROW / SSP 2.7.31

## 記述例

```sakurascript
\![set,scaling,200,200,--time=2000]2秒かけて200%へ変化する（非同期）。
```

```sakurascript
\![set,scaling,200,200,--time=3000,--wait]3秒かけて200%へ変化する（完了まで待機）。
```

```sakurascript
\![set,scaling,100,100,--time=1000,--wait]1秒かけて等倍に戻す（完了まで待機）。
```
