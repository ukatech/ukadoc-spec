# Sakura Script 的转义

- 如果想显示“\\”而不是将其作为 Sakura Script 的起始符号，请写作“\\\\”
- 同样，环境变量嵌入标签中的“%”请写作“\\%”
- 仅在方括号内带参数的标签（例如 `\q[ラベル名,ID]`）中，“\]”可以写作“\\\]”。
- 对于方括号内带多个参数的标签，如果要在第二个及之后的参数中将“,”作为参数内容，可以将该参数整体用""括起，从而将整体作为一个参数处理。<br />
  例：`\![raise,OnTest,"100,2"]`
- 同样，如果要将“"”作为参数内容，请将该参数整体用""括起，并将"加倍。<br />
  例：`\![call,ghost,"the ""MobileMaster"""]`
