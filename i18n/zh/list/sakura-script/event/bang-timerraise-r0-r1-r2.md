# `\![timerraise,時間,繰り返すか否か,イベント名,r0,r1,r2...]`

**カテゴリ:** 事件命令

指定「时间」的等待时间（毫秒）后执行事件。<br />
「是否重复」指定为0时，每隔指定时间重复触发事件；指定为1以上时，只触发一次。<br />
第5个及之后的参数为reference。<br />
不同名称的事件可以分别执行，但对同名事件重复执行时会被覆盖。<br />
执行同一事件名且时间为0的Sakura Script即可取消。<br />
计时器在网络更新后也会保留。

「是否重复」为0时，计时器会持续有效，直到指定事件触发。「是否重复」为1以上时，计时器会持续有效，直到ghost结束。

**対応:** SSP

## 記述例

```sakurascript
\![timerraise,5000,1,OnTimerraiseTest,test]5秒後(5000ミリ秒)後に、OnTimerraiseTestが発生する。さくらスクリプトが実行された瞬間から時間をカウントする。\![timerraise,0,1,OnTimerraiseTest]ここで先ほどのタイマー予約をキャンセル。
```
