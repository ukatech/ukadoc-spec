# `\![change,calendarskin,カレンダースキン名]`

**カテゴリ:** 事件命令

切换日历 skin。其效果与从日历菜单中选择 skin 相同。<br />
如果没有对应的日历 skin，则忽略此命令。<br />
如果从未打开过日历，则只更改设置；下次打开日历时才会生效。

将日历 skin 名称设为 lastinstalled 时，会切换到最后安装的日历 skin。但如果 SSP 曾经退出，则此功能无效。<br />
将日历 skin 名称设为 random 时，会随机切换。<br />
日历 skin 名称通过[installedcalendarskinname](../../shiori-event/notify/installedcalendarskinname.md)通知。

**対応:** SSP 2.8.93
