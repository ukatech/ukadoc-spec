# `\_+`

**カテゴリ:** 事件命令

切换到下一个顺序的 ghost（顺序切换）。切换到 ghost 浏览器中位于当前 ghost 下方的 ghost。<br />
如果当前 ghost 位于列表末尾，则切换到列表开头的 ghost。<br />
通过此脚本切换时，不会通知 SHIORI 事件[OnGhostChanging](../../shiori-event/boot-close-change/OnGhostChanging.md)。

**対応:** Materia / SSP / Ninix

## 記述例

```sakurascript
リストの次のゴーストへチェンジ。\_+
```
