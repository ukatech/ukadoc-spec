# `\![vanishbymyself]`

**カテゴリ:** 事件命令

不显示卸载指示，直接卸载自己的ghost。<br />
请注意，执行时不会显示确认对话框等，而是立即执行。<br />
是否执行删除取决于用户一侧的SSP设置。

SSP中可以指定以下选项<br />
`\![vanishbymyself,ゴースト名]` 指定删除后要切换到的ghost（如果找不到，SSP会自动选择适当的ghost）<br />
`\![vanishbymyself,--option=query]` 2.5.82 : 显示删除确认对话框。与从菜单执行时相同。

**対応:** Materia / SSP / Ninix

## 記述例

```
自分自身を削除。Send Boxからのサンプル入力での実行時は要注意。\![vanishbymyself]
```
