# `\_l[x,y]`

**カテゴリ:** 气球、文本命令

将当前scope侧的光标位置移动到XY坐标。X、Y可按以下方式指定。<br />
请注意，执行`\_l`后，为避免问题，行对齐会重置为左对齐。必要时请重新指定。

- **数值**: 从气球文字绘制起点（[origin](../../../descript/balloon/descript-txt/origin.x.md)的位置；横排时为文字绘制区域的左上角）开始计算的像素坐标
- **(省略)**: 不移动。X、Y都省略时无效果。
- **centerx / centery**: X写作centerx、Y写作centery时，移动到气球图像的中央（宽度／高度的一半）。只有此项以气球图像本身为基准，而非文字绘制起点。
- **XXem**: 在后面加上em，即可按文字高度指定坐标。1em＝写入标签时的文字高度。可指定小数。
- **XXlh**: 在后面加上lh，即可按行高指定坐标。1lh＝1em＋行间距。可指定小数。
- **XX%**: 在后面加上%，即可按文字高度指定坐标。100%＝写入标签时的文字高度。可指定小数。
- **@XX**: 指定相对于当前文字绘制位置的坐标。X为负值时向左，Y为负值时向上。可与em或%指定方式并用。

即使在[竖排气球](../../../descript/balloon/descript-txt/vertical.md)中，坐标轴也与气球图像本身一致，X向右、Y向下为正。<br />
但是，文字绘制起点会变为文字绘制区域的*右上角*，文字列从那里向左延伸，因此要移至下一列，必须为X指定负值。Y是文字排列方向（从上到下），用法与横排相同。<br />
例如，`\_l[@-1lh,0]`表示“移至左侧一列的开头”（相当于横排时的`\_l[0,@1lh]`），`\_l[,@1em]`表示“向文字排列方向前进一个字符”。

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\_l[30,5em]「座標X=30pixel、座標Y=5文字分高さ」に表示。\_l[@-1650%,100]「座標X=最後の文字から文字高さ1650%分左、座標Y=100pixel」に表示。\_l[,@-100]「座標X=変更なし、座標Y=最後の文字から100pixel上」に表示。
```
