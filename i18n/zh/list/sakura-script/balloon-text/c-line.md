# `\c[line,数値]`

**カテゴリ:** 气球、文本命令

清除当前作用域一侧，从气球光标位置开始的指定行数。<br />
将对话用`\_l[x,y]`,`\n`,`\n[half]`,`\n[パーセント]`分割后得到的内容视为“行”。不过，`\n\n`等由`\_l[x,y]`以外的方式分割出的空内容不视为行。<br />
与`\c[char,数値]`一样，按照脚本中的出现顺序进行引用。

**対応:** SSP

## 記述例

```sakurascript
トークを1行削除。\nこの行が削除される。\c[line,1]削除終了。\nこの行は削除される。\n\n\n\n\n\c[line,1]削除終了。\nこの行は削除されない。\_l[0,0]\c[line,1]削除終了。
```
