# `\![set,balloonwait,倍率]`

**カテゴリ:** 气球、文本命令

指定气球中字符串逐字显示的速度（每个字符的等待时间）的倍率。<br />
仅指定数值：可指定 0～100。1 表示原速。可以指定小数。例如：指定 1.5 时，显示速度慢 50%。<br />
数值后加％：可指定 0～10000。100 表示原速。只能指定大于等于 0 的整数。<br />
数值后加 ms：可指定 0～10000，以毫秒为单位绝对指定每个字符的等待时间。

省略参数或指定为 1：恢复默认值<br />
指定为 0：始终立即显示

脚本执行结束后会重置为相当于指定 100% 的状态。

**対応:** SSP
