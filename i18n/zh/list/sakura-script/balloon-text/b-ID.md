# `\b[ID番号]`

**カテゴリ:** 气球、文本命令

将当前scope侧的气球切换为指定ID的气球。<br />
奇数ID保留给显示在角色右侧的气球，因此只能使用0或偶数ID。<br />
使用`\b[-1]`可隐藏气球。

从SSP 2.6.34起，写作 `\b[ID1,--fallback=ID2,--fallback=ID3]` 时，若ID1不存在则使用ID2，若ID2也不存在则使用ID3。

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\b[2]本体側のトークをバルーン2番に表示する。バルーンによって実装状況は異なり、バルーン2番が存在しない場合もある。SSP同梱バルーン「SSPデフォルト+」では、本体側バルーン2番は表示文字数の多い大きなバルーンとなるが、サイズの決まりはないため、これを使う際は推奨バルーンを指定する・専用バルーンを同梱するなどが必要。
```
