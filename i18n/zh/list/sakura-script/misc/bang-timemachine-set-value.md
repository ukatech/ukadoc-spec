# `\![timemachine,set,値]`

**カテゴリ:** 未分类命令

将“当前时间的虚拟更改”（时间机器）的偏移量设为指定值。ghost 看到的当前时间（`system.year` 等属性、[OnSecondChange](../../shiori-event/time/OnSecondChange.md) 等时间事件、日历日程等）会发生偏移。用于测试依赖日期或时间的 ghost。<br />
仅在启动 SSP 时附带 `--allow-timemachine-control` 才有效。未附带时不执行任何操作，并在错误日志中记录警告（防止 ghost 的脚本改变全局时钟）。无法从未经授权的 SSTP（外部 SSTP）执行。<br />
偏移量仅在本次运行期间有效，不会保存到设置中。该命令将偏移量设为指定值，而不是在当前偏移量上累加（多次执行相同指令的结果相同）。

- **值**: 指定偏移量，可使用以下任一格式。如果省略值或无法解析，则在错误日志中记录警告，不执行任何操作。
  - `+秒` / `-秒`: 偏移量本身（秒数），必须带符号。例如：`+86400`（提前 1 天）、`-3600`（推迟 1 小时）
  - `0`: 将偏移量设为 0（保持实际时间）
  - ISO8601 格式的日期时间：计算该日期时间与实际时间的差值，并将其设为偏移量。如果未指定时区，则视为本地时间。时钟不会停止，而是从该日期时间继续前进。例如：`2026-12-31T23:59:50`

偏移量的绝对值最大约为 200 年。不足一秒的部分会被舍弃。<br />
跳转时间时，如果跳转后的分钟或小时与跳转前不同，下一次按秒处理时会触发 [OnMinuteChange](../../shiori-event/time/OnMinuteChange.md) 或 [OnHourTimeSignal](../../shiori-event/time/OnHourTimeSignal.md) 等事件（向过去跳转时也一样）。<br />
自动更新等的间隔计量、日志和通信等使用实际时间的功能不受影响。

!!! note "注"
    也可以通过启动选项 `--time-shift` 指定启动时的偏移量。当前偏移量可通过属性 `system.os.timeshift` 读取。<br />
    如果希望不通过 ghost 脚本而同步设置，请使用 SSTP 的 EXECUTE 方法中的 [SetTimeShift](../../../spec/sstp/method_execute.md)（需要相同格式的值和相同的启动选项）。

**対応:** SSP 2.9.39

## 記述例

```sakurascript
\![timemachine,set,2026-12-31T23:59:50]
```

将时间设为 2026 年 12 月 31 日 23 时 59 分 50 秒，并让时钟从该时间继续前进。可用于测试跨年事件等。

```sakurascript
\![timemachine,set,+86400]
```

将时间设为实际时间的 1 天后。
