# RSS筛选选项 \[2.8.92\]

在[`\![execute,rss-get/rss-post]`](bang-execute-rss-get-URL.md)中，用于指定从获取的 feed 中返回哪些项目的选项。<br />
格式与[iCal筛选选项](bang-execute-ical-post-URL.note.md)相同，但省略时的处理方式不同。--expand 会被忽略。

如果全部省略，则返回所有项目。

- **期间（--from・--to）**: --from=yyyymmdd 返回具有该日期 0 时 0 分 0 秒之后的更新时间的项目，--to=yyyymmdd 返回具有该日期结束之前（含该日）的更新时间的项目。日期根据执行环境的本地日期判断。<br />
  省略的一侧不设限制（不会像 iCal 那样从当天开始）。如果写入不存在的日期，则按省略处理。如果 --to 早于 --from，则不返回任何项目。<br />
  如果指定了 --from 或 --to，便不会返回不具有（或无法解析）更新时间的项目。
- **数量上限（--limit）**: 只有指定时，才会在达到该数量时停止。--limit=0 表示不限制。<br />
  与 iCal 不同，没有默认上限（200 项）；仅指定 --limit 不会筛选期间。<br />
  项目按更新时间从新到旧排序，因此 --limit=5 会返回最新的 5 项（如果 feed 中的项目都没有更新时间，则返回 feed 中列出的前 5 项）。
