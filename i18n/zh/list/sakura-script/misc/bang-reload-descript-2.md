# `\![reload,descript,パラメータ]`

**カテゴリ:** 未分類命令

重新加载指定的 descript.txt。<br />
可以用半角空格分隔指定多个项目。<br />
ghost shell balloon headline plugin language calendar.skin calendar.plugin

calendar.skin是日历皮肤，calendar.plugin是日程传感器（与[install.txt的type](../../../descript/install/install-txt/type.md)相同分类）。<br />
也接受与install.txt相同的“calendar skin”“calendar plugin”写法，但由于参数以半角空格分隔，建议使用带点号的写法。

**対応:** SSP

## 記述例

```sakurascript
\![reload,descript,shell balloon]シェルとバルーンのdescript.txtをリロードする。
```
