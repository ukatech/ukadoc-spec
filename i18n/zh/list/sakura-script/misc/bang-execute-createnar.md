# `\![execute,createnar,出力先ファイル]`

**カテゴリ:** Uncategorized command

Creates a NAR of the ghost that executed the script.<br />
Output file: Optional. Specify a path relative to the ghost's ghost/master folder, or an absolute path. \[2.8.98\]<br />
If specified, the NAR is created at that path without prompting for confirmation. If a file with the same name already exists, it is overwritten. If the output file is inside the ghost's folder, that file itself is not included in the NAR.

**対応:** SSP 2.5.08
