# `\![execute,rss-post,URL,オプション,オプション,オプション...]`

**カテゴリ:** Unclassified commands

Send an http post request with [※options](bang-execute-http-options-URL.note.md), parse the response as an RSS/Atom feed, and then notify the parsing results as events.<br />
The parsing, notification, and [filtering](bang-execute-rss-post-URL.note.md) specifications are the same as for [rss-get](bang-execute-rss-get-URL.md). Specify the parameters in the same way as for http-post.

**対応:** SSP
