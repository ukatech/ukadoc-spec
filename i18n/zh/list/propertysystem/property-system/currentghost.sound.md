# currentghost.sound(元素名).サウンド属性名

**カテゴリ:** プロパティシステム

从当前 ghost 管理的媒体中，获取元素名匹配的最新媒体的信息。<br />
元素名即通过`\![sound,play,～]`等指定的文件名/路径/URL。<br />
请注意，括号直接跟在属性名后面，中间不加点号（`currentghost.sound(～)`，而不是`currentghost.sound.(～)`）。<br />
サウンド属性名参见[后文](sound-property/sound.name.md)。关于可写入的属性及相关注意事项，请参见[此处](sound-property/sound.pause.note.md)。

**対応:** SSP 2.8.72
