# currentghost.sound(element name).sound property name

**カテゴリ:** Property System

Gets information from the most recently opened media managed by the current ghost whose element name matches.<br />
The element name is the file name/path/URL itself specified with `\![sound,play,～]` and similar tags.<br />
Note that the parentheses immediately follow without an intervening dot (`currentghost.sound(～)`, not `currentghost.sound.(～)`).<br />
See [below](sound-property/sound.name.md) for sound property names. See [here](sound-property/sound.pause.note.md) for writable properties and notes on writing to them.

**対応:** SSP 2.8.72
