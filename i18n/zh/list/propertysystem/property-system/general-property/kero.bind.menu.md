# kero.bind.menu

**カテゴリ:** Property system \> General property names

(Valid only for currentghost) Visibility of items in the dressup menu for the target shell's partner scope.<br />
hidden when set to hidden, auto in automatic enumeration mode, or none otherwise<br />
*\[SET enabled\]*Default value is [kero\*.menu](../../../../descript/shell/descript-txt/kero.menu.md) in the shell's descript.txt
