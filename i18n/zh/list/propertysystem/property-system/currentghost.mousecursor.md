# currentghost.mousecursor

**カテゴリ:** 属性系统

表示ghost可操作区域的光标文件名（指针）<br />
以下以currentghost.mousecursor / currentghost.balloon.mousecursor开头的属性均适用：<br />
相对路径依次在shell和ghost文件夹中查找。<br />
将空字符串指定为SET值时，会删除定义，并恢复为设置前的显示状态。<br />
光标可以使用与[surfaces.txt的cursor段](../../../descript/shell-surfaces/cursor-brace/introduction_cursorbrace.md)相同的指定方式。<br />
*\[SET有效\]*

**対応:** SSP \[2.6.11\]
