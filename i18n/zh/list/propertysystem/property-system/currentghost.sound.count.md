# currentghost.sound.count

**カテゴリ:** Property System

The number of media managed by the current ghost.<br />
This includes everything opened with `\![sound,play]`, `\![sound,loop]`, `\![sound,preload]`, and similar tags that has not yet been closed. Note that this is not limited to media currently playing.<br />
Whether individual media is playing can be determined with [playing](sound-property/sound.playing.md).

**対応:** SSP 2.8.72
