# currentghost.sound.index(ID).sound property name

**カテゴリ:** Property System

Gets information from the media at position ID among the media managed by the current ghost.<br />
IDs are assigned starting from 0 to newly opened media, in order. The request fails if the specified ID is out of range.<br />
See [below](sound-property/sound.name.md) for sound property names. See [here](sound-property/sound.pause.note.md) for writable properties and notes on writing to them.

**対応:** SSP 2.8.72
