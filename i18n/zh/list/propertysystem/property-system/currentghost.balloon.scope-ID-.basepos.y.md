# currentghost.balloon.scope(ID).basepos.y

**カテゴリ:** プロパティシステム

当前 balloon 的文字绘制起始点（Y 坐标）。不一定是绘制区域的上端。坐标原点为 balloon 图像的左上角。<br />
[纵排](../../../descript/balloon/descript-txt/vertical.md)时，表示字距推进的起始位置（第 1 个字符的上端，即 [origin.y](../../../descript/balloon/descript-txt/origin.y.md)）。

**対応:** SSP (2.3.72)
