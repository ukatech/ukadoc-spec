# OnWeatherStation.Alerts

**カテゴリ:** plugin“Weather Station”

向所有运行中的ghost发送天气警报信息。必须使用`\![raiseplugin]`调用。如果没有警报则不返回任何内容。

- **Reference\***: 包含一条天气警报信息的数组。部分元素可能为空。元素以1字节的值分隔。

  - \[0\] - 标题
  - \[1\] - 警报类型
  - \[2\] - 严重程度
  - \[3\] - 紧急程度
  - \[4\] - 涉及地区
  - \[5\] - 类别
  - \[6\] - 确定性
  - \[7\] - 事件
  - \[8\] - 备注
  - \[9\] - 生效时间
  - \[10\] - 失效时间
  - \[11\] - 描述
  - \[12\] - 指示事项
