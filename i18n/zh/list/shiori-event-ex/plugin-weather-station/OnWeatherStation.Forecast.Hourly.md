# OnWeatherStation.Forecast.Hourly

**カテゴリ:** 插件「Weather Station」

将一天内逐小时预报的相关信息发送给所有正在运行的 ghost。必须使用 `\![raiseplugin]` 调用。可以通过附加参数指定发送哪一天的数据。0表示今天，1表示明天，2表示后天。未提供参数时默认为今天。

- **Reference0～23**: 包含预报信息的逗号分隔数组。Reference编号对应数据所对应的时间（24小时制）（例如：reference0对应00:00/上午12点，reference14对应14:00/下午2点）。
  - \[0\] - 信息所对应的日期和时间。
  - \[1\] - “是否为白天”。太阳升起时为1，落下时为0。
  - \[2\] - 气温（华氏度）。
  - \[3\] - 气温（摄氏度）。
  - \[4\] - “体感”温度（华氏度）。
  - \[5\] - “体感”温度（摄氏度）。
  - \[6\] - 湿度（百分比）。
  - \[7\] - 风速（英里/小时）。
  - \[8\] - 风速（公里/小时）。
  - \[9\] - 风向（16方位。例如：NNW表示西北偏北）。
  - \[10\] - 风向（度）。
  - \[11\] - 阵风风速（英里/小时）。
  - \[12\] - 阵风风速（公里/小时）。
  - \[13\] - 降水量（英寸）。
  - \[14\] - 降水量（毫米）。
  - \[15\] - 云量（百分比）。
  - \[16\] - “是否下雨”。下雨时为1，不下雨时为0。
  - \[17\] - 下雨的概率（百分比）。
  - \[18\] - “是否下雪”。下雪时为1，不下雪时为0。
  - \[19\] - 下雪的概率（百分比）。
  - \[20\] - 能见度（英里）。
  - \[21\] - 能见度（公里）。
  - \[22\] - 风寒指数（华氏度）。
  - \[23\] - 风寒指数（摄氏度）。
  - \[24\] - 热指数（华氏度）。
  - \[25\] - 热指数（摄氏度）。
  - \[26\] - 露点（华氏度）。
  - \[27\] - 露点（摄氏度）。
  - \[28\] - 气压（英寸）。
  - \[29\] - 气压（毫巴）。
  - \[30\] - UV指数。
- **Reference24**: 上述信息所对应的日期。0表示今天，1表示明天，2表示后天。
