# OnWeatherStation.Forecast.Hourly

**カテゴリ:** plugin“Weather Station”

向所有运行中的 ghost 发送某一天逐小时的天气预报信息。必须通过 `\![raiseplugin]` 调用。可以通过额外参数指定发送哪一天的数据。0 表示今天，1 表示明天，2 表示后天。如果没有参数，则默认为今天。

- **Reference0～23**: 包含预报信息的逗号分隔数组。Reference 的编号对应数据所针对的小时数（24 小时制）（例：reference0 对应 00:00/上午 12 点，reference14 对应 14:00/下午 2 点）。
  - \[0\] - 信息对应的日期和时间。
  - \[1\] - “是否为白天”。太阳升起时为 1，落下时为 0。
  - \[2\] - 气温（华氏度）。
  - \[3\] - 气温（摄氏度）。
  - \[4\] - “体感”温度（华氏度）。
  - \[5\] - “体感”温度（摄氏度）。
  - \[6\] - 湿度（百分比）。
  - \[7\] - 风速（英里每小时）。
  - \[8\] - 风速（千米每小时）。
  - \[9\] - 风向（16 方位。例：NNW 表示北西北）。
  - \[10\] - 风向（度）。
  - \[11\] - 阵风风速（英里每小时）。
  - \[12\] - 阵风风速（千米每小时）。
  - \[13\] - 降水量（英寸）。
  - \[14\] - 降水量（毫米）。
  - \[15\] - 云量（百分比）。
  - \[16\] - “是否会下雨”。会则为 1，不会则为 0。
  - \[17\] - 下雨的概率（百分比）。
  - \[18\] - “是否会下雪”。会则为 1，不会则为 0。
  - \[19\] - 下雪的概率（百分比）。
  - \[20\] - 能见度（英里）。
  - \[21\] - 能见度（千米）。
  - \[22\] - 风寒温度（华氏度）。
  - \[23\] - 风寒温度（摄氏度）。
  - \[24\] - 热指数（华氏度）。
  - \[25\] - 热指数（摄氏度）。
  - \[26\] - 露点（华氏度）。
  - \[27\] - 露点（摄氏度）。
  - \[28\] - 气压（英寸）。
  - \[29\] - 气压（毫巴）。
  - \[30\] - UV 指数。
- **Reference24**: 上述信息对应的日期。0 表示今天，1 表示明天，2 表示后天。
