# OnWeatherStation.Forecast.Day

**カテゴリ:** 插件「Weather Station」

将与全天预报有关的信息发送给所有正在运行的 ghost。必须使用 `\![raiseplugin]` 调用。可以通过附加参数指定发送哪一天的数据。0表示今天，1表示明天，2表示后天。未提供参数时默认为今天。

- **Reference0**: 以下信息所对应的日期。0表示今天，1表示明天，2表示后天。
- **Reference1**: 当天最高气温（华氏度）。
- **Reference2**: 当天最高气温（摄氏度）。
- **Reference3**: 当天最低气温（华氏度）。
- **Reference4**: 当天最低气温（摄氏度）。
- **Reference5**: 当天平均气温（华氏度）。
- **Reference6**: 当天平均气温（摄氏度）。
- **Reference7**: 当天平均湿度（百分比）。
- **Reference8**: 当天最大风速（mph）。
- **Reference9**: 当天最大风速（kph）。
- **Reference10**: 当天总降水量（英寸）。
- **Reference11**: 当天总降水量（毫米）。
- **Reference12**: “当天是否下雨”。下雨时为1，不下雨时为0。
- **Reference13**: 当天下雨的概率（百分比）。
- **Reference14**: “当天是否下雪”。下雪时为1，不下雪时为0。
- **Reference15**: 当天下雪的概率（百分比）。
- **Reference16**: 当天平均能见度（英里）。
- **Reference17**: 当天平均能见度（公里）。
