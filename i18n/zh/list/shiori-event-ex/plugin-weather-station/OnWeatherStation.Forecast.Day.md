# OnWeatherStation.Forecast.Day

**カテゴリ:** plugin“Weather Station”

向所有运行中的 ghost 发送某一整天的天气预报信息。必须通过 `\![raiseplugin]` 调用。可以通过额外参数指定发送哪一天的数据。0 表示今天，1 表示明天，2 表示后天。如果没有参数，则默认为今天。

- **Reference0**: 以下信息对应的日期。0 表示今天，1 表示明天，2 表示后天。
- **Reference1**: 当天的最高气温（华氏度）。
- **Reference2**: 当天的最高气温（摄氏度）。
- **Reference3**: 当天的最低气温（华氏度）。
- **Reference4**: 当天的最低气温（摄氏度）。
- **Reference5**: 当天的平均气温（华氏度）。
- **Reference6**: 当天的平均气温（摄氏度）。
- **Reference7**: 当天的平均湿度（百分比）。
- **Reference8**: 当天的最大风速（mph）。
- **Reference9**: 当天的最大风速（kph）。
- **Reference10**: 当天的总降水量（英寸）。
- **Reference11**: 当天的总降水量（毫米）。
- **Reference12**: “当天是否会下雨”。会则为 1，不会则为 0。
- **Reference13**: 当天下雨的概率（百分比）。
- **Reference14**: “当天是否会下雪”。会则为 1，不会则为 0。
- **Reference15**: 当天下雪的概率（百分比）。
- **Reference16**: 当天的平均能见度（英里）。
- **Reference17**: 当天的平均能见度（千米）。
