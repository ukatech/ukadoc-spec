# OnHttpcNotify

**カテゴリ:** SAORI "httpc.dll"

An event notifying of the return value, sent via DirectSSTP from the same DLL after a function provided by httpc.dll has been executed with the asynchronous execution option.

- **Reference0**: Identifier passed as argument 1 when called.
- **Reference1**: Empty string
- **Reference\***: Return value of the executed function.
