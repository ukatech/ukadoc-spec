# OnElonaOmakeMMAEventNewGame

**カテゴリ:** 应用「Elona omake_MMA」

开始新游戏时触发。

- **Reference0**: 游戏版本。
- **Reference1**: 游戏内年份
- **Reference2**: 游戏内月份
- **Reference3**: 游戏内日期
- **Reference4**: 游戏内小时
- **Reference5**: 游戏内分钟
- **Reference6**: 游戏内秒数
- **Reference7**: 游戏内天气
- **Reference8**: 地图名称
- **Reference9**: 区域名称
- **Reference10**: 世界名称
- **Reference11**: 层数
- **Reference12**: 所属公会
- **Reference\***: Reference13-19未使用，保留。
- **Reference20**: 各事件的目标角色编号（0:PC、1～15:宠物、16～55:冒险者、56～:其他NPC）
- **Reference21**: PC:名称
- **Reference22**: PC:别名
- **Reference23**: PC:种族
- **Reference24**: PC:职业
- **Reference25**: PC:信仰
- **Reference26**: PC:角色类型名称（PC没有类型，因此赋值为「错误」）
- **Reference27**: PC:性别
- **Reference28**: PC:年龄
- **Reference29**: PC:身高
- **Reference30**: PC:体重
- **Reference31**: PC:等级
- **Reference32**: PC:当前HP
- **Reference33**: PC:最大HP
- **Reference34**: PC:当前MP
- **Reference35**: PC:最大MP
- **Reference36**: PC:持有金钱
- **Reference37**: PC:名声
- **Reference38**: PC:业报
- **Reference39**: PC:DV
- **Reference40**: PC:PV
- **Reference41**: PC:力量
- **Reference42**: PC:耐力
- **Reference43**: PC:灵巧
- **Reference44**: PC:感知
- **Reference45**: PC:学习
- **Reference46**: PC:意志
- **Reference47**: PC:魔力
- **Reference48**: PC:魅力
- **Reference49**: PC:速度
- **Reference50**: PC:运势
- **Reference\***: Reference51-80中，目标角色的数据按相同顺序存放在对应PC信息编号+30的位置。
