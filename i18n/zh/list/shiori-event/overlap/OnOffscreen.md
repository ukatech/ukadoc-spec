# OnOffscreen

**カテゴリ:** 屏幕外与重叠事件

角色（surface）的窗口被挤到显示器（工作区域）外，或移出显示器（工作区域）时触发。即窗口超出屏幕边界。<br />
超出屏幕边界的状态发生变化时会逐次通知，因此也可以通过适当处理检测到“恢复到屏幕内”。

- **Reference0**: ID \[`\1`\] ID \[`\1`\] ID ...<br />
  \[`\1`\] 是字节值1<br />
  例：1 \[`\1`\] 2 表示1号窗口和2号窗口超出屏幕边界。
- **Reference1**: 使用与Reference0相同的格式，通知状态变化前的值（即上一次事件触发时的Reference0）。

**対応:** SSP / Ninix
