# OnOverlap

**カテゴリ:** 屏幕外与重叠事件

角色（surface）的窗口发生重叠时触发。<br />
重叠状态发生变化时会逐次通知，因此也可以通过适当处理检测到“不再重叠”。

- **Reference0**: ID-ID \[`\1`\] ID-ID \[`\1`\] ID-ID ...<br />
  \[`\1`\] 是字节值1<br />
  例：0-1 \[`\1`\] 0-2 表示0号窗口与1号窗口、0号窗口与2号窗口发生了重叠。
- **Reference1**: 使用与Reference0相同的格式，通知状态变化前的值（即上一次事件触发时的Reference0）。

**対応:** SSP / Ninix
