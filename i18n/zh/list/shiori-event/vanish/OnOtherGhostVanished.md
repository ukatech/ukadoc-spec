# OnOtherGhostVanished

**カテゴリ:** Vanish events

Occurs when another ghost disappears while multiple ghosts are running.

- **Reference0**: Baseware-side name of the ghost that disappeared.
- **Reference1**: Script of the disappeared ghost's OnVanishSelected event.
- **Reference2**: Name of the disappeared ghost.
- **Reference7**: *Shell name of the ghost that was switched to.*

**対応:** SSP
