# OnSNTPCompare

**カテゴリ:** 时钟同步事件

与服务器建立连接时触发。若要执行时钟校正，请返回包含[`\6`标签](../../sakura-script/event/6.md)的脚本。

- **Reference0**: 连接目标服务器名称。
- **Reference1**: 以逗号分隔的服务器当前时间：年,月,日,时,分,秒（差值小于1秒时与本地时间相同）
- **Reference2**: 以逗号分隔的本地当前时间：年,月,日,时,分,秒
- **Reference3**: 服务器与本地时间的偏差。以秒为单位，始终为正整数。
- **Reference4**: ※仅SSP　服务器与本地时间的偏差。以毫秒为单位，始终为正整数。

**対応:** Materia / SSP / CROW
