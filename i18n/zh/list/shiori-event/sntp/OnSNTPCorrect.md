# OnSNTPCorrect

**カテゴリ:** 时钟校准事件

通过[`\6`标签](../../sakura-script/event/6.md)将本地时间校正为服务器时间时触发。

即使实际上没有校正 OS 时钟，例如 OS 的自动时间同步已启用且偏差较小（60秒以内）时，也会触发（SSP 2.9.40以后）。可通过 Reference5 区分是否进行了校正。

- **Reference0**: 连接目标服务器名。
- **Reference1**: 以逗号分隔的服务器当前时间：年,月,日,时,分,秒（偏差不足1秒时与本地时间相同）
- **Reference2**: 以逗号分隔的本地当前时间：年,月,日,时,分,秒
- **Reference3**: 服务器与本地的时间偏差。以秒为单位的整数。正值表示本地时间落后，负值表示本地时间超前。
- **Reference4**: ※仅 SSP　服务器与本地的时间偏差。以毫秒为单位的整数。
- **Reference5**: ※仅 SSP　是否实际校正了 OS 时钟（SSP 2.9.40以后）。校正时为1，未校正时为0。OS 的自动时间同步已启用且偏差在60秒以内时，交由 OS 处理，不进行校正。

**対応:** Materia / SSP / CROW
