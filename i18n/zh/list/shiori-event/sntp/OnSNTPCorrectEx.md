# OnSNTPCorrectEx

**カテゴリ:** 时钟同步事件

通过[`\6`标签](../../sakura-script/event/6.md)将本地时间校正为服务器时间时触发。

- **Reference0**: 连接目标服务器名称。
- **Reference1**: 以逗号分隔的服务器当前时间：年,月,日,时,分,秒,毫秒
- **Reference2**: 以逗号分隔的本地当前时间：年,月,日,时,分,秒,毫秒
- **Reference3**: 服务器与本地时间的偏差。以秒为单位且带小数。正值表示本地时间落后于服务器时间，负值表示本地时间超前于服务器时间。
- **Reference4**: 服务器与本地时间的偏差。以毫秒为单位的整数。正负含义与Reference3相同。

**対応:** SSP 2.5.66
