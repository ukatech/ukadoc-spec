# 轴名称列表

- **LeftStickX**: 左摇杆水平轴（右为正，左为负）。归一化值范围为-1.0～1.0。
- **LeftStickY**: 左摇杆垂直轴（上为正，下为负）。归一化值范围为-1.0～1.0。
- **RightStickX**: 右摇杆水平轴（右为正，左为负）。归一化值范围为-1.0～1.0。
- **RightStickY**: 右摇杆垂直轴（上为正，下为负）。归一化值范围为-1.0～1.0。
- **LeftTrigger**: 左扳机（按下越深，值越大）。归一化值范围为0.0～1.0。
- **RightTrigger**: 右扳机（按下越深，值越大）。归一化值范围为0.0～1.0。
