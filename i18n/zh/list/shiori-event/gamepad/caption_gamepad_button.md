# 按钮名称列表

- **A**: 正面下方按钮
- **B**: 正面右侧按钮
- **X**: 正面左侧按钮
- **Y**: 正面上方按钮
- **LB**: 左肩键（相当于 L1）
- **RB**: 右肩键（相当于 R1）
- **LSB**: 左摇杆按下（相当于 L3）
- **RSB**: 右摇杆按下（相当于 R3）
- **Start**: Start 按钮
- **Back**: Back / Select 按钮
- **DPadUp**: 十字键上
- **DPadDown**: 十字键下
- **DPadLeft**: 十字键左
- **DPadRight**: 十字键右

十字键斜向输入会分别触发两个按钮事件（例如：右上方向会触发 DPadUp 和 DPadRight）。
