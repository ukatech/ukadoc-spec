# 安装标识符

- shell
- ghost
- balloon
- plugin
- headline
- rss
- supplement

以下标识符仅用于OnInstallComplete / OnNarCreated<br />
SSP中已废止，ghost和balloon会分别作为不同的标识符通知。

- ghost with balloon
- shell with balloon

以下标识符仅适用于SSP

- calendar skin
- calendar plugin
- package
- language

SSP中[同时安装](../../../descript/install/install-txt/introduction_install_multi.md)的项目标识符与install.txt中的指定相同，为以*点号分隔*的 calendar.skin / calendar.plugin。<br />
归档文件本体侧的标识符保持install.txt中type的写法，因此为以空格分隔的 calendar skin / calendar plugin。
