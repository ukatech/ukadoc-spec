# OnInstallReroute

**カテゴリ:** 安装事件

当要安装的文件指定了其他 ghost，且指定的 ghost 同时正在运行时触发。之后的安装事件会发送给被指定的 ghost。

- **Reference0**: 指定 ghost 的本体侧名称（由install.txt的[accept](../../../descript/install/install-txt/accept.md)指定，即本应接收文件的一方）。
- **Reference1**: 已安装项目的[※标识符](caption_install-identifier.md)。
- **Reference2**: 已安装项目的名称。

**対応:** SSP 2.4 / Ref1起适用于2.4.85
