# OnInstallRefuse

**カテゴリ:** 安装事件

待安装的文件指定了其他 ghost 时触发。

- **Reference0**: 指定的 ghost 的本体名称（install.txt 中的 [accept](../../../descript/install/install-txt/accept.md) 指定，即原本应接收此文件的一方）。
- **Reference1**: 尝试安装项目的[※标识符](caption_install-identifier.md)。
- **Reference2**: 尝试安装项目的名称。

**対応:** Materia / SSP（Ref1 及之后的项目仅从 2.4.85 起支持）/ CROW / Ninix
