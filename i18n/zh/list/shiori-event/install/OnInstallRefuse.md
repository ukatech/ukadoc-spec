# OnInstallRefuse

**カテゴリ:** Installation events

Occurs when the file being installed specifies another ghost as its intended recipient.

- **Reference0**: Baseware-side name of the specified ghost (the intended recipient specified by [accept](../../../descript/install/install-txt/accept.md) in install.txt).
- **Reference1**: [※Identifier](caption_install-identifier.md) of the item being installed.
- **Reference2**: Name of the item being installed.

**対応:** Materia / SSP / Ref1 and later: 2.4.85 / CROW / Ninix
