# OnRecommendsiteChoice

**カテゴリ:** 其他事件

从菜单中选择网站链接时会触发此事件。

- **Reference0**: 所选网站的名称。
- **Reference1**: 所选网站的URL。
- **Reference2**: ※仅限SSP　悬停时显示的缩略图图片URL/路径
- **Reference3**: ※仅限SSP　recommend或portal
- **Reference4**: ※仅限SSP　0或1（0=sakura或1=kero）
- **Reference5**: ※仅限SSP　数值，表示菜单中从上往下的第几个（注意从0开始）

**対応:** Materia / SSP / CROW / Ninix
