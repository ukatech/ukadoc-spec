# OnLanguageChange

**カテゴリ:** Other events

Notifies when the language settings change and immediately after startup.<br />
When notified immediately after startup, this is always a NOTIFY, and the event cannot be responded to with speech.

- **Reference0**: Language name (name)
- **Reference1**: Language ID (langid)
- **Reference2**: Full path to the folder containing the language settings files
- **Reference3**: URL where help is provided

**対応:** SSP 2.5
