# Archive operation error codes

- **none**: No error (normal)
- **invalid parameter**: Invalid parameter
- **file not found**: File not found
- **directory not found**: Directory not found
- **create directory failed**: Failed to create directory
- **open failed**: Failed to open file
- **getfileinfo failed**: Failed to retrieve file information
- **goto failed**: Failed to move to file position
- **corrupted**: Archive is corrupted
- **crc**: CRC error (data integrity error)
- **stream**: Stream error
- **unknown method**: Unknown compression method
- **password required**: Password required
- **password mismatch**: Password mismatch
- **close failed**: Failed to close file
