# 归档操作错误代码

- **none**: 无错误（正常）
- **invalid parameter**: 参数无效
- **file not found**: 找不到文件
- **directory not found**: 找不到目录
- **create directory failed**: 创建目录失败
- **open failed**: 打开文件失败
- **getfileinfo failed**: 获取文件信息失败
- **goto failed**: 移动文件位置失败
- **corrupted**: 归档已损坏
- **crc**: CRC错误（数据完整性错误）
- **stream**: 流错误
- **unknown method**: 未知的压缩方式
- **password required**: 需要密码
- **password mismatch**: 密码不匹配
- **close failed**: 关闭文件失败
