# OnDisplayChange

**カテゴリ:** OS state event

Occurs when the resolution/color depth of the desktop (primary screen) changes. *\[NOTIFY at startup/GET otherwise\]*

- **Reference0**: Color depth after the change (bpp)
- **Reference1**: Resolution after the change (width)
- **Reference2**: Resolution after the change (height)

**対応:** SSP / CROW / Ninix
