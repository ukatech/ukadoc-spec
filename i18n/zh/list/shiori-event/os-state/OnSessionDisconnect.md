# OnSessionDisconnect

**カテゴリ:** OS state event

Occurs when switching to another user account using Fast User Switching.<br />
In Windows, it is notified together with OnSessionLock, and OnWindowStateMinimize also occurs because the window is forcibly minimized.<br />
Note that this behavior is a Windows-specific limitation and may not be the same on other operating systems.

**対応:** SSP 2.5.53
