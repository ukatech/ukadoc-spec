# OnBatteryChargingStop

**カテゴリ:** OS state event

Occurs when battery charging stops. This does not necessarily mean that the battery is fully charged.<br />
An event compatible with “[Ukagaka for Android](http://tatadenden.blog23.fc2.com/) ([archive](https://web.archive.org/web/20240106101741/http://tatadenden.blog23.fc2.com/))”.

- **Reference0～**: Same as OnBatteryNotify.

**対応:** SSP
