# OnSchedulesenseBegin

**カテゴリ:** Calendar event

Occurs when a schedule sensor starts connecting.<br />
This is sent to all running ghosts, not a specific ghost.

**Occurs only during a manual update (when you select a sensor from the calendar menu and update it).** It does not occur during periodic checks, as [described below](caption_schedulesensetiming.md).

- **Reference0**: Schedule sensor name
- **Reference1**: Schedule sensor subscription URL

**対応:** SSP
