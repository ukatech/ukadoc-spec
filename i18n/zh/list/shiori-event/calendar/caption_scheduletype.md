# Schedule types

- **default**: Unrecognized type
- **event**: General
- **meeting**: Meeting
- **appointment**: Appointment
- **reservation**: Reservation, such as a hospital appointment
- **duedate**: Deadline
- **party**: Party or drinks
- **date**: Date
- **work**: Work
- **go**: Outing
- **tv**: TV program
- **recording**: Recording reservation
- **cd**: CD release date
- **game**: Game release date
- **video**: Video media release date
- **book**: Book release date
- **release**: Other release date
