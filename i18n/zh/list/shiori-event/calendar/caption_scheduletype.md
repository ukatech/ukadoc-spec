# 日程类型

- **default**: 无法识别的类型
- **event**: 通用
- **meeting**: 会议
- **appointment**: 约会
- **reservation**: 医院等的预约
- **duedate**: 截止日期
- **party**: 派对、聚会
- **date**: 约会
- **work**: 工作
- **go**: 外出
- **tv**: 电视节目
- **recording**: 录像预约
- **cd**: CD发售日
- **game**: 游戏发售日
- **video**: 影像媒体发售日
- **book**: 书籍发售日
- **release**: 其他发售日
