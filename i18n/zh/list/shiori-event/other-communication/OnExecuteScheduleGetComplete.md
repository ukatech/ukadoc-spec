# OnExecuteScheduleGetComplete

**カテゴリ:** 其他通信事件

通过 [`\![execute,schedule-get]`](../../sakura-script/misc/bang-execute-schedule-get.md)读取 ghost 的日程表时触发。

通过 --event 指定以 On 开头的 ID 时，该 ID 会成为事件名。

- **Reference0～**: [与 OnExecuteICalComplete 相同](OnExecuteICalComplete.md)。<br />
  仅包含 ghost 的日程表，不包含用户登记的日程或日程传感器的日程。

**対応:** SSP 2.8.91
