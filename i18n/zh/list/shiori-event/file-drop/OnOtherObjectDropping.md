# OnOtherObjectDropping

**カテゴリ:** 文件拖放事件

当光标移动到幽灵上方，且该对象无法作为“文件”处理时触发。例如：Windows 的“我的电脑”等。

- **Reference0**: 被拖放角色的 scope 编号。本体侧为0，搭档为1，第三人及之后为2以上。
- **Reference1**: 被拖放对象的名称（受 OS 语言设置影响）。<br />
  有多个对象时，以字节值1分隔。
- **Reference2**: 被拖放对象的类似 ID 的标识符，不受 OS 语言设置影响。<br />
  有多个对象时，以字节值1分隔。以下为 Windows 上的示例。
  - PC（我的电脑） = ::\{20D04FE0-3AEA-1069-A2D8-08002B30309D\}
  - 回收站 = ::\{645FF040-5081-101B-9F08-00AA002F954E\}
  - （我的）网络 = ::\{F02C1A0D-BE21-4350-88B0-7367FC96EF3C\}

**対応:** SSP 2.6.41
