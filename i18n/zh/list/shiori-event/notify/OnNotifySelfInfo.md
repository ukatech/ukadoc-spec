# OnNotifySelfInfo

**カテゴリ:** Notify 事件

通知 ghost 自身的信息。*\[NOTIFY\]*

- **Reference0**: ghost 名称。
- **Reference1**: 本体一方的名称。
- **Reference2**: 搭档一方的名称。
- **Reference3**: 当前 shell 名称。
- **Reference4**: 当前 shell 的绝对路径。
- **Reference5**: 当前 balloon 名称。
- **Reference6**: 当前 balloon 的绝对路径。

**対応:** SSP / CROW
