# OnShellChanged

**カテゴリ:** Startup, shutdown, and switching events

Occurs when switched from another shell.

- **Reference0**: Current shell name.
- **Reference1**: (CROW only) Same as Reference0. (SSP only) Current ghost name.
- **Reference2**: (SSP only) Path of the current shell.

**対応:** Materia / SSP / CROW / Ninix
