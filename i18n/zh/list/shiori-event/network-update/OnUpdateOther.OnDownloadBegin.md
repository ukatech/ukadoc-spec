# OnUpdateOther.OnDownloadBegin

**カテゴリ:** 网络更新事件

开始下载ghost以外的文件时触发。

- **Reference0**: 要下载的文件名。
- **Reference1**: 正在下载的更新文件编号（从0开始的连续编号）。
- **Reference2**: 要更新的文件总数减1（从0开始的连续编号）。
- **Reference3**: [※更新目标类型](caption_updatetype.md)
- **Reference4**: SSP 2.3：[※更新执行原因](caption_updatereason.md)。
