# OnUpdateResult

**カテゴリ:** 网络更新事件

执行网络更新时触发，将包括balloon、shell批量更新功能在内的所有更新结果一次性通知。

- **Reference\***: 按更新执行的顺序，以以下格式填入更新结果（`\1`是字节值1）

  (※1)\[`\1`\](※2)\[`\1`\](※3)\[`\1`\](※4)<br />
  或者<br />
  (※1)\[`\1`\](※2)\[`\1`\](※3)

  - ※1……[网络更新目标的类型](caption_updatetype.md)
  - ※2……成功时为“OK”，失败时为“NG”
  - ※3……成功时为更新文件数（没有更新文件=none时为0），失败时为[失败原因](caption_updateresultfailure.md)。
  - ※4……更新失败且已知失败原因文件时，为该文件名。

**対応:** SSP
