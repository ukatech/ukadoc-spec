# OnUserInput

**カテゴリ:** 输入框事件

在 InputBox 中输入内容并确认时触发。

另请参阅[InputBox 的 ID](../../sakura-script/open/bang-close-textareabox-ID.note-2.md)。

- **Reference0**: InputBox 的 ID。
- **Reference1**: 输入的内容。
- **Reference2**: 输入内容的补充信息（仅 sliderinput 使用，最小值,最大值。其他情况为空）
- **Reference3～**: 通过 --reference= 指定的附加信息

**対応:** Materia / SSP / CROW / Ninix
