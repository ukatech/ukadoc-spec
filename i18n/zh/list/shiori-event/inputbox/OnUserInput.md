# OnUserInput

**カテゴリ:** Input box events

Occurs when input is submitted in InputBox.

See also [InputBox ID](../../sakura-script/open/bang-close-textareabox-ID.note-2.md).

- **Reference0**: InputBox ID.
- **Reference1**: Entered content.
- **Reference2**: Input details (sliderinput only: minimum, maximum; empty otherwise)
- **Reference3～**: Additional information specified with --reference=

**対応:** Materia / SSP / CROW / Ninix
