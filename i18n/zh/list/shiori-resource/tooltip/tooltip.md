# tooltip

**カテゴリ:** 工具提示类

获取 shell 的工具提示内容。<br />
鼠标光标移到 shell 的 surface 上时通知。<br />
如果存在[ shell 侧设置](../../../descript/shell-surfaces/tooltip-brace/entry.md)，则优先使用该设置。

- **Reference0**: 鼠标光标的 x 坐标（局部坐标）
- **Reference1**: 鼠标光标的 y 坐标（局部坐标）
- **Reference2**: 始终为 0。
- **Reference3**: 本体为 0，搭档为 1。SSP/CROW 中还可能为 2 及以上。
- **Reference4**: 命中区域的标识符。
- **Reference5**: 始终为 0。

**対応:** SSP
