# OnGhostExit

**カテゴリ:** PLUGIN Event

ghost 結束時發生。*\[NOTIFY\]*

- **Reference0**: 以位元組值1分隔，已結束的 ghost 中`\0`之後各角色視窗的 HWND。<br />
  尚未建立等情況下，可能會是0。
- **Reference1**: 已結束的 ghost 名稱。
- **Reference2**: 已結束的 ghost 目前的 shell 名稱。
- **Reference3**: 已結束的 ghost ID（與 Owned SSTP 傳送的相同）。
- **Reference4**: 已結束的 ghost 完整路徑。

**対応:** SSP
