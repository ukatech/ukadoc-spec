# OnChoiceSelect(Ex)/OnAnchorSelect(Ex)/`\q`等指定的任意名稱事件

**カテゴリ:** PLUGIN Event

選擇選項或錨點時發生的 SHIORI Event，在 plugin 端的攔截事件。<br />
當 plugin 傳送給 ghost 的 script，以及 ghost 對 plugin 通知的事件所回覆的 script 中，包含選項或錨點相關的 Sakura Script 標籤時，僅限該次選取時，會將與通知給 SHIORI 端相同的事件轉送通知給 plugin。

- **Reference\***: 發生的選項或錨點相關 SHIORI Event 的 Reference。

**対応:** SSP
