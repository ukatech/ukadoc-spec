# OnWeatherStation.Alerts

**カテゴリ:** 外掛程式「Weather Station」

將天氣警報資訊傳送給所有正在執行的 ghost。必須使用 `\![raiseplugin]` 呼叫。若沒有警報，則不回傳任何內容。

- **Reference\***: 包含一筆天氣警報資訊的陣列。也可能有未填入的元素。元素以 1 位元組的值分隔。

  - \[0\] - 標題
  - \[1\] - 警報類型
  - \[2\] - 嚴重程度
  - \[3\] - 緊急程度
  - \[4\] - 目標區域
  - \[5\] - 類別
  - \[6\] - 確定性
  - \[7\] - 事件
  - \[8\] - 備註
  - \[9\] - 生效時間
  - \[10\] - 失效時間
  - \[11\] - 說明
  - \[12\] - 指示事項
