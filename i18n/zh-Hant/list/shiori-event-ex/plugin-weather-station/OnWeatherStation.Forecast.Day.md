# OnWeatherStation.Forecast.Day

**カテゴリ:** plugin「Weather Station」

向所有執行中的 ghost 傳送全天的整體天氣預報資訊。必須透過 `\![raiseplugin]` 呼叫。可用額外的引數指定傳送哪一天的資料。0 表示今天，1 表示明天，2 表示後天。若未指定引數，預設為今天。

- **Reference0**: 以下資訊所對應的日期。0 表示今天，1 表示明天，2 表示後天。
- **Reference1**: 當日最高溫度（華氏）。
- **Reference2**: 當日最高溫度（攝氏）。
- **Reference3**: 當日最低溫度（華氏）。
- **Reference4**: 當日最低溫度（攝氏）。
- **Reference5**: 當日平均溫度（華氏）。
- **Reference6**: 當日平均溫度（攝氏）。
- **Reference7**: 當日平均濕度（百分比）。
- **Reference8**: 當日最大風速（mph）。
- **Reference9**: 當日最大風速（kph）。
- **Reference10**: 當日總降水量（英吋）。
- **Reference11**: 當日總降水量（毫米）。
- **Reference12**: 「當日是否下雨」。會下雨為 1，不會為 0。
- **Reference13**: 當日降雨機率（百分比）。
- **Reference14**: 「當日是否下雪」。會下雪為 1，不會為 0。
- **Reference15**: 當日降雪機率（百分比）。
- **Reference16**: 當日平均能見度（英里）。
- **Reference17**: 當日平均能見度（公里）。
