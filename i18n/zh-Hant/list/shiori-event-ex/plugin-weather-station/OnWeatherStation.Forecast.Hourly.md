# OnWeatherStation.Forecast.Hourly

**カテゴリ:** 外掛程式「Weather Station」

將一天之中每小時預報的相關資訊傳送給所有正在執行的 ghost。必須使用 `\![raiseplugin]` 呼叫。可透過額外引數指定要傳送哪一天的資料。0 代表今天，1 代表明天，2 代表後天。未指定引數時，預設為今天。

- **Reference0～23**: 包含預報資訊的逗號分隔陣列。Reference 編號對應資料所屬時間的數字（24 小時制）（例如：reference0 為 00:00／上午 12 時，reference14 為 14:00／下午 2 時）。
  - \[0\] - 資訊所對應的日期與時間。
  - \[1\] -「是否為白天」。太陽升起時為 1，太陽落下時為 0。
  - \[2\] - 氣溫（華氏）。
  - \[3\] - 氣溫（攝氏）。
  - \[4\] -「體感」溫度（華氏）。
  - \[5\] -「體感」溫度（攝氏）。
  - \[6\] - 濕度（百分比）。
  - \[7\] - 風速（英里／小時）。
  - \[8\] - 風速（公里／小時）。
  - \[9\] - 風向（16 方位。例如：NNW 代表西北西）。
  - \[10\] - 風向（度）。
  - \[11\] - 陣風風速（英里／小時）。
  - \[12\] - 陣風風速（公里／小時）。
  - \[13\] - 降水量（英吋）。
  - \[14\] - 降水量（毫米）。
  - \[15\] - 雲量（百分比）。
  - \[16\] -「是否會下雨」。會下雨時為 1，不會下雨時為 0。
  - \[17\] - 下雨機率（百分比）。
  - \[18\] -「是否會下雪」。會下雪時為 1，不會下雪時為 0。
  - \[19\] - 下雪機率（百分比）。
  - \[20\] - 能見度（英里）。
  - \[21\] - 能見度（公里）。
  - \[22\] - 風寒指數（華氏）。
  - \[23\] - 風寒指數（攝氏）。
  - \[24\] - 體感溫度（華氏）。
  - \[25\] - 體感溫度（攝氏）。
  - \[26\] - 露點（華氏）。
  - \[27\] - 露點（攝氏）。
  - \[28\] - 氣壓（英吋）。
  - \[29\] - 氣壓（毫巴）。
  - \[30\] - UV 指數。
- **Reference24**: 前述資訊所對應的日期。0 代表今天，1 代表明天，2 代表後天。
