# OnWeatherStation.Forecast.Hourly

**カテゴリ:** plugin「Weather Station」

將一天中逐小時的預報資訊傳送給所有執行中的 ghost。必須使用 `\![raiseplugin]` 呼叫。可透過額外引數指定要傳送哪一天的資料。0 表示今天，1 表示明天，2 表示後天。若未指定引數，預設為今天。

- **Reference0～23**: 包含預報資訊、以逗號分隔的陣列。Reference 的編號對應資料所屬的小時數（24 小時制；例如 reference0 對應 00:00／上午 12 時，reference14 對應 14:00／下午 2 時）。
  - \[0\] - 資訊所對應的日期與時間。
  - \[1\] - 「是否為白天」。太陽已升起為 1，已落下為 0。
  - \[2\] - 氣溫（華氏）。
  - \[3\] - 氣溫（攝氏）。
  - \[4\] - 「體感」溫度（華氏）。
  - \[5\] - 「體感」溫度（攝氏）。
  - \[6\] - 濕度（百分比）。
  - \[7\] - 風速（英里每小時）。
  - \[8\] - 風速（公里每小時）。
  - \[9\] - 風向（16 方位；例如 NNW 表示北北西）。
  - \[10\] - 風向（度）。
  - \[11\] - 陣風風速（英里每小時）。
  - \[12\] - 陣風風速（公里每小時）。
  - \[13\] - 降水量（英吋）。
  - \[14\] - 降水量（毫米）。
  - \[15\] - 雲量（百分比）。
  - \[16\] - 「是否下雨」。會下雨為 1，不會下雨為 0。
  - \[17\] - 降雨機率（百分比）。
  - \[18\] - 「是否下雪」。會下雪為 1，不會下雪為 0。
  - \[19\] - 降雪機率（百分比）。
  - \[20\] - 能見度（英里）。
  - \[21\] - 能見度（公里）。
  - \[22\] - 風寒指數（華氏）。
  - \[23\] - 風寒指數（攝氏）。
  - \[24\] - 熱指數（華氏）。
  - \[25\] - 熱指數（攝氏）。
  - \[26\] - 露點（華氏）。
  - \[27\] - 露點（攝氏）。
  - \[28\] - 氣壓（英吋）。
  - \[29\] - 氣壓（毫巴）。
  - \[30\] - UV 指數。
- **Reference24**: 上述資訊所對應的日期。0 表示今天，1 表示明天，2 表示後天。
