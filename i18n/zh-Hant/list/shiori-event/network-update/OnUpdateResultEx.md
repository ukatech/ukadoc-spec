# OnUpdateResultEx

**カテゴリ:** 網路更新事件

執行網路更新時觸發，並一次通知所有更新結果，包括 balloon、shell 的批次更新功能。

- **Reference\***: 依照執行更新的順序，更新結果會以以下格式填入（`\1` 是位元組值 1）

  (※1)\[`\1`\](※2)\[`\1`\](※3)\[`\1`\](※4)\[`\1`\](※5)<br />
  或<br />
  (※1)\[`\1`\](※2)\[`\1`\](※3)\[`\1`\](※4)

  - ※1……網路更新目標的名稱
  - ※2……[網路更新目標的類型](caption_updatetype.md)
  - ※3……成功時為「OK」，失敗時為「NG」
  - ※4……成功時為更新檔案數（沒有更新檔案=none 時為 0），失敗時為[失敗原因](caption_updateresultfailure.md)。
  - ※5……更新失敗且能確認失敗原因檔案時，為該檔名。

**対応:** SSP
