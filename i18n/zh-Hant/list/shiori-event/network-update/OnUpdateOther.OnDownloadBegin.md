# OnUpdateOther.OnDownloadBegin

**カテゴリ:** 網路更新事件

開始下載 ghost 以外的檔案時觸發。

- **Reference0**: 要下載的檔名。
- **Reference1**: 正在下載的更新檔案編號（從 0 開始的連續編號）。
- **Reference2**: 要更新的檔案總數減 1（從 0 開始的連續編號）。
- **Reference3**: [※更新目標類型](caption_updatetype.md)
- **Reference4**: SSP 2.3：[※更新執行原因](caption_updatereason.md)。
