# OnOffscreen

**カテゴリ:** 超出範圍與重疊事件

角色（surface）的視窗被卡在螢幕（工作區域）外，或移出螢幕時觸發。視窗超出範圍。<br />
超出範圍的狀態改變時會逐次通知，因此只要稍加設計，也能偵測到「不再超出範圍」。

- **Reference0**: ID \[`\1`\] ID \[`\1`\] ID ...<br />
  \[`\1`\] 是位元組值1<br />
  例：1 \[`\1`\] 2 表示第1號視窗和第2號視窗超出範圍。
- **Reference1**: 以與Reference0相同的格式，通知狀態改變前（＝前一次事件觸發時的Reference0）的內容。

**対応:** SSP / Ninix
