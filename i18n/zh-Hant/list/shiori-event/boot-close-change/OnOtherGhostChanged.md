# OnOtherGhostChanged

**カテゴリ:** 啟動、結束與切換事件

其他ghost之間切換時觸發。

- **Reference0**: 前一個ghost的本體名稱。
- **Reference1**: 切換後ghost的本體名稱。
- **Reference2**: 前一個ghost切換時使用的腳本。
- **Reference3**: 切換後ghost切換時使用的腳本。
- **Reference4**: 前一個ghost的名稱。
- **Reference5**: 切換後ghost的名稱。
- **Reference14**: 前一個ghost的shell名稱。
- **Reference15**: 切換後ghost的shell名稱。

**対応:** SSP / Ninix
