# 封存檔操作錯誤代碼

- **none**: 無錯誤（正常）
- **invalid parameter**: 無效的參數
- **file not found**: 找不到檔案
- **directory not found**: 找不到目錄
- **create directory failed**: 建立目錄失敗
- **open failed**: 開啟檔案失敗
- **getfileinfo failed**: 取得檔案資訊失敗
- **goto failed**: 移動檔案位置失敗
- **corrupted**: 封存檔已損毀
- **crc**: CRC錯誤（資料完整性錯誤）
- **stream**: 串流錯誤
- **unknown method**: 不明的壓縮方式
- **password required**: 需要密碼
- **password mismatch**: 密碼不符
- **close failed**: 關閉檔案失敗
