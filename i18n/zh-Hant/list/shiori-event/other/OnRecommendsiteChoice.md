# OnRecommendsiteChoice

**カテゴリ:** Other events

Occurs when a site link is selected from the menu.

- **Reference0**: Name of the selected site.
- **Reference1**: URL of the selected site.
- **Reference2**: ※SSP only: URL/path of the thumbnail image shown on hover
- **Reference3**: ※SSP only: recommend or portal
- **Reference4**: ※SSP only: 0 or 1 (0=sakura or 1=kero)
- **Reference5**: ※SSP only: Number indicating the item's position in the menu from the top (note that counting starts at 0)

**対応:** Materia / SSP / CROW / Ninix
