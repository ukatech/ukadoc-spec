# OnRecommendsiteChoice

**カテゴリ:** 其他事件

從選單選擇網站連結時會發生。

- **Reference0**: 選取的網站名稱。
- **Reference1**: 選取的網站 URL。
- **Reference2**: ※僅 SSP　重疊時顯示的縮圖圖片 URL／路徑
- **Reference3**: ※僅 SSP　recommend 或 portal
- **Reference4**: ※僅 SSP　0 或 1（0=sakura 或 1=kero）
- **Reference5**: ※僅 SSP　數值，表示選單由上往下第幾項（請注意從 0 開始計算）

**対応:** Materia / SSP / CROW / Ninix
