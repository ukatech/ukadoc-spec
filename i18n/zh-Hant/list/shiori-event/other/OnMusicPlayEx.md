# OnMusicPlayEx

**カテゴリ:** 其他事件

在 Windows 標準媒體播放器等支援的音樂播放軟體中，播放歌曲時會將歌曲資訊通知 ghost。<br />
若未對此事件做出反應，則會改用 OnMusicPlay。<br />
請注意，瀏覽器中播放的所有影片與音樂都會視為 OnVideoPlayEx。

- **Reference0**: 歌曲標題
- **Reference1**: 藝人名稱
- **Reference2 以後**: 擴充資訊名稱\[位元組值1\]擴充資訊內容 [OnMusicPlayEx 擴充資訊清單](caption_musicplayex_codes.md)

**対応:** SSP 2.7.55
