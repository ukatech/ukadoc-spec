# OnKeyPress

**カテゴリ:** Other events

Occurs when a key is pressed while the baseware is active.

- **Reference0**: Pressed key. (Character shown on the keycap)
- **Reference1**: Pressed key. (Win32 virtual-key code)
- **Reference2**: ※SSP only: Key auto-repeat count.
- **Reference3**: ※SSP only: ID of the character window that received the key event.
- **Reference4**: ※SSP only: Modifier keys, listed as comma-separated values. Example: "ctrl,alt"

**対応:** Materia / SSP / CROW / Ninix
