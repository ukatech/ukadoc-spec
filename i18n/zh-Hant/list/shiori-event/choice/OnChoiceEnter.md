# OnChoiceEnter

**カテゴリ:** Choice event

Occurs when the cursor moves onto or *off* a choice.<br />
When the cursor moves off a choice, OnChoiceEnter occurs with no References.

- **Reference0**: Choice text (label).
- **Reference1**: Choice ID.
- **Reference\***: Extended information (third and subsequent arguments in the `\q` tag).

**対応:** Materia / SSP / CROW / Ninix
