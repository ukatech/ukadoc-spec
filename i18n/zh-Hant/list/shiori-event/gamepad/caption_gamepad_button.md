# 按鈕名稱一覽

- **A**: 面部按鈕下
- **B**: 面部按鈕右
- **X**: 面部按鈕左
- **Y**: 面部按鈕上
- **LB**: 左側肩鍵（相當於 L1）
- **RB**: 右側肩鍵（相當於 R1）
- **LSB**: 左搖桿按下（相當於 L3）
- **RSB**: 右搖桿按下（相當於 R3）
- **Start**: 開始按鈕
- **Back**: 返回／選擇按鈕
- **DPadUp**: 十字鍵上
- **DPadDown**: 十字鍵下
- **DPadLeft**: 十字鍵左
- **DPadRight**: 十字鍵右

十字鍵的斜向輸入會個別觸發兩個按鈕事件（例如：右上會觸發 DPadUp 和 DPadRight）。
