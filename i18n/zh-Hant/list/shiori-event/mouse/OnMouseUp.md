# OnMouseUp

**カテゴリ:** 滑鼠事件

放開滑鼠左鍵或右鍵時觸發。

- **Reference0**: 滑鼠游標的 x 座標（區域座標）
- **Reference1**: 滑鼠游標的 y 座標（區域座標）
- **Reference2**: 固定為0。
- **Reference3**: 本體為0，搭檔為1。SSP/CROW中也有2以上的值。
- **Reference4**: 命中判定的識別碼。
- **Reference5**: 左鍵點擊為0，右鍵點擊為1，中鍵點擊為2（相容規格：建議改用OnMouseClickEx）。
- **Reference6**: 來自支援多點觸控環境中的觸控面板（※不含觸控板）輸入時為touch，來自繪圖板輸入時為pen，來自繪圖板橡皮擦端輸入時為eraser，來自滑鼠等輸入時為mouse

**対応:** SSP / Ninix
