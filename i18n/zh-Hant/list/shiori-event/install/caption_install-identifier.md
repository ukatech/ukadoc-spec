以下僅適用於 OnInstallComplete / OnNarCreated<br />
此識別碼已在 SSP 中廢止，ghost 和 balloon 會分別以不同識別碼通知。

- ghost with balloon
- shell with balloon

以下僅適用於 SSP

- calendar skin
- calendar plugin
- package
- language

在 SSP 中[同時安裝](../../../descript/install/install-txt/introduction_install_multi.md)的項目，其識別碼與 install.txt 中的指定相同，使用*點號分隔*的 calendar.skin / calendar.plugin。<br />
壓縮檔本體側的識別碼則維持 install.txt 中 type 的寫法，因此使用空格分隔的 calendar skin / calendar plugin。
