# OnInstallRefuse

- **Reference1**: 嘗試安裝項目的[※識別碼](caption_install-identifier.md)。
- **Reference2**: 嘗試安裝項目的名稱。

**対応:** Materia / SSP（Ref1 以後為 2.4.85）/ CROW / Ninix
