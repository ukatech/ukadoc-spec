# OnInstallRefuse

**カテゴリ:** Installation event

Occurs when the file being installed specifies another ghost.

- **Reference0**: The name of the specified ghost on its own side (specified by [accept](../../../descript/install/install-txt/accept.md) in install.txt; in other words, the intended recipient).
- **Reference1**: The [identifier](caption_install-identifier.md) of the item being installed.
- **Reference2**: The name of the item being installed.

**対応:** Materia / SSP supports Reference1 and later from 2.4.85 / CROW / Ninix
