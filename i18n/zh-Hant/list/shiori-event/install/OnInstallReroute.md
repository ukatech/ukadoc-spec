# OnInstallReroute

**カテゴリ:** 安裝事件

安裝的檔案指定了其他 ghost，且指定的 ghost 也同時啟動時會發生。之後的安裝事件會傳送給指定的 ghost。

- **Reference0**: 指定 ghost 的本體名稱（install.txt 的 [accept](../../../descript/install/install-txt/accept.md) 指定，也就是原本應接收安裝項目的對象）。
- **Reference1**: 已安裝項目的[※識別碼](caption_install-identifier.md)。
- **Reference2**: 已安裝項目的名稱。

**対応:** SSP 2.4 / Ref1 以後為 2.4.85
