# 行程類型

- **default**: 無法辨識的類型
- **event**: 一般活動
- **meeting**: 會議
- **appointment**: 約定
- **reservation**: 預約（例如醫院）
- **duedate**: 截止期限
- **party**: 派對、聚餐
- **date**: 約會
- **work**: 工作
- **go**: 外出
- **tv**: 電視節目
- **recording**: 預約錄影
- **cd**: CD 發售日
- **game**: 遊戲發售日
- **video**: 影像媒體發售日
- **book**: 書籍發售日
- **release**: 其他發售日
