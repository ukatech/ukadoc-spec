# OnSNTPCorrectEx

**カテゴリ:** 時間校正事件

透過[`\6`標籤](../../sakura-script/event/6.md)將本機時間校正為伺服器時間時觸發。

在啟用 OS 自動時間同步且時差較小（60 秒以內）等情況下，即使未實際校正 OS 時鐘也會觸發（SSP 2.9.40 以後）。可透過 Reference5 區分是否已校正。

- **Reference0**: 連線的伺服器名稱。
- **Reference1**: 以逗號分隔的伺服器目前時間：年,月,日,時,分,秒,毫秒
- **Reference2**: 以逗號分隔的本機目前時間：年,月,日,時,分,秒,毫秒
- **Reference3**: 伺服器與本機的時差。以秒為單位，包含小數部分。正值表示本機時間比伺服器時間慢，負值表示本機時間比伺服器時間快。
- **Reference4**: 伺服器與本機的時差。以毫秒為單位的整數。正負意義與 Reference3 相同。
- **Reference5**: ※僅 SSP　是否實際校正 OS 時鐘（SSP 2.9.40 以後）。已校正為 1，未校正為 0。啟用 OS 自動時間同步且時差在 60 秒以內時，交由 OS 處理，不進行校正。

**対応:** SSP 2.5.66
