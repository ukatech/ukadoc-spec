# OnSNTPCorrect

**カテゴリ:** 校時事件

使用[`\6`標籤](../../sakura-script/event/6.md)將本機時間修正為伺服器時間時觸發。

- **Reference0**: 連線目標伺服器名稱。
- **Reference1**: 以逗號分隔的伺服器端目前時間：年,月,日,時,分,秒（差異小於1秒時與本機時間相同）
- **Reference2**: 以逗號分隔的本機端目前時間：年,月,日,時,分,秒
- **Reference3**: 伺服器與本機的時間差。以秒為單位的整數。正值表示本機時間較慢，負值表示本機時間較快。
- **Reference4**: ※僅SSP　伺服器與本機的時間差。以毫秒為單位的整數。

**対応:** Materia / SSP / CROW
