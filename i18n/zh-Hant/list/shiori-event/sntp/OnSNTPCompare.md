# OnSNTPCompare

**カテゴリ:** 校時事件

與伺服器建立連線時觸發。若要執行時間修正，請回傳包含[`\6`標籤](../../sakura-script/event/6.md)的指令稿。

- **Reference0**: 連線目標伺服器名稱。
- **Reference1**: 以逗號分隔的伺服器端目前時間：年,月,日,時,分,秒（差異小於1秒時與本機時間相同）
- **Reference2**: 以逗號分隔的本機端目前時間：年,月,日,時,分,秒
- **Reference3**: 伺服器與本機的時間差。以秒為單位，且一律為正整數。
- **Reference4**: ※僅SSP　伺服器與本機的時間差。以毫秒為單位，且一律為正整數。

**対応:** Materia / SSP / CROW
