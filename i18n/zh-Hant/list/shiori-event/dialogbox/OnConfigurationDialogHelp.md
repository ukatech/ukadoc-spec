# OnConfigurationDialogHelp

**カテゴリ:** Dialog box events

Occurs when an item is clicked in the settings dialog's help button.

- **Reference0**: Dialog ID. The mapping between types and pages is as follows.
  - setup …… General
  - ghost …… Ghost (1)
  - ghost2 …… Ghost (2)
  - folder …… Folder
  - display …… Display
  - dictation …… Speech synthesis/recognition
  - talk …… Speech/balloon
  - network …… Connection (1)
  - network2 …… Connection (2)
  - biff …… Mail
  - application …… External applications
  - messenger …… IM
  - ipmessenger …… IPMessenger
  - international …… Internationalization
  - developer …… Development/Other
- **Reference1**: Dialog title.
- **Reference2**: Item type: item name.
- **Reference3**: Item content text.

**対応:** SSP
