# OnOSUpdateInfo

**カテゴリ:** OS 狀態事件

通知 OS 更新檢查時間、更新執行時間及歷史記錄資訊。<br />
啟動後立即以 NOTIFY（無法說話）通知，更新執行後稍晚會以 GET（可以說話）通知。

- **Reference0**: 檢查時間 年,月,日,時,分,秒 以半形逗號分隔的本地時間
- **Reference1**: 執行時間 年,月,日,時,分,秒 以半形逗號分隔的本地時間
- **Reference2～**: 後續會接上以下格式的更新歷史記錄資訊。\[`\1`\] 是位元組值 1。<br />
  狀態\[`\1`\]錯誤代碼\[`\1`\]更新時間\[`\1`\]更新內容（標題）<br />
  狀態：以下其中之一：not_started（未執行）・in_progress（更新中）・success（成功）・success_with_errors（大致成功，但有錯誤）・fail（失敗）・abort（中止）・unknown（不明）<br />
  錯誤代碼：更新時若發生錯誤則為非 0，否則為 0。Windows 中為 8 位十六進位數。<br />
  更新時間：年,月,日,時,分,秒 以半形逗號分隔的本地時間

**対応:** SSP 2.5.02
