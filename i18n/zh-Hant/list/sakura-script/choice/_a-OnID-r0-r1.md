# `\_a[OnID,r0,r1...]`

**カテゴリ:** 選項指令

將直到`\_a`為止的範圍設為錨點。選項不會逾時，但與一般對話相同，氣球會逾時。<br />
如上所述，ID 以「On」開頭時，點擊後會觸發 SHIORI 事件 OnID（即所寫的事件）。<br />
ID 後續的引數會依序存入 Reference0 以後。

**対応:** SSP / Ninix

## 記述例

```sakurascript
\_a[OnHint,0]ヒント\_aが欲しいならクリックしよう。\_a[OnHint,1]ほらほら早く\_a。この2つのアンカーは、クリックするとSHIORIイベントOnHintが通知されるが、クリックしたものによってReference0の値が「0」か「1」に変わる。
```
