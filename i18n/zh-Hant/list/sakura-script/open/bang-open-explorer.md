# `\![open,explorer,ファイル]`

**カテゴリ:** 開啟指令

使用 baseware 設定的檔案管理器開啟指定檔案。<br />
可在 owner draw 選單的 baseware 設定中，透過「外部應用程式 -\> 檔案管理器設定」指定。

若未指定檔案管理器，指定的項目若為資料夾則開啟該資料夾；若為檔案，則在檔案總管中選取該檔案。

指定為 `\![open,explorer,種類(ghost/shell/balloon/headline/plugin),名前]` 時，可用種類和名稱指定要開啟的資料夾。<br />
例：`\![open,explorer,ghost,Emily/Phase4]`

**対応:** SSP 2.5.12
