# `\![open,explorer,ファイル]`

**カテゴリ:** Open commands

Opens the file manager configured in the baseware, with the specified file.<br />
This is the file manager specified in “External Applications -> File Manager Settings” under the owner draw menu’s baseware settings.

If no file manager is specified, a specified folder is opened, or a specified file is selected in Explorer.

Specify `\![open,explorer,種類(ghost/shell/balloon/headline/plugin),名前]` to choose the folder to open by type and name.<br />
Example: `\![open,explorer,ghost,Emily/Phase4]`

**対応:** SSP 2.5.12
