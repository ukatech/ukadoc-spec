# `\![open,browser,パラメータ]`

**カテゴリ:** Open command

Open the browser configured in the baseware.<br />
This is the browser specified under "External applications -> Browser settings" in the owner draw menu's baseware settings.

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\![open,browser,http://ssp.shillest.net/]ばぐとら研究所をSSP本体設定で指定されたブラウザを立ち上げて表示する。
```
