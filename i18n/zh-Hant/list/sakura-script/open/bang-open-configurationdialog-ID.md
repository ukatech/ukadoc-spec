# `\![open,configurationdialog,ダイアログID]`

**カテゴリ:** Open command

Open the settings dialog ("Baseware settings" in the owner draw menu).<br />
The dialog ID can specify which screen to display initially (the last-opened screen is used if omitted).<br />
See Reference0 of SHIORI Event ※[OnConfigurationDialogHelp](../../shiori-event/dialogbox/OnConfigurationDialogHelp.md).

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\![open,configurationdialog,talk]SSP本体設定ダイアログの喋り/バルーンのタブを開く。
```
