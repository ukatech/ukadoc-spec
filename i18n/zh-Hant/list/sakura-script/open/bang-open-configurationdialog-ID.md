# `\![open,configurationdialog,ダイアログID]`

**カテゴリ:** 開啟命令

開啟設定對話方塊（owner draw 選單中的「baseware 設定」）。<br />
可透過對話方塊 ID 指定初始顯示的畫面（省略時會顯示上次開啟的畫面）。<br />
請參閱 SHIORI Event ※[OnConfigurationDialogHelp](../../shiori-event/dialogbox/OnConfigurationDialogHelp.md) 的 Reference0。

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\![open,configurationdialog,talk]SSP本体設定ダイアログの喋り/バルーンのタブを開く。
```
