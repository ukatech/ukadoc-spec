# `\![open,mailer,パラメータ]`

**カテゴリ:** Open commands

Opens the mailer configured in the baseware.<br />
This is the mailer specified in “External Applications -> Mailer Settings” under the owner draw menu’s baseware settings.

**対応:** Materia / SSP

## 記述例

```sakurascript
\![open,mailer,test@example.com]送信先アドレスにtest@example.comが入ったメーラーを開く。
```
