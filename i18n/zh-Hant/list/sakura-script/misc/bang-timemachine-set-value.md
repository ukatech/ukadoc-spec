# `\![timemachine,set,値]`

**カテゴリ:** 未分類指令

將「目前時間的虛擬變更」（時光機）的時間差設為指定值。ghost 所看到的目前時間（`system.year` 等屬性、[OnSecondChange](../../shiori-event/time/OnSecondChange.md) 等時間事件、日曆行程等）會隨之偏移。供測試依賴日期或時間的 ghost 使用。<br />
僅在啟動 SSP 時加上 `--allow-timemachine-control` 才有效。未加上時不會執行任何操作，並會在錯誤日誌中記錄警告（避免 ghost 的腳本改動整體時鐘）。無法從未經授權的 SSTP（外部的 SSTP）執行。<br />
時間差僅在本次執行期間有效，不會儲存至設定。此指令會將時間差設為指定值，而非加到目前的時間差上（多次執行相同指令的結果相同）。

- **值**: 指定時間差。可使用下列其中一種。省略值或無法解析時，會在錯誤日誌中記錄警告，不執行任何操作。
  - `+秒` / `-秒`: 時間差本身（秒數）。必須加上正負號。例如：`+86400`（1日後）、`-3600`（1小時前）
  - `0`: 將時間差設為0（維持實際時間）
  - ISO8601 格式的日期時間：計算與實際時間的差距，並將其設為時間差，使時間變為指定的日期時間。若未指定時區，則視為本地時間。時鐘不會停止，會從該日期時間繼續前進。例如：`2026-12-31T23:59:50`

時間差的大小上限約為200年。不到一秒的部分會捨去。<br />
跳轉時間時，若跳轉後的分鐘或小時與跳轉前不同，則在下一次的1秒處理中會觸發 [OnMinuteChange](../../shiori-event/time/OnMinuteChange.md) 或 [OnHourTimeSignal](../../shiori-event/time/OnHourTimeSignal.md) 等事件（跳轉至過去時也相同）。<br />
自動更新等間隔的計測、日誌、通訊等依實際時間運作的功能不受影響。

!!! note "註"
    也可透過啟動選項 `--time-shift` 指定啟動時的時間差。可透過屬性 `system.os.timeshift` 讀取目前的時間差。<br />
    若要不透過 ghost 腳本同步設定，請使用 SSTP EXECUTE 的 [SetTimeShift](../../../spec/sstp/method_execute.md)（需要相同格式的值及相同的啟動選項）。

**対応:** SSP 2.9.39

## 記述例

```sakurascript
\![timemachine,set,2026-12-31T23:59:50]
```

將時間設為2026年12月31日23時59分50秒，並從該時間繼續前進。可用於測試跨年事件等。

```sakurascript
\![timemachine,set,+86400]
```

將時間設為實際時間的1日後。
