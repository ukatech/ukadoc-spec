# `\![execute,websocket,URL,オプション,オプション,オプション...]`

**カテゴリ:** Uncategorized commands

Establish a WebSocket connection with [options](bang-execute-http-options-URL.note.md). SHIORI events are issued when the connection is established, when data is received, and when the connection is closed. Specify the parameter group in the same way as for rss-get.

**対応:** SSP 2.8.05
