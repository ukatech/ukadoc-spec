# `\![execute,rss-post,URL,オプション,オプション,オプション...]`

**カテゴリ:** Uncategorized commands

Send an HTTP POST request with [options](bang-execute-http-options-URL.note.md), parse the response as an RSS/Atom feed, and notify the parsed results as an event.<br />
The parsing, notification, and [filtering](bang-execute-rss-post-URL.note.md) specifications are the same as for [rss-get](bang-execute-rss-get-URL.md). Specify the parameter group in the same way as for http-post.

**対応:** SSP
