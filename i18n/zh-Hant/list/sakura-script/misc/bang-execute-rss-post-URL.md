# `\![execute,rss-post,URL,オプション,オプション,オプション...]`

**カテゴリ:** 未分類コマンド

使用[※選項](bang-execute-http-options-URL.note.md)執行 http post 請求，並將回應解析為 RSS/Atom feed，再將解析結果作為事件通知。<br />
解析、通知與[篩選](bang-execute-rss-post-URL.note.md)的規格與[rss-get](bang-execute-rss-get-URL.md)相同。參數群的指定方式與 http-post 相同。

**対応:** SSP
