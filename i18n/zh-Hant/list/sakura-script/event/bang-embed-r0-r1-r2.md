# `\![embed,イベント名,r0,r1,r2...]`

**カテゴリ:** 事件指令

這是一種特殊標籤，會將事件的執行結果**「嵌入」**目前執行中的 script 內。<br />
選項部分的用法與 `\![raise]` 相同，第 3 個引數起會依序存入 Reference0 以後的欄位。

執行時遇到 `\![embed]` 標籤，會呼叫指定的事件；若有傳回結果（Result），整個 `\![embed]` 標籤會被該結果字串取代，並從替換後字串的第 1 個字元繼續執行 script。<br />
（※此功能旨在更廣泛、通用地提供里々執行期間 SAORI 呼叫「sync」的機制。）

此功能最初是設計為搭配屬性系統使用：屬性系統呼叫本身不會傳回結果，而是透過緊接其後嵌入的 `\![embed]` 標籤，依結果動態變更處理方式，並在「單次 script 執行期間」完成。不過，並沒有這類限制；只要希望在 script 執行時同步進行其他處理，都可以使用此規格。

**対応:** SSP / Ninix

## 記述例

```sakurascript
このトークの最後に、SHIORIイベント「OnEmbedTest」の実行結果が表示される。raiseと違いスクリプトが1つなので、スクリプト終了で効果が切れるさくらスクリプト(フォント変更など)が持続する。\![embed,OnEmbedTest]
```

```sakurascript
里々のテンプレートでこのスクリプトを実行した場合は、この文の後にランダムトークがくっつく。\![embed,OnTalk]
```
