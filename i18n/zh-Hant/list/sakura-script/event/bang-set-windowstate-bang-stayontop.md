# `\![set,windowstate,!stayontop]`

**カテゴリ:** Event command

Do not display in front. From this script onward, stacking is handled in the same way as for other windows.

This setting remains in effect until the ghost exits.

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\![set,windowstate,!stayontop]このスクリプト以降、アクティブなウインドウが手前に表示されるようになる。
```
