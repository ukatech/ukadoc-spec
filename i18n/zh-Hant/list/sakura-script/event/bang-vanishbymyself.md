# `\![vanishbymyself]`

**カテゴリ:** 事件指令

不需發出消滅指示，即可解除安裝自己的 ghost。<br />
執行時不會顯示確認對話框等，而是立即執行，請注意。<br />
是否會執行刪除取決於使用者的 SSP 設定。

SSP 可指定以下選項<br />
`\![vanishbymyself,ゴースト名]` 指定刪除後切換到的 ghost（若找不到，SSP 會自動選擇適當的 ghost）<br />
`\![vanishbymyself,--option=query]` 2.5.82：顯示刪除確認對話框。與從選單執行時相同。

**対応:** Materia / SSP / Ninix

## 記述例

```
自分自身を削除。Send Boxからのサンプル入力での実行時は要注意。\![vanishbymyself]
```
