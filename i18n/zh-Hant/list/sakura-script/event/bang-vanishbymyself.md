# `\![vanishbymyself]`

**カテゴリ:** Event command

Uninstall the current ghost without a vanish request.<br />
Use with caution, as it executes immediately without displaying a confirmation dialog or similar prompt.<br />
Whether deletion is carried out depends on the user's SSP settings.

The following options can be specified in SSP<br />
`\![vanishbymyself,ゴースト名]` Specify the ghost to switch to after deletion (SSP automatically selects one as appropriate if it cannot be found)<br />
`\![vanishbymyself,--option=query]` 2.5.82 : Display a deletion confirmation dialog. Same as when run from the menu.

**対応:** Materia / SSP / Ninix

## 記述例

```
自分自身を削除。Send Boxからのサンプル入力での実行時は要注意。\![vanishbymyself]
```
