# `\_+`

**カテゴリ:** 事件命令

切換至下一個順序的 ghost（循序切換）。切換至 Ghost Explorer 中位於下方的 ghost。<br />
若目前位於清單最下方，則切換至清單最上方的 ghost。<br />
使用此 script 切換時，不會收到 SHIORI 事件[OnGhostChanging](../../shiori-event/boot-close-change/OnGhostChanging.md)通知。

**対応:** Materia / SSP / Ninix

## 記述例

```sakurascript
リストの次のゴーストへチェンジ。\_+
```
