# `\![anim,add,overlay,ID]`

**カテゴリ:** surface 指令

將 ID 編號的 surface 疊加在目前的 surface 上。

- **`\![anim,add,overlay,ID]`**：將 ID 編號的 surface 疊加在目前的 surface 上。
- **`\![anim,add,overlayfast,ID]`**：使用 overlayfast 將 ID 編號的 surface 疊加在目前的 surface 上。
- **`\![anim,add,base,ID]`**：將目前的基底 surface 變更為 ID 編號的 surface。
- **`\![anim,add,move,x,y]`**：將目前的 surface 移動到 XY 座標後顯示。
- **`\![anim,add,overlay,ID,x,y]`**：將 ID 編號的 surface 移動到 XY 座標後，疊加在目前的 surface 上。
- **`\![anim,add,overlay,ID,x,y,表示時間,ID,x,y,表示時間,ID,x,y,表示時間...]`**：將疊加的 surface 製作成動畫。（時間單位為 ms）
- **`\![anim,add,overlay,ID,x,y,表示時間,ID,x,y,表示時間,ID,x,y,表示時間,アニメーションタイミング]`**：動畫時機可指定 runonce 或 always。

**対応:** CROW
