# `\![set,scaling,横倍率,縦倍率,オプション]`

**カテゴリ:** surface 指令

精確調整 surface 的倍率。倍率單位為%。<br />
可透過選項指定動畫時間，或等待動畫完成。

- --time=毫秒……動畫時間（毫秒）。省略或指定負值時為0（立即套用）。也可作為位置參數指定（為了向後相容）。
- --wait……等待指令執行，直到動畫完成。省略時為非同步（立即進入下一個處理）。適用於 SSP 2.7.52 以後。

**対応:** CROW / SSP 2.7.31

## 記述例

```sakurascript
\![set,scaling,200,200,--time=2000]2秒かけて200%へ変化する（非同期）。
```

```sakurascript
\![set,scaling,200,200,--time=3000,--wait]3秒かけて200%へ変化する（完了まで待機）。
```

```sakurascript
\![set,scaling,100,100,--time=1000,--wait]1秒かけて等倍に戻す（完了まで待機）。
```
