# `\![set,alpha,數値,オプション]`

**カテゴリ:** surface 指令

將目前 scope 的 surface 透明度變更為 0～100。0 為完全透明，100 為不透明。超過 100 的值會限制為 100。負值只會重新繪製，不會變更數值。<br />
可透過選項指定動畫時間，或等待動畫完成。<br />
持續有效，直到 ghost 結束。

- --time=毫秒……動畫時間（毫秒）。省略時或指定負值時為 0（立即套用）。也可作為位置參數指定（為了向下相容）。
- --wait……等待指令執行至動畫完成。省略時為非同步（立即進入下一個處理）。適用於 SSP 2.7.52 及更新版本。

**対応:** SSP

## 記述例

```sakurascript
\0\![set,alpha,0]本体側が透明になり見えなくなる。\1\![set,alpha,50]相方側がだいたい半透明になる。
```

```sakurascript
\![set,alpha,50,--time=1000]1秒かけて透過度50へ変化する（非同期）。
```

```sakurascript
\![set,alpha,50,--time=2000,--wait]2秒かけて透過度50へ変化する（完了まで待機）。
```

```sakurascript
\![set,alpha,100,--time=1000,--wait]1秒かけて不透明に戻す（完了まで待機）。
```
