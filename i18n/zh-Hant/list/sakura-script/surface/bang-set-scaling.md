# `\![set,scaling,倍率]`

**カテゴリ:** Surface command

Change the surface's scaling factor.

Change the surface's scaling factor. The unit is %.<br />
The scaling factor is relative to the user's setting of 100%.<br />
Negative values are allowed; -100 flips the surface along that axis.

Valid until the ghost ends.

**対応:** SSP / CROW

## 記述例

```sakurascript
\![set,scaling,50]本体側のサーフェスの大きさが、50%になる。
```
