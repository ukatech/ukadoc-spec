# `\f[height,数値]`

**カテゴリ:** Text change command

Changes this text to the specified font size.<br />
Relative changes using + or - are possible.<br />
Stylesheet size specifications are also supported.<br />
Specify default to restore the balloon's default setting.

**対応:** SSP / Ninix

## 記述例

```sakurascript
\f[height,15]15pixelで表示。\f[height,+3]3pixel大きくする。\f[height,200%]デフォルトサイズの200%で表示。\f[height,default]元のサイズに戻す。
```
