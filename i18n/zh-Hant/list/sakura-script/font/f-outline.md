# `\f[outline,パラメータ]`

**カテゴリ:** Text change command

Set the parameter to true or 1 to enable outline text.<br />
Set the parameter to false or 0 to disable it.<br />
Specify default to restore the balloon's default setting.<br />
Specify disable to use the same settings as disabled text display.

**対応:** SSP

## 記述例

```sakurascript
\f[height,30]\f[outline,1]白抜きにする。\f[outline,default]バルーンのデフォルト設定にもどす。
```
