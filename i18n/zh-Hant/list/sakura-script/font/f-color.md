# `\f[color,色指定]`

**カテゴリ:** Text change command

Changes the text color.<br />
For details on how to specify the color, see [※refer below](../choice-marker/note-1.md#形状指定の方法).

**対応:** SSP / Ninix

## 記述例

```sakurascript
\f[color,red]赤色で表示。\f[color,100,150,200]色指定で表示。\f[color,default]バルーンのデフォルト色に戻す。
```
