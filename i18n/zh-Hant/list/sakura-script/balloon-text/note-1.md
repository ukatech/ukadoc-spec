# 補充說明

## 關於 `\_b[ファイルパス,...]`

除了絕對路徑外，也可使用相對於 SHIORI 本體的路徑。

※僅 SSP 支援；檔名等路徑也可使用環境變數。

- **使用 base64 時**: 例: "data:image/png;base64,iV～II"
- **使用 exe/dll 資源時**: 例: D:\\hogehoge.exe,20
- **使用 exe/dll 資源時（指定資源 ID）**: 例: D:\\hogehoge.exe,-10

## `\_b[ファイルパス,...]`的選項

`\_b[ファイルパス,x,y,オプション,オプション...]` 和 `\_b[ファイルパス,inline,オプション,オプション...]` 都可指定的選項。

- **--option=opaque**: 顯示時不將左上角的顏色設為透明。
- **--option=use_self_alpha**: 以透明方式顯示含有 Alpha 通道的 PNG。
- **--clipping=左 上 右 下**: 將影像的一部分裁切成矩形後顯示。<br />
  以左、上、右、下的數值指定裁切範圍。
- **--scaling=横 縦**: 將影像放大或縮小至指定尺寸後顯示。<br />
  數值末尾加上 % 時，表示相對於原始影像（套用 --clipping 裁切後）的百分比；未指定單位或末尾加上 px 時，則視為像素數。<br />
  若數值為負數，則以其絕對值作為尺寸，並左右或上下翻轉後顯示。<br />
  若橫向或縱向其中一方指定為 0，則配合另一方非 0 的尺寸，在維持原始影像長寬比的情況下縮放。（原始影像為 300x200 時，150 0 的結果與 150x100 相同）\[SSP 2.8.82～\]<br />
  可指定的尺寸限制在 1～4096px。<br />
  \[SSP 2.8.73～\]
- **--scaling=サイズ 基準辺**: 在維持原始影像長寬比的情況下縮放，使基準邊符合指定尺寸。尺寸只能以像素數指定，不能使用 %。<br />
  基準邊可指定 long（長邊）或 short（短邊）。<br />
  在基準邊末尾加上 max 時，只縮小（小於指定尺寸的影像不放大）；加上 min 時，只放大（大於指定尺寸的影像不縮小）。<br />
  省略 long 或 short，只寫 max 或 min 時，會視為指定 long。<br />
  若尺寸為負數，則以其絕對值作為尺寸，並同時左右、上下翻轉後顯示。<br />
  可指定的尺寸限制在 1～4096px。<br />
  例：--scaling=300 long 表示原始影像為 400x300 時，會縮放為 300x225。<br />
  例：--scaling=300 longmax 表示只有長邊超過 300px 時才縮小至 300px。<br />
  \[SSP 2.8.82～\]
- **--option=fixed**: 捲動時不移動影像。<br />
  僅在指定 x,y 時有效。指定 inline 時，影像會配置在行內，因此此選項無效。
- **--option=background**: 合成顯示時，優先採用氣球的透明度，而非影像的透明度。\[未指定時的標準規格\]<br />
  指定 x,y 時，影像會顯示在文字下方。使用此選項即可將影像作為文字背景。
- **--option=foreground**: 合成顯示時，優先採用影像的透明度，而非氣球的透明度。\[SSP 2.6.54～\]<br />
  指定 x,y 時，影像會顯示在文字前方。
- **--source=値**: 從含有多個可繪製候選項目的影像或檔案中，指定實際要繪製的項目。<br />
  多頁 TIFF 時指定從 0 起算的頁碼；DLL/EXE 內的圖示時指定從 0 起算的資源編號；<br />
  PSD 等檔案則指定圖層名稱。<br />
  若要指定圖層群組中的圖層，請以 :: 分隔並寫上群組名稱（支援群組巢狀）。<br />
  \[SSP 2.8.41～\]
