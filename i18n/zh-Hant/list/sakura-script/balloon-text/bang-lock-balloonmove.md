# `\![lock,balloonmove]`

**カテゴリ:** balloon, text command

Suppress user drag-movement of balloons until `\![unlock,balloonmove]` is called.<br />
This can be set permanently in descript.txt, for example with [sakura.balloon.dontmove](../../../descript/shell/descript-txt/sakura.balloon.dontmove_.md).<br />
Do not overuse this, as it interferes with user interaction.

**対応:** SSP 2.4.96
