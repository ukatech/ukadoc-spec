# `\__v[オプション]`

**カテゴリ:** バルーン、テキストコマンド

調整直到下一個 `\__v` 為止的字串之語音合成內容。<br />
`\__v[disable]`：停用語音合成<br />
`\__v[alternate,文字列]`：為讀音不同的詞指定正確的發音字串。為避免誤讀，建議使用平假名。

\[僅限 SSP\]此效果也會影響回顧記錄（發言歷史）。<br />
`\__v[disable]` 區段不僅不會進行語音合成，也不會記錄到回顧記錄中。<br />
`\__v[alternate,文字列]` 區段會以指定字串取代一般文字，記錄到回顧記錄中，無論是否啟用語音合成都適用。

**対応:** SSP 2.4

## 記述例

```sakurascript
\1\__v[disable]この文章は音声合成機能でしゃべらない。\__v
```
