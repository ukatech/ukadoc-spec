# sound play/load/option 的選項

- **--volume=0～100**: 變更播放音量。Max 為 100。但不會操作整個 OS 的音量。
- **--balance=-100～0～100**: 左右平衡。-100 為最左，100 為最右。
- **--rate=1～100～10000**: 播放速度。100 為正常速度。<br />
  實際可指定的範圍取決於音效驅動程式等的實作，通常指定約 400 以上（435 以上）時會發生錯誤。
- **--seektime=時刻 \[2.8.70/72\]**: 指定播放開始位置。play 時會先搜尋到指定位置，再開始播放。option 時，若正在播放，會跳到該位置並繼續播放；若處於暫停狀態，則會在內部搜尋到該位置並待命（不會開始播放）。<br />
  load 時會在搜尋到指定位置後待命，並將該位置保留至下次 play。但若檔案已經 load，再次指定 load 並不會改變位置。此時請使用 option。<br />
  時刻有兩種格式：不包含「:」時，會解讀為以毫秒為單位的整數；包含「:」時，會解讀為\[\[時:\]分:\]秒\[.毫秒\]。「90500」、「1:30.5」和「0:01:30.5」都表示 1 分 30.5 秒。<br />
  小數點以下最多取 3 位（毫秒），第 4 位以後會捨去。指定無法解讀的格式或負值時，會視為 0（檔案開頭）。<br />
  某些檔案格式可能無法搜尋，此時會忽略指定並從檔案開頭播放。特別是 wav 僅支援未壓縮的 PCM/IEEE float，ADPCM 等壓縮 wave 無法搜尋。<br />
  在開頭加上 @ 會改為從目前播放位置起算的相對位置。此時也可以指定負值。
- **--window=false/true (=OFF/ON)**: 是否顯示附有搜尋列的視窗。指定 true 時，即使只有音訊也會強制顯示。未指定時，只有音訊則不顯示，影片則顯示。
- **--sound-only=false/true (=OFF/ON)**: 僅限 load 時：可以只播放影片檔的音訊。未指定時與 false 相同。
- **--spectrum=間隔 \[2.9.18\]**: 透過[OnSoundSpectrum](../../shiori-event/other/OnSoundSpectrum.md)事件，以指定的間隔（毫秒）通知播放中音訊的頻譜（各頻帶的音量）。可指定範圍為 20～1000，1～19 會限制為 20，1001 以上會限制為 1000。\[2.9.33\] Windows 10 (1803) 以後，間隔會精確計時並依指定值送達（即使處理延遲，週期也不會偏移；ghost 處理不及時，通知會被略過而不會累積）。2.9.32 以前及更舊的 OS，實際間隔會受到 OS 計時器刻度（通常約為每 15.6 毫秒一次）影響，間隔越短就越無法符合指定值（指定 100 時約每 111 毫秒一次）。指定 0（負值也相同）會停止通知。未指定時不會通知。<br />
  播放期間也可以隨時使用 option 開始或停止通知，或變更間隔。若在播放途中開始，開始後短時間內的頻帶值有時會偏小。
- **--spectrum-bands=0/5/10/15/31 \[2.9.18\]**: --spectrum=通知的頻帶數。指定 0、5、10、15、31 其中之一（指定其他數值時會使用最接近的值。例如：16 會使用 15、20 會使用 15、64 會使用 31）。未指定時為 10。播放期間也可以變更。<br />
  \[2.9.19\] 指定 0 時，不會分析各頻帶，只會通知各聲道的整體音量（[OnSoundSpectrum](../../shiori-event/other/OnSoundSpectrum.md) 的 Reference2・3）和播放位置（Reference6）。可用於附有音量資訊的經過時間通知。即使是 MIDI、CD 音軌等無法取得波形的音訊，也會通知播放位置（音量為 0）。<br />
  各頻帶的頻率會依頻帶數，按照固定的表格決定，如[下表](bang-sound-option.note-2.md)所示。
- **--spectrum-hold=毫秒 \[2.9.18\]**: --spectrum=通知的峰值保持值（[OnSoundSpectrum](../../shiori-event/other/OnSoundSpectrum.md) 的 Reference3・5）的保持時間。範圍為 0～10000，未指定時為 500。指定 0 時不保持峰值（峰值會與目前值相同）。播放期間也可以變更。<br />
  每當目前值超過峰值時，峰值就會升至該值並重新計算保持時間；在保持時間內不會變動，時間一到，就會以每秒 100（至 0 的全幅）的速度下降。下降途中若目前值追上峰值，就會從該處重新開始相同的動作。
- **--spectrum-skipbusy=false/true (=OFF/ON) \[2.9.33\]**: 使用 --spectrum= 通知時，若 ghost 的 script 正在播放或等待播放，就不發送通知（略過通知）。未指定時為 false。播放期間也可以變更。<br />
  [OnSoundSpectrum](../../shiori-event/other/OnSoundSpectrum.md) 傳回的 script，除非在開頭加上`\C`，否則會中斷正在播放或等待播放的 script（包括其他事件傳回的 script）。由於通知頻繁，有時會在執行標籤之前，覆蓋每秒事件等傳回的 script。指定此選項可避免這種情況。<br />
  被略過的通知不會送達（下一個間隔若有空檔，便會再次發送）。播放或停止時所有音量值皆為 0 的通知不會被略過。<br />
  此選項無法避免的情況是，ghost 正在播放通知的 script 時發生的 OnSecondChange 等事件，會和一般事件一樣成為無法傳回 script 的 NOTIFY。
- **--eq=增益:增益:… \[2.9.29\]**: 圖形等化器。依低音頻帶至高音頻帶的順序，以`:`分隔並列出各頻帶的增益（dB）。例如：`\![sound,play,bgm.wav,--eq=-12:-12:-6:0:0:0:6:12:12:12]`<br />
  列出的項目數就是頻帶數，必須是 5、10、15、31 其中之一。各頻帶的頻率與 --spectrum-bands= 使用相同的[固定表格](bang-sound-option.note-2.md)，並與頻譜顯示的頻帶一一對應（10 個頻帶時為 32、64、125、…、16kHz）。增益可以是整數或小數，也可以加上正負號。範圍會限制在 -24～24（超出範圍時會使用端點值）。所有頻帶皆為 0 時不會加工音訊。不能使用逗號作為分隔符（因為逗號會成為 `\![sound,…]` 的引數分隔符）。<br />
  只指定 `--eq=`（值為空）時，所有頻帶會恢復為 0dB。項目數不是 5、10、15、31 其中之一，或包含無法解讀為數值的項目時，會忽略整個指定並維持目前設定。<br />
  播放期間也可以隨時使用[`\![sound,option,…]`](bang-sound-option.md)變更。變更會在約 10 毫秒內平順完成，因此不會產生爆音。此指定僅套用於該音訊；播放結束後重新播放同一檔案時，不會沿用此設定。<br />
  各頻帶的設定會讓其中心頻率處的音量恰好符合指定增益（並會補償與相鄰頻帶的重疊）。頻帶之間的音量會隨增益調整幅度而稍有偏差（±12dB 時約差 1dB）。在許多交界處，偏差會朝 0dB 靠近指定值（提高時稍低，降低時稍淺）。太接近取樣率一半（奈奎斯特頻率）的頻帶不會生效。<br />
  等化器會在 --volume 和 --balance 之前，以及[OnSoundSpectrum](../../shiori-event/other/OnSoundSpectrum.md)分析之前套用。因此，等化器也會反映在 OnSoundSpectrum 的值中。MIDI、CD 音軌等無法取得波形的音訊不會生效。
- **--eq-preamp=增益 \[2.9.29\]**: 等化器的整體增益（dB）。範圍會限制在 -24～24（超出範圍時會使用端點值），未指定時為 0。提高頻帶後若音訊失真（音量過大而達到削波），可用此選項降低整體音量以避免失真。可與 --eq= 分開指定；即使未指定 --eq= 也會生效。播放期間也可以變更。
