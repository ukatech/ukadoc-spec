# `\!`\[sound,play,ファイル名,[オプション](bang-sound-option.note.md)...\]

**カテゴリ:** 音效指令

功能與 `\_v` 相同，但可以指定[選項](bang-sound-option.note.md)。

**対応:** SSP（選項自 2.4 起支援）/ Ninix

## 記述例

```sakurascript
\![sound,play,test.mp4,--sound-only=true,--window=true][実行したゴーストのフォルダ]/ghost/masterフォルダにあるtest.mp4動画を再生する。ただしシークバー強制表示、音声のみ。
```
