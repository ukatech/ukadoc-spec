# `\_V`

**カテゴリ:** Sound command

Wait for playback of the file in `\_v` to finish.<br />
If playback has already finished or the file does not exist, this command is ignored.

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\_v[test.wav][実行したゴーストのフォルダ]/ghost/masterフォルダにあるtest.wavを再生する。\_V再生が終了するまで待ってからこの文章を表示する。
```
