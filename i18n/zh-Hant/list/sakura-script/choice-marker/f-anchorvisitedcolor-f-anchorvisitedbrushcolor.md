# `\f[anchorvisitedcolor,色指定]`或`\f[anchorvisitedbrushcolor,色指定]`

**カテゴリ:** 選項標記變更命令

變更已造訪 anchor 矩形內的顏色。請注意，顏色會受 `\f[anchorvisitedmethod,描画方法]`的效果影響。<br />
指定方法請參閱[※下方說明](note-1.md#形状指定の方法)。

**対応:** SSP

## 記述例

```sakurascript
\f[anchorvisitedbrushcolor,red]\_a[OnTest]アンカー\_a訪問済みのアンカーの形状がsquareの場合、背景色が赤色になる。
```
