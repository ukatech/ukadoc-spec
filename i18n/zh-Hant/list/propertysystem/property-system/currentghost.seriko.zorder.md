# currentghost.seriko.zorder

**カテゴリ:** 屬性系統

目前[`\![set,zorder,～]`](../../sakura-script/surface/bang-set-zorder-ID-ID.md)的設定狀態。<br />
以逗號分隔群組內的元素，並以分號分隔各群組。元素依照由前至後的順序排列。<br />
在明確指定元素的模式中，會以 `s0,b0,s1;s2,b2` 這樣的格式傳回，其中 `s`（surface）・`b`（balloon）加上 scope ID 的簡寫。<br />
在僅指定 scope ID 的舊模式中，會以 `0,1;2,3` 這樣的格式傳回純數字。<br />
若沒有任何設定，則沒有值。<br />
*\[SET有效\]*

寫入時會以相同格式**完全取代目前的設定**。請注意，這與 Sakura Script 標籤逐一新增群組的方式不同。<br />
寫入空字串會解除所有 Z-order 設定。<br />
將讀取的值原樣寫回，即可還原原本狀態。<br />
元素少於 2 個的群組會被忽略。此外，明確指定模式與舊模式互斥，因此**無法混用兩種模式**，例如 `s0,b0;2,3`。

**対応:** SSP 2.8.78
