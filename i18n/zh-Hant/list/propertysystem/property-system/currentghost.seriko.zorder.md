# currentghost.seriko.zorder

**カテゴリ:** 屬性系統

目前的 [`\![set,zorder,～]`](../../sakura-script/surface/bang-set-zorder-ID-ID.md) 設定狀態。<br />
群組內的元素以逗號分隔，群組之間以分號分隔。元素依由前至後的順序排列。<br />
在明確指定元素的模式下，會以 `s0,b0,s1;s2,b2` 的形式，回傳 `s`（surface）或 `b`（balloon）加上 scope ID 的縮寫。<br />
在僅指定 scope ID 的傳統模式下，會以 `0,1;2,3` 的形式只回傳數值。<br />
在指定 `front`、`back` 的模式下，會以 `front,0,1;back,3` 的形式，將前方與後方以分號分隔後回傳。若只指定其中一方，則只回傳該部分。<br />
若沒有任何設定，則無值。<br />
*\[SET 有效\]*

寫入時會以相同格式**完全取代目前的設定**。請注意，這與 Sakura Script 標籤逐一新增群組的行為不同。<br />
寫入空字串會解除所有 Z 順序設定。<br />
將讀取的值原樣寫回，即可還原原本的狀態。<br />
元素少於 2 個的群組會被忽略（`front`、`back` 可以只有 1 個）。此外，明確指定模式與傳統模式互斥，因此**不能混用兩種模式**，例如 `s0,b0;2,3`。`front`、`back` 也不能與其他模式混用，混用時會採用後寫入的指定。

**対応:** SSP 2.8.78/2.9.35（front,back 寫法）
