# system.network.(キー)

**カテゴリ:** プロパティシステム

網路連線狀態。可填入 (キー) 的字串如下。

- **status**: 網路連線狀態。online（已連線）或 offline（未連線）。
- **ipaddress**: 本機 IP 位址。
- **type**: 連線類型。可為 bluetooth、cellular、ethernet、none、wifi、wimax、other 或 unknown。
- **cost**: 連線費用類別。可為 unknown（未知）、unrestricted（不受限）、fixed（固定費率）或 variable（依用量計費）。
- **downlink**: 下行最大連線速度（Mbps）。
- **downlink.estimate**: 下行估計連線速度（Mbps）。根據實測計算，較為保守的估計值。

**対応:** SSP 2.8.17
