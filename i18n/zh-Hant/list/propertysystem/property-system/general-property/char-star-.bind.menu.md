# char\*.bind.menu

**カテゴリ:** Property System \> General property names

(Only valid for currentghost) The hidden state of the item in the dressup menu for the target shell's scope number \*.<br />
hidden when set to hidden, auto in auto-enumeration mode, or none otherwise<br />
*\[SET enabled\]* The initial value is [char\*.menu](../../../../descript/shell/descript-txt/char-star-.menu.md) in the shell's descript.txt.

**対応:** SSP
