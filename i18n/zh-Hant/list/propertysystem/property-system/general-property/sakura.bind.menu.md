# sakura.bind.menu

**カテゴリ:** Property System \> General property names

(Only valid for currentghost) The hidden state of the item in the dressup menu for the target shell's main-character scope.<br />
hidden when set to hidden, auto in auto-enumeration mode, or none otherwise<br />
*\[SET enabled\]* The initial value is [sakura.menu](../../../../descript/shell/descript-txt/sakura.menu.md) in the shell's descript.txt.

**対応:** SSP
