# system.power.(キー)

**カテゴリ:** プロパティシステム

電源與電池狀態。可填入 (キー) 的字串如下。在無法取得資訊的環境（包括桌上型電腦等沒有電池的情況）中，各值會是下列「無法取得時」的值。

- **source**: 目前的電源來源。可為 battery（電池供電）、ac（AC 電源／連接插座）或 ups（透過 UPS 供電）。無法取得時為 unknown。
- **battery.percent**: 電池剩餘電量（％，整數）。無法取得或剩餘電量不明時為 -1。
- **battery.lifetime**: 僅以電池供電時可運作的剩餘時間（秒）。無法取得或剩餘時間不明時為 -1。
- **battery.flag**: 電池狀態旗標。以逗號分隔列出符合的狀態。可能的值為 high（電量充足）、low（電量偏低）、critical（電量危急）、charging（充電中）、no_battery（無電池）、power_saving（已啟用電池節能功能，僅限 Windows 10 以後）。無法取得時為空字串。

**対応:** SSP 2.8.17
