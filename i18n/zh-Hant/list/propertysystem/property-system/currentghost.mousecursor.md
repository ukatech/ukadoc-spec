# currentghost.mousecursor

**カテゴリ:** プロパティ系統

表示 ghost 可操作區域的游標檔名（指尖）<br />
以下以currentghost.mousecursor / currentghost.balloon.mousecursor開頭的屬性皆適用：<br />
相對路徑會依序搜尋 shell → ghost 資料夾。<br />
以空字串執行SET時，會視為刪除定義，並可恢復成SET前的顯示方式。<br />
游標可使用與[surfaces.txt的cursor區段](../../../descript/shell-surfaces/cursor-brace/introduction_cursorbrace.md)相同的指定方式。<br />
*\[SET有效\]*

**対応:** SSP \[2.6.11\]
