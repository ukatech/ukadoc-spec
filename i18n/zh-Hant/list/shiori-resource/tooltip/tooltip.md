# tooltip

**カテゴリ:** 工具提示類

取得 shell 的工具提示內容。<br />
滑鼠游標移到 shell 的 surface 上時通知。<br />
若有[ shell 端設定](../../../descript/shell-surfaces/tooltip-brace/entry.md)，則以該設定為優先。

- **Reference0**: 滑鼠游標的 x 座標（區域座標）
- **Reference1**: 滑鼠游標的 y 座標（區域座標）
- **Reference2**: 一律為 0。
- **Reference3**: 本體為 0，搭檔為 1。SSP/CROW 中也有 2 以上的值。
- **Reference4**: 命中區域識別碼。
- **Reference5**: 一律為 0。

**対応:** SSP
