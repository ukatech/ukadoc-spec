# kero.popupmenu.applybindtoself

**カテゴリ:** Ghost information

Changes the behavior of the dressup menu when the owner-draw menu type is changed.<br />
Change according to the menu type = 0; show the dressup menu for the scope (character ID) the menu belongs to = 1<br />
The default is 1, which differs from the behavior before SSP 2.7.25. To restore the previous behavior, explicitly set this to 0.

**対応:** SSP 2.7.26
