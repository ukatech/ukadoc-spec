# internal_system

列出內建模組並說明函式的呼叫方式。可用來從 script 確認哪些函式可用，以及可用的選項或演算法名稱。<br />
清單只會列出名稱以`internal_`開頭的模組（不包含[相容模組](../compat.md)）。<br />
`ListModules` / `ListFunctions`的結果會以逗號分隔，放在`Result`中，並從`Value0`開始逐一放入。排序順序沒有特別意義。
