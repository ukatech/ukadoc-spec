# Format

**カテゴリ:** internal_time

將日期時間格式化為`--tz=`時區的日期時間。星期與月份名稱固定使用英文（不受語言或地區設定影響）。

- **Argument1**: 日期時間
- **Argument2**: 格式（省略或為空時使用`iso8601`）
- **選項**: `--tz=`

格式可使用以下名稱或使用`%`的格式。未知格式名稱或未知的`%`字元會回傳 400（`invalid parameter`）。

- **iso8601 / rfc3339**: `2026-10-11T21:00:00+09:00`。偏移量為 0 時，結尾為`Z`。
- **http**: `Sun, 11 Oct 2026 12:00:00 GMT`。不論`--tz=`設定為何，一律使用 GMT。
- **epoch / epochms**: Epoch 秒 / Epoch 毫秒。
- **%格式**: `%Y`（西元 4 位數） `%y`（西元年份後 2 位數） `%m`（月） `%d`（日） `%H`（時） `%M`（分） `%S`（秒） `%j`（一年中的第幾天） `%u`（星期，週一=1～週日=7） `%w`（星期，週日=0～週六=6） `%a`（Sun） `%A`（Sunday） `%b`（Jan） `%B`（January） `%z`（+0900） `%:z`（+09:00） `%s`（Epoch 秒） `%%`（%）。<br />
  `%`以外的字元會原樣輸出。

## 記述例

```
Argument0: Format
Argument1: 0
Argument2: %Y/%m/%d %H:%M (%a)
Argument3: --tz=+09:00

→ Result: 1970/01/01 09:00 (Thu)
```

**対応:** SSP 2.9.13
