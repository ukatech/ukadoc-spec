# 欄位詳細說明

updates2.dau與updates.txt的 `file,` 行所共用的欄位定義。

- **必要欄位**:

  - **檔案路徑 (位置\[0\])**: 更新目標檔案的相對路徑。以斜線 (`/`) 分隔。
  - **MD5雜湊 (位置\[1\])**: 檔案內容的MD5雜湊。由32個字元組成的十六進位字串。

- **擴充欄位 (位置\[2\]以後)**: 以 `key=value` 格式記述。皆可省略。

  - **size=數值**: 檔案大小（以位元組為單位）。
  - **date=字串**: ISO 8601格式的日期時間字串。例: `2024-01-15T12:34:56`
  - **charset=字串**: 字元編碼名稱。只會附加在updates2.dau第一個項目的末尾。僅用於判定字元編碼，讀取為定義檔時會忽略。
