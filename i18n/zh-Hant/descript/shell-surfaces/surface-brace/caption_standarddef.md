# サーフェス ID 的配置

要將哪些サーフェス ID 配置給何種表情或內容，基本上可以自由決定。

但 surface0、surface10 分別是必要的預設サーフェス，即使是沒有搭檔的 ghost，也必須準備透明圖片等作為 surface10（僅 SSP 不要求必須提供；也可以透過 descript 等設定變更預設サーフェス）。

此外，也有一套可視為「事實上的標準」的 ID 配置方式，列於下方。以下配置（除了 0、10 以外）並非必要，只供參考；基本上可以自由決定。

sakura 側

- 00 平常
- 01 害羞
- 02 驚訝
- 03 不安
- 04 消沉
- 05 微笑
- 06 閉眼
- 07 生氣
- 08 冷笑
- 09 害羞又生氣
- 25 歌唱

kero 側

- 10 平常
- 11 睜大眼睛
- 19 歌唱

另外，MATERIA 中可用於 surfaceID 的數字範圍限制為 0 到 8192。
