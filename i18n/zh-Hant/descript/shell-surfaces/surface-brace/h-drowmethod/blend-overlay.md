# blend-overlay

**カテゴリ:** surface brace \> Drawing method

Overlay the *new layer* using overlay compositing.<br />
This is equivalent to the Overlay layer blending mode in image editing software such as Photoshop.<br />
This is unrelated to the [overlay](overlay.md) method; dark areas use multiply compositing and light areas use screen compositing.<br />
Can also be used with dressup and element.<br />
It is recommended to set [`seriko.use_self_alpha,full`](../../../shell/descript-txt/seriko.use_self_alpha.md) in the shell's descript.txt.

**対応:** SSP 2.8.36
