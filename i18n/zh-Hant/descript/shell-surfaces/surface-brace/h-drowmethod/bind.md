# bind

**カテゴリ:** surface brace \> drawing method

Uses the *new layer* as a dressup part.<br />
This was the only method available when dressup parts could only be made by simply overlaying a single surface. It is now compatible with add.<br />
Its processing is equivalent to [overlay](overlay.md).<br />
Use in animations or elements that are not dressups is undefined.

**対応:** Materia / SSP
