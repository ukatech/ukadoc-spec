# base

**カテゴリ:** surface brace \> drawing method

Completely replaces the [base surface](../caption_basesurface.md) with the *new layer*. Collision is also updated to the one defined for the frame's surface.<br />
Stacking patterns with this method enables animation by redrawing the entire surface (in effect, a flipbook).<br />
In a pattern definition that specifies this drawing method, XY coordinates are ignored.<br />
For dressups and elements, the base method can be used only for the first one (element0, pattern0). In all other cases, it is interpreted as overlay.

**対応:** Materia / SSP / CROW
