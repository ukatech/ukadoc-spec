# surface\* 區塊可使用的 ID 指定方式

以下各種記法可以併用，且都僅適用於 SSP。

- **列舉指定「,」**:

  ```
  surface1,3,4,6,12
  {
  // 略
  }
  ```

  如此使用「,」分隔指定 ID，即可對多個サーフェス套用相同內容的定義。

- **範圍指定「-」**:

  ```
  surface1-12
  {
  // 略
  }
  ```

  如此使用「-」指定 ID，即可對編號連續範圍內的多個サーフェス（本例為 surface1 到 surface12）套用相同內容的定義。

- **排除範圍指定「!」**:

  ```
  surface1-30,!15,!20-25
  {
  // 略
  }
  ```

  如此在「!」後指定單一 ID 或 ID 範圍，該 ID 就會從定義對象中排除（本例等同於指定 surface1-14,16-19,26-30 等範圍）。<br />
  此外，以 ! 排除的指定不受書寫位置影響，優先於其他指定（例如 surface1-10,!2-4,3，即使在 ! 之後再加上 3，3 仍會被排除）。

在 materia 原本的規格中，只允許使用以下這種附有 surface 的列舉指定方式。

```
surface1,surface3,surface4
{
// 略
}
```
