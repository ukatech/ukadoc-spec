# animation\*.option, options

**カテゴリ:** surface brace

The exclusive, background, and shared-index options can be specified together, with multiple options separated by +. Example: exclusive+background<br />
The \* following animation is the animationID (the same as the \* in animation\*.interval).<br />
When specified as animation\*.option,exclusive+background,(1,3,5), only *exclusive* is affected.<br />
Note that exclusive is undefined for animations whose interval is bind.

**既定値:** No behavior

**対応:** SSP
