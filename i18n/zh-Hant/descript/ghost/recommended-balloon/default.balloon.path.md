# default.balloon.path,路徑

**カテゴリ:** descript.txt - 推薦 balloon

預設使用的 balloon 的相對路徑。<br />
也可寫在 shell 的 descript.txt 的 [default.balloon.path](../../shell/descript-txt/default.balloon.path.md) 中。切換至該 shell 時，若使用者未明確切換 balloon，則以 shell 端的指定為優先。

**既定値:** 不明 | SSP balloon 或使用者設定的預設 balloon（在 SSP 上）

**対応:** SSP
