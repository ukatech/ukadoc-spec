# sstpmessage.yb,coordinate [\*1](../index.md#balloon設定)

**カテゴリ:** descript.txt

The Y coordinate where the SSTP message display ends. Measured from the top. (If a negative value is specified, measured from the bottom.)<br />
Used only for vertical writing ([vertical](vertical.md) is 1); ignored for horizontal writing.<br />
In vertical writing, characters flow from top to bottom, so specify the display end position with the Y coordinate, not the X coordinate of [sstpmessage.xr](sstpmessage.xr.md).

**既定値:** unknown

**対応:** SSP 2.8.83
