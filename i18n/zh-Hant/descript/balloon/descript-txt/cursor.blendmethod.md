# cursor.blendmethod,Command

**カテゴリ:** descript.txt

Raster operation command for the choice marker.<br />
Use none for no operation.<br />
Use notmaskpen for r2_notmaskpen.<br />
Use mergepennot for r2_mergepennot.<br />
SSP allows any operator supported by the Win32API SetROP2 function (reference: [SetROP2 function (external site)](https://learn.microsoft.com/ja-jp/windows/win32/api/wingdi/nf-wingdi-setrop2))<br />
In this case as well, specify the lowercase mode name without "R2\_".

**既定値:** none

**対応:** Materia / SSP / CROW
