# char\*.bindgroup\*.name,類別名稱,零件名稱,縮圖名稱

**カテゴリ:** descript.txt

為動畫 ID 為 \* 的零件定義類別名稱和零件名稱。（第 3 人起）<br />
動畫 ID 是 surfaces.txt 中動畫定義「animation\*.interval,bind」的 \* 所代表的數字。<br />
必須設定此項目，才能在 owner draw 選單的 dressup 中顯示。<br />
使用 Sakura Script 的[`\![bind,カテゴリ名,パーツ名,数値]`](../../../list/sakura-script/surface/bang-bind.md)進行操作時也需要此項目。（僅 SSP）

**既定値:** 無作用

**対応:** SSP
