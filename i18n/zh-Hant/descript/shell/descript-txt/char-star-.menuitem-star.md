# char\*.menuitem\*,ID

**カテゴリ:** descript.txt

Display the dressup with the specified animation ID at position \* in the dressup menu. \* is a sequential number starting from 0. (For the third character onward)<br />
Specify "-" instead of an ID to display a separator at that position.

**既定値:** no action

**対応:** SSP
