# kero.bindgroup\*.name,類別名稱,零件名稱,縮圖名稱

**カテゴリ:** descript.txt

為第 \* 個動畫 ID 的零件定義類別名稱和零件名稱。（夥伴側）<br />
動畫 ID 是 surfaces.txt 中動畫定義「animation\*.interval,bind」裡的 \* 所代表的數字。<br />
要在 owner draw 選單的 dressup 項目中顯示時必須設定。<br />
也必須設定此項，才能透過 Sakura Script 的[`\![bind,カテゴリ名,パーツ名,数値]`](../../../list/sakura-script/surface/bang-bind.md)操作。（僅 SSP）

**既定値:** 無作用

**対応:** Materia / SSP
