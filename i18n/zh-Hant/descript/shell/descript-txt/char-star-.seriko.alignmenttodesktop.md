# char\*.seriko.alignmenttodesktop,position information

**カテゴリ:** descript.txt

The default position of the partner side for the third character onward [※Position information](note-1.md#補足).<br />
Takes precedence over the shell-wide setting ([seriko.alignmenttodesktop](seriko.alignmenttodesktop.md)). In other words, this has the highest priority among all alignmenttodesktop settings.<br />
※Ghost-wide setting < ghost scope-specific setting < shell-wide setting < this setting
