# char\*.balloon.offsetx,座標

**カテゴリ:** descript.txt

`\p[*]` 的 balloon 位置 X 座標。`char0` 的指定方式與 `sakura` 相同，`char1` 則與 `kero` 相同。<br />
座標的意義及在後方附加表示方向的單一字元（l / r / c / b）的寫法，皆與 [sakura.balloon.offsetx](sakura.balloon.offsetx.md) 相同。

也可以寫在 ghost 端的 descript.txt 中。若 shell 端有設定則以 shell 端為優先，否則使用 ghost 端的值。

**既定値:** 無值

**対応:** SSP
