# seriko.dpi,建議DPI

**カテゴリ:** descript.txt

此 shell 建議使用的螢幕 DPI 值。若未指定，則固定使用 Windows 標準值 96。<br />
建議確認建立 shell 時的 Windows 設定「系統-顯示器-縮放比例」，並依照下列對照表選擇值。

- 100% - 96
- 125% - 120
- 150% - 144
- 175% - 168
- 200% - 192

參考值：4K 螢幕使用 144(150%)，近期的筆記型電腦使用 120-144(125-150%)

**既定値:** 96

**対応:** SSP 2.7.21
