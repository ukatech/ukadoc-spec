# seriko.dpi,建議 DPI

**カテゴリ:** descript.txt

此 shell 建議的螢幕 DPI 值。若未指定，則固定使用 Windows 標準值 96。<br />
建議在製作 shell 的環境中，於 Windows 設定的「系統-顯示器-縮放」確認設定，並依照下表選擇數值。

- 100% - 96
- 125% - 120
- 150% - 144
- 175% - 168
- 200% - 192

參考值：4K 螢幕為 144(150%)，較新的筆記型電腦為 120-144(125-150%)

也可寫在 ghost 側的 descript.txt。若 shell 側有指定，則優先使用 shell 側的值；否則使用 ghost 側的值。

**既定値:** 96

**対応:** SSP 2.7.21
