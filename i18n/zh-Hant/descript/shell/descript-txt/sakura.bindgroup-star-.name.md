# sakura.bindgroup\*.name,類別名稱,零件名稱,縮圖名稱

**カテゴリ:** descript.txt

為動畫 ID 為 \* 的零件設定類別名稱和零件名稱。（本體端）<br />
動畫 ID 是 surfaces.txt 中動畫定義「animation\*.interval,bind」裡 \* 所代表的數字。<br />
若要在 owner draw 選單的 dressup 項目中顯示，必須設定此項目。<br />
使用 Sakura Script 的 [`\![bind,カテゴリ名,パーツ名,数値]`](../../../list/sakura-script/surface/bang-bind.md) 操作時也必須設定此項目。（僅限 SSP）

**既定値:** 無作用

**対応:** Materia / SSP
