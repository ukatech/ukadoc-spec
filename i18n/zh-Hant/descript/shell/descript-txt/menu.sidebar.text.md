# menu.sidebar.text,字串

**カテゴリ:** descript.txt

顯示在 owner draw 選單側邊欄中的字串。以由下往上閱讀的方向（向左旋轉 90 度）顯示。<br />
若有側邊欄圖片（[menu.sidebar.bitmap.filename](menu.sidebar.bitmap.filename.md)），則使用圖片，不顯示此字串。<br />
背景色由 [menu.sidebar.color](menu.sidebar.color.md) 指定，文字顏色由 [menu.sidebar.font.color](menu.sidebar.font.color.md) 指定。字型與選單項目使用相同的設定（[menu.font.name](menu.font.name.md) / [menu.font.height](menu.font.height.md)）。

也可以寫在 ghost 的 descript.txt 中。若 shell 中有設定，則優先使用 shell 的值；否則使用 ghost 的值。

**既定値:** 無值

**対応:** SSP
