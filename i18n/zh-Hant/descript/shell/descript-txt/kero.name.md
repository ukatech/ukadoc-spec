# kero.name,名稱

**カテゴリ:** descript.txt

搭檔側 ghost 的名稱。

也可寫在 ghost 側的 descript.txt 中。若 shell 側有設定，則優先使用 shell 側的值；否則使用 ghost 側的值。但當 ghost 側的 [name.allowoverride](../../ghost/descript-txt/name.allowoverride.md) 為 0 時，不使用 shell 側的設定。

**既定値:** 不可省略／在 SSP 中省略時為 sakura.name　※用於設定視窗標題

**対応:** Materia / SSP / CROW
