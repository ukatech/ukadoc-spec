# menu.sidebar.font.color,顏色

**カテゴリ:** descript.txt

owner draw 選單側邊欄中顯示的文字（[menu.sidebar.text](menu.sidebar.text.md)）顏色。<br />
顏色可指定為顏色名稱（例如 `red`）、`#RRGGBB` 或 `#RGB`（可省略 `#`）。<br />
也可以在 `menu.sidebar.font.color.r` / `menu.sidebar.font.color.g` / `menu.sidebar.font.color.b` 中填入 0～255 的數值，分別指定紅、綠、藍。

也可以寫在 ghost 端的 descript.txt 中。若 shell 端有設定，則優先使用 shell 端的值；否則使用 ghost 端的值。

**既定値:** 與 [menu.foreground.font.color](menu.foreground.font.color.r.md) 相同的顏色

**対応:** SSP
