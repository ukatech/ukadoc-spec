# id,ID

**カテゴリ:** descript.txt

作為 plugin ID 的字串，應盡可能降低重複的可能性。<br />
字串只能由單位元組字元組成，長度最多為 63 位元組。通常會使用稱為 GUID/UUID 的字串。<br />
一旦決定就不得變更。<br />
ID 相同表示彼此相容，即使是不同名稱的 plugin 也一樣。<br />
<br />
※產生方式：[http://www.famkruithof.net/uuid/uuidgen](http://www.famkruithof.net/uuid/uuidgen)。<br />
若開發環境具備相應工具，也可以使用 guidgen.exe 的 Registry Format。<br />
亦有提供[工具](http://ssp.shillest.net/docs/guid.zip)。

**既定値:** 不可省略

**対応:** Materia / SSP / CROW
