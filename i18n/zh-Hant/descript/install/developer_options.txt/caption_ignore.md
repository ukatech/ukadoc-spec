# Automatically excluded items

When SSP creates nar/updates2.dau(updates.txt), the following files and folders are automatically excluded, even if they are not specified in developer_options.txt.

Files

- desktop.ini
- thumbs.db
- folder.htt
- mscreate.dir
- .DS_Store
- \_CATALOG.VIX

Folders

- profile/
- var/
- \_\_MACOSX/
- XtraStuf.mac/
