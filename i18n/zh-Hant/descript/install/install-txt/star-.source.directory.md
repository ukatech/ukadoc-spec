# \*.source.directory,目錄名稱

**カテゴリ:** install.txt

同時安裝的內容在封存檔中的目錄名稱。建議使用半形英數字。<br />
同時安裝的內容在安裝後的目錄名稱與封存檔中的目錄名稱不一致時設定。<br />
也可以指定帶有編號的項目（例如 balloon0.source.directory）。

SSP 2.9.00 以後，也可以指定像 extra\\bal1 這樣沿著封存檔內階層往下的相對路徑。<br />
分隔符號可以使用「\\」或「/」。「..」不能用來參照上層目錄（會被移除）。<br />
在 2.9.00 以前，分隔符號會被取代為「\_」，因此只能指定單層目錄名稱。

**既定値:** 以 \*.directory 設定的目錄名稱

**対応:** SSP
