# type,Type

**カテゴリ:** install.txt

The type of archive contents. The available types are as follows.

- **ghost**: ghost
- **shell**: Additional shell for a ghost
- **supplement**: Additional files for a ghost
- **balloon**: balloon
- **plugin**: plugin
- **headline**: headline sensor
- **language**: (SSP only) language pack
- **calendar skin**: (SSP only) calendar appearance file
- **calendar plugin**: (SSP only) calendar schedule sensor
- **package**: (SSP only) package for installing multiple items

\[Legacy specification\](SSPのみ) Specifying only calendar is treated the same as calendar skin.<br />
This is for compatibility with the era before calendar plugin existed; do not use it now.

**既定値:** Cannot be omitted

**対応:** Materia / SSP / CROW
