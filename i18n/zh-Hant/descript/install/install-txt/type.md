# type,種類

**カテゴリ:** install.txt

アーカイブの内容の種別。種類は以下のとおり。

- **ghost**: ghost
- **shell**: ghost 的追加 shell
- **supplement**: ghost 的追加檔案
- **balloon**: balloon
- **plugin**: plugin
- **headline**: headline sensor
- **language**: （僅限 SSP）語言套件
- **calendar skin**: （僅限 SSP）行事曆外觀檔案
- **calendar plugin**: （僅限 SSP）行事曆排程感測器
- **package**: （僅限 SSP）多重安裝用套件

\[舊規格\](SSPのみ) 只寫 calendar 時，會視同 calendar skin 處理。<br />
這是用於相容沒有 calendar plugin 時代的用途，目前請勿使用。

**既定値:** 不可省略

**対応:** Materia / SSP / CROW
