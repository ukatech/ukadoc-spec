# MediaInfo

**カテゴリ:** internal_file

音声・動画ファイルのタグ・長さ・大きさを、**ファイルをロードせずに**（再生の準備をせずに、ヘッダやタグだけを読んで）取得する。\[SSP 2.9.27\] 画像の大きさは[ImageInfo](internal_file.ImageInfo.md)で読む。画像ファイルをMediaInfoに渡したときの扱いは保証しない（SSPは、\[SSP 2.9.25\]から変わらず、画像の`Result`・`width` / `height`も返す）。`\![sound]`で要素を作らなくても、パスだけで読める。`sound.*`の一覧に要素は増えず、`OnSound*`イベントも出ず、一時ファイルも作らない。<br />
**環境によっては取得できない場合がある。**SSPはOSのプロパティハンドラ（エクスプローラーのファイルの詳細に出るのと同じ仕組み）に頼って読むので、OSにその形式のハンドラが無い、あるいはハンドラが一部の項目を返さない形式では、その値は空になる（タグが無いファイルと区別はできない）。取れなかったことはエラーにならない。<br />
同期で呼ぶと、読み出しの間ゴーストが止まる点に注意。読み出しはファイルの置き場所（ネットワークドライブなど）によっては時間がかかるので、[`--async`](../async.md)の利用も検討する。

- **Argument1**: ファイルのパス。相対パスはゴーストのフォルダ（ghost/master）が基準。区切りは`/`も`\`も書ける。ゴーストなしの呼び出しで相対パスを渡すと400（`ghost required`）。ファイルが無い（フォルダを含む）ときは400（`file not found`）。URLは受け付けない。
- **Argument2以降**: 欲しい値のキー。1個以上必須（1個もなければ400 `invalid parameter`）で、11個まで。キーは大文字小文字を区別しない。

キーは次のとおり。値はすべて文字列（数値は10進の整数）。タグの項目は、`sound.(要素名).meta.*`と同じ名前と意味。

- **title / artist / albumartist / album / genre / comment**: 文字列。
- **year**: 4桁の西暦。元の値が日付全体なら先頭の4桁。
- **track**: 曲番号の整数だけ。総数は含めない（`3/12`なら`3`）。
- **duration**: 音声・動画の長さ（ミリ秒）。画像は空。VBRのMP3などは推定値のことがある。
- **width / height**: 画素数（px）。動画は映像のサイズ。音声は空。アルバムアートなど、埋め込まれたジャケット画像だけの映像は動画と数えない。

応答の`Result`は種別で、`audio`（音声）/ `video`（動画）のどちらか。判別できなければ空。種別は目安なので、`Result`が空でも`Value`は埋まることがある。`Result`で分岐せず、`Value`が空かどうかで判断すること。今後、種別が増えることがある。<br />
`Value0`以降は、`Argument2`以降に並べたキーと同じ順に対応する。取れなかった値・知らないキーは**空文字**（エラーにはならない。実装独自のキーは返さない）。読めない・未対応の形式でも、400にはならず、`Result`も`Value`もすべて空の200で返る。

- 値の中の改行は、バイト値`0x01`に置き換える（CRLFも`0x01`1つ。LFだけ・CRだけもそれぞれ`0x01`1つ）。NULは除く。
- 複数の値を持つタグ（複数のアーティストなど）は、` ;  `（セミコロンと半角空白）でつないだ1つの文字列にする。
- 応答の文字コードは要求の`Charset`に従う。
- ファイルに書かれたタグの文字コードの推定（ID3v1や、実際は別の文字コードなのに誤った文字コードとして書かれたタグなど）はOSまかせで、文字化けすることがある。
- どの形式のどの項目が取れるかはOSの環境で異なる。SSPで確かめた範囲では、Windows 11の標準の環境で、WAVのタグ、MP3のコメント、MKV / WebMのほとんどのタグと映像サイズなどは取れなかった。

## 記述例

```
Argument0: MediaInfo
Argument1: sound/bgm01.mp3
Argument2: title
Argument3: artist
Argument4: duration
Argument5: --async=OnMediaInfo

→ 204（結果はOnMediaInfoイベントで届く）
　Reference0: OnMediaInfo
　Reference1: audio
　Reference2: internal_file
　Reference3: MediaInfo
　Reference4: タイトル
　Reference5: アーティスト
　Reference6: 215000
```

**対応:** SSP 2.9.25
