# Format

**カテゴリ:** internal_time

日時を`--tz=`のゾーンの日時として整形する。曜日・月名は英語で固定（言語・地域の設定によらない）。

- **Argument1**: 日時
- **Argument2**: 書式（省略時・空のときは`iso8601`）
- **オプション**: `--tz=`

書式は次の名前か、`%`を使った書式。知らない書式名・知らない`%`の文字は400（`invalid parameter`）。

- **iso8601 / rfc3339**: `2026-10-11T21:00:00+09:00`。オフセットが0なら末尾は`Z`。
- **http**: `Sun, 11 Oct 2026 12:00:00 GMT`。`--tz=`によらず常にGMT。
- **epoch / epochms**: エポック秒 / エポックミリ秒。
- **%書式**: `%Y`（西暦4桁） `%y`（西暦の下2桁） `%m`（月） `%d`（日） `%H`（時） `%M`（分） `%S`（秒） `%j`（年の何日目） `%u`（曜日 月=1～日=7） `%w`（曜日 日=0～土=6） `%a`（Sun） `%A`（Sunday） `%b`（Jan） `%B`（January） `%z`（+0900） `%:z`（+09:00） `%s`（エポック秒） `%%`（%）。<br />
  `%`以外の文字はそのまま出力する。

## 記述例

```
Argument0: Format
Argument1: 0
Argument2: %Y/%m/%d %H:%M (%a)
Argument3: --tz=+09:00

→ Result: 1970/01/01 09:00 (Thu)
```

**対応:** SSP 2.9.13
