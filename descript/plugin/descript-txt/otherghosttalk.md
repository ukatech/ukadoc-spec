# otherghosttalk,オプション

**カテゴリ:** descript.txt

PLUGIN Event [OnOtherGhostTalk](../../../list/plugin-event/plugin-event/OnOtherGhostTalk.md)を通知する設定。

- **false**: 通知しない
- **0**: 通知しない
- **true**: 直後通知(喋り終わった直後に通知)
- **1**: 直後通知
- **after**: 直後通知
- **before**: 直前通知(喋る直前に通知)

**既定値:** false

**対応:** SSP
