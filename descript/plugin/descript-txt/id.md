# id,ID

**カテゴリ:** descript.txt

そのプラグインのIDとなる、極力重複可能性の低い文字列。<br />
文字列は1バイト文字のみで構成される63バイトまでのもの。通常GUID/UUIDと呼ばれるものを使う。<br />
一度決定したら変更してはならない。<br />
IDの一致は、たとえ別名のプラグインであっても互換性があることを示す。<br />
<br />
※生成方法[http://www.famkruithof.net/uuid/uuidgen](http://www.famkruithof.net/uuid/uuidgen)。<br />
またはそれなりに開発環境が揃っていれば、guidgen.exeのRegistry Formatが利用可能。<br />
[ツール](http://ssp.shillest.net/docs/guid.zip)も配布されている。

**既定値:** 省略不可

**対応:** Materia / SSP / CROW
