# default.balloon.path,パス

**カテゴリ:** descript.txt

このシェルの標準バルーンの相対パス。[balloon](balloon.md)と同じく、ユーザーがバルーンを明示的に切り替えていないときに使われる。優先順位などは[balloon](balloon.md)を参照。<br />
ゴースト側のdescript.txtの[default.balloon.path](../../ghost/recommended-balloon/default.balloon.path.md)にも書ける。シェル側に書かれていればシェル側が優先され、書かれていなければゴースト側の値が使われる。

**既定値:** ghostのdescript設定

**対応:** SSP
