# menu.sidebar.font.color,色

**カテゴリ:** descript.txt

オーナードローメニューのサイドバーに表示する文字([menu.sidebar.text](menu.sidebar.text.md))の色。<br />
色の指定は、色名(`red` など)、`#RRGGBB`、`#RGB`のいずれか(`#`は省略可)。<br />
`menu.sidebar.font.color.r` / `menu.sidebar.font.color.g` / `menu.sidebar.font.color.b` に0～255の数値を書いて、赤・緑・青を別々に指定することもできる。

ゴースト側のdescript.txtにも書ける。シェル側に書かれていればシェル側が優先され、書かれていなければゴースト側の値が使われる。

**既定値:** [menu.foreground.font.color](menu.foreground.font.color.r.md)と同じ色

**対応:** SSP
