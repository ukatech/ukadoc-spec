# vertical,0/1

**カテゴリ:** descript.txt

1を指定すると、このバルーンのテキストを日本語縦書き（上から下へ字を送り、右から左へ行を送る）で表示する。

縦書きにすると、descript.txtの座標指定の意味が以下のように変わる。座標自体は今までどおりバルーン画像の左上を原点として書けばよい。

- origin.x … *1列目の右端*。ここから左へ向かって列が進む。通常は指定せずvalidrectの定義に任せる場合が多い。
- origin.y … 字送りの開始位置（1文字目の上端）。通常は指定せずvalidrectの定義に任せる場合が多い。
- validrect … 変更なし。テキストを描画してよい範囲。
- 折り返しは[wordwrappoint.y](wordwrappoint.y.md)で指定する。wordwrappoint.xは無視される。
- SSTPメッセージの表示終了位置は[sstpmessage.yb](sstpmessage.yb.md)で指定する。sstpmessage.xrは無視される。
- [number.y](number.y.md)（＝number.yb） … カウンタ数値の*下端*。ここから上へ向かって数値が伸びる。[number.x](number.x.md)（＝number.xr）は数値が置かれる列の位置になる。

origin.xやnumber.xのように右端を基準にしたい座標は、[\*1](../index.md#balloon設定)のルールどおりマイナス値で書ける（例：origin.x,-14 ならバルーン画像の右端から14ピクセル）。

フォントは指定されたフォント名の縦書き用異体（フォント名の頭に@が付いたもの）が自動的に使われる。<br />
指定されたフォントに縦書き用異体が存在しない場合（バルーンフォルダに置いたフォントファイルや欧文フォントなど）は、環境の標準ゴシックの縦書き用異体に自動的に差し替わる。

また、以下の項目は「画面上の向き」ではなく「文字の送り方向を基準にした向き」で働くようになるので注意すること。

- `\f[align,～]`は列内での字寄せ（left＝上寄せ、right＝下寄せ）、`\f[valign,～]`は行の厚み方向の寄せ（top＝右寄せ、bottom＝左寄せ）になる。
- arrow0（スクロール上）・arrow1（スクロール下）は、意味としてはそれぞれ右・左へのスクロールになる。画像と位置はバルーン側で用意すること。
- 下線（font.underlineや`\f[underline,true]`、アンカーの下線）は列の右側に引かれる。

制限として、SSTPマーカーの送信元表示とネットワーク更新の進捗表示も縦書きで描画される。入力ボックス（communicatebox）は横書きのまま。

バルーンの各サーフェスごとの[balloon(s/k)\*s.txt](../balloonsoption/index.md)でも指定できるが、同一バルーン内でサーフェスごとに縦書き・横書きを切り替えると、切り替え前に表示していた文章のレイアウトが崩れる。

**既定値:** 0（横書き）

**対応:** SSP 2.8.80
