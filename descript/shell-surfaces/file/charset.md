# charset,文字コード

**カテゴリ:** surfaces.txt または surfaces\*\*.txt(SSPのみ)

表示する文字コード。旧い環境との互換性を考慮する場合はShift_JIS、それ以外はUTF-8を推奨。

SSPにおいて複数の[surfaces\*\*\*.txtを用意](../introduction_surfaces.txt.md)した場合はそれぞれのファイルに設定する必要がある（逆に言うとそれぞれのファイルで異なる設定が可能）。

**既定値:** (OSの標準設定またはSSP-\>国際化-\>省略時の文字コード-\>テキスト定義)

**対応:** SSP / CROW
