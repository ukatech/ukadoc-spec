# kero.balloon.offsety,座標

**カテゴリ:** surfaceブレス

そのサーフェスでのみの相方側バルーン位置Y座標。<br />
方向を表す1文字(l / r / c / b)を後ろに付ける書き方については[sakura.balloon.offsetx](sakura.balloon.offsetx.md)を参照。

**既定値:** 左右に出す時：バルーンの上端と、サーフェスの上端が揃う位置<br />
頭上に出す時：バルーンの下端と、サーフェスの上端が揃う位置<br />
足元に出す時：バルーンの上端と、サーフェスの下端が揃う位置

**対応:** Materia / SSP / CROW
