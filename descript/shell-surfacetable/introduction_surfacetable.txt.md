# surfacetable.txt

## 概要

SSP開発用パレットの「サーフィステスト」機能や、そのほかのシェル作成支援ユーティリティでの利用を目的としたサーフェス内容の定義ファイル。

## 基本の書式

記載例

```
charset,Shift_JIS
version,1
option,DisableNoDefineSurfaces

//==========パーツ==========
group,__disabled
{
	19,__parts
}

//==========クー==========
group,[空]平日
{
	scope,0
	
	0,素
	1,照れ
	3,不安
	4,はぅー
	5,笑
}
```

// から始まる行はコメントとみなされ、完全に無視される。

半角スペースおよびタブによるインデントが可能。
