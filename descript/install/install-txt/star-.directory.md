# \*.directory,ディレクトリ名

**カテゴリ:** install.txt

同時インストールする内容のインストール後のディレクトリ名。半角英数推奨。<br />
\*部分の書き方と、同じ種別を複数同梱する場合の番号の付け方は[「同時インストール」](introduction_install_multi.md)を参照。<br />
ここに指定できるのは*1階層のディレクトリ名だけ*で、パス区切りは使えない（「\_」に置換される）。<br />
アーカイブ自身の[type](type.md)を問わず機能するが、実用上はtypeが*ghost*か*shell*のアーカイブで用いる。

**既定値:** 挙動なし

**対応:** SSP
