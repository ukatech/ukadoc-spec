# \*.source.directory,ディレクトリ名

**カテゴリ:** install.txt

同時にインストールする内容のアーカイブ内でのディレクトリ名。半角英数推奨。<br />
同時にインストールする内容の、設置後のディレクトリ名とアーカイブ内でのディレクトリ名が一致しない場合に設定。<br />
番号付き（balloon0.source.directoryなど）も同様に指定できる。

SSP 2.9.00以降は、extra\\bal1 のようにアーカイブ内の階層を辿る相対パスも指定できる。<br />
区切りは「\\」「/」のどちらでもよい。「..」による上位階層への参照はできない（取り除かれる）。<br />
2.9.00未満では区切りが「\_」に置換されるため、1階層のディレクトリ名しか指定できない。

**既定値:** \*.directoryで設定したディレクトリ名

**対応:** SSP
