# type,種別

**カテゴリ:** install.txt

アーカイブの内容の種別。種類は下記の通り。

- **ghost**: ゴースト
- **shell**: ゴーストへの追加シェル
- **supplement**: ゴーストへの追加ファイル
- **balloon**: バルーン
- **plugin**: プラグイン
- **headline**: ヘッドラインセンサ
- **language**: （SSPのみ）言語パック
- **calendar skin**: （SSPのみ）カレンダーの外見ファイル
- **calendar plugin**: （SSPのみ）カレンダーのスケジュールセンサ
- **package**: （SSPのみ）複数インストール用パッケージ

\[旧仕様\](SSPのみ) calendar のみを書くと calendar skin と同等の扱いになる。<br />
calendar pluginが無かった時代の互換用途であり、現在は書いてはいけない。

**既定値:** 省略不可

**対応:** Materia / SSP / CROW
