# delete.txt

## 概要

[ファイル構成「ネットワーク更新」](../../../manual/update.md)のページも参考に。

クライアント（ユーザ）のファイルは、更新時にサーバ（作者）のファイルで上書きされるだけで、同期されるわけではない。<br />
つまり、一度クライアント側にダウンロード・作成されたファイルは、例えサーバ側で削除したとしても取り除く事ができない。<br />
従って、公開後に一度公開したファイルを削除する必要がある場合にはdelete.txtにそのファイルを記載しなければならない。<br />
なおdelete.txtは削除実行後も自動で削除されず、一度記載した内容は、変更しない限り永久に除外され続ける。

以下はSSPのみの仕様。

- **charset,(文字コード)**: ファイルの文字コードを指定する

## 記述例

```
ghost\master\ai.dtx
ghost\master\testdict\
shell\master\surface110.png
```
