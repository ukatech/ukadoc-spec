# position

**カテゴリ:** プロパティシステム \> サウンドプロパティ名

対象のメディアの現在の再生位置。ミリ秒。<br />
位置を取得できない実装・フォーマットの場合は-1。<br />
*\[SET有効\]*SETすると[`\![sound,option,～]`](../../../sakura-script/sound/bang-sound-option.md)の[--seektime=](../../../sakura-script/sound/notes_sound.md)と同じ効果。<br />
値の書式も--seektime=と同じで、「:」を含まない場合はミリ秒単位の整数、「:」を含む場合は\[\[時:\]分:\]秒\[.ミリ秒\]として解釈する。頭に@をつけると現在の再生位置からの相対指定となり、負の値も指定できる（例：@-5000で5秒巻き戻し）。

**対応:** SSP 2.8.72
