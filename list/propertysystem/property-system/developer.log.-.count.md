# developer.log.ログ種別.count

**カテゴリ:** プロパティシステム

SSPが記録しているログの現在の件数。ログ種別に入る文字列は以下の通り。

- **script**: スクリプトログ（ログウインドウの種別Script）。
- **error**: エラーログ（同Error）。
- **network**: ネットワークログ（同Network）。
- **update**: アップデートログ（同Update）。

各ログが保持する件数には上限があり（既定50件）、上限を超えると古いものから消えていく。<br />
developer.log.～ はすべて読み取り専用で、開発者機能の設定に関わらず取得できる。<br />
エラーログでは、同じ内容のログが続くとtypeがSystemの要約1件にまとめられることがある。

**対応:** SSP
