# currentghost.mousecursor

**カテゴリ:** プロパティシステム

ゴーストで操作できる部分を示すカーソルファイル名（指先）<br />
以降currentghost.mousecursor / currentghost.balloon.mousecursor で始まるプロパティに共通：<br />
相対パス指定はシェル→ゴーストフォルダ内の順で探索する。<br />
空文字列を指定してSETすると、定義削除扱いとなり、set前の表示に戻すことができる。<br />
カーソル指定は[surfaces.txtのcursorセクション](../../../descript/shell-surfaces/cursor-brace/introduction_cursorbrace.md)と同じ指定が可能。<br />
*\[SET有効\]*

**対応:** SSP \[2.6.11\]
