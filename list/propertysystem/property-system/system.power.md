# system.power.(キー)

**カテゴリ:** プロパティシステム

電源・バッテリーの状態。(キー)に入る文字列は以下の通り。情報が取得できない環境（デスクトップPC等でバッテリーが存在しない場合を含む）では、各値は下記の「取得不能時」の値になる。

- **source**: 現在の電源供給元。battery（バッテリー駆動）、ac（AC電源/コンセント接続）、ups（UPS経由）のいずれか。取得不能時はunknown。
- **battery.percent**: バッテリー残量（％、整数）。取得不能時・残量不明時は-1。
- **battery.lifetime**: バッテリーのみで動作可能な残り時間（秒）。取得不能時・残り時間不明時は-1。
- **battery.flag**: バッテリーの状態フラグ。該当する状態をカンマ区切りで列挙する。取り得る値は high（残量十分）、low（残量低下）、critical（残量危機的）、charging（充電中）、no_battery（バッテリーなし）、power_saving（バッテリー節約機能が有効、Windows 10以降のみ）。取得不能時は空文字列。

**対応:** SSP 2.8.17
