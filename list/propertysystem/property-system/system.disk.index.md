# system.disk.index(ID).(キー)

**カテゴリ:** プロパティシステム

ID番目（0始まり）のドライブの情報。IDの範囲は0から system.disk.count - 1 まで。(キー)に入る文字列は以下の通り。

- **mountpoint**: Windowsではドライブレター（末尾の「\\」を除いたもの）、他OSではマウントポイント。例： C: /home
- **type**: ドライブの種類。fixed（固定ディスク）、removable（リムーバブルディスク）、network（ネットワークドライブ）、optical（光学ドライブ）、ram（RAMディスク）、unknown（不明）のいずれか。
- **total**: ドライブの総容量（MB）。容量を取得できない場合（メディア未挿入等）は-1。
- **free**: ドライブの空き容量（MB）。容量を取得できない場合（メディア未挿入等）は-1。

**対応:** SSP 2.8.17
