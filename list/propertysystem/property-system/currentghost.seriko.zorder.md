# currentghost.seriko.zorder

**カテゴリ:** プロパティシステム

現在の[`\![set,zorder,～]`](../../sakura-script/surface/bang-set-zorder-ID-ID.md)の設定状態。<br />
グループ内の要素をカンマ区切り、グループ同士をセミコロン区切りで並べたもの。要素は手前にあるものから順に並ぶ。<br />
要素を明示指定するモードでは `s0,b0,s1;s2,b2` のように `s`（サーフェス）・`b`（バルーン）＋スコープIDの短縮形で返る。<br />
スコープIDのみを指定する従来のモードでは `0,1;2,3` のように数値だけが返る。<br />
`front`・`back`を指定するモードでは `front,0,1;back,3` のように、前面側・背面側をセミコロンで区切って返る。どちらか一方だけの場合は、その分だけが返る。<br />
設定が一つもない場合は値なし。<br />
*\[SET有効\]*

書き込みの場合は同じ書式で**現在の設定を完全に置き換える**。さくらスクリプトのタグがグループを追加していくのとは異なる点に注意。<br />
空文字列を書き込むとすべてのZオーダー設定が解除される。<br />
読み取った値をそのまま書き戻せば元の状態を再現できる。<br />
要素が2つ未満のグループは無視される(`front`・`back`は1つでもよい)。また明示指定モードと従来モードは排他のため、`s0,b0;2,3` のように**両モードを混在させることはできない**。`front`・`back` も他のモードと混在できず、混在させた場合は後に書いたほうの指定になる。

**対応:** SSP 2.8.78/2.9.35(front,back記法)
