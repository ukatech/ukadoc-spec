# currentghost.seriko.sticky-window

**カテゴリ:** プロパティシステム

現在の[`\![set,sticky-window,～]`](../../sakura-script/surface/bang-set-sticky-window-ID-ID.md)の設定状態。<br />
グループ内のスコープIDをカンマ区切り、グループ同士をセミコロン区切りで並べたもの。<br />
例えばスコープ0と1、スコープ2と3をそれぞれくっつけている場合は `0,1;2,3` となる。<br />
設定が一つもない場合は値なし。<br />
*\[SET有効\]*

書き込みの場合は同じ書式で**現在の設定を完全に置き換える**。さくらスクリプトのタグがグループを追加していくのとは異なる点に注意。<br />
空文字列を書き込むとすべてのくっつき設定が解除される。<br />
要素が2つ未満のグループ、および既に他のグループで使われているスコープIDを含むグループは無視される。

**対応:** SSP 2.8.78
