# currentghost.sound.index(ID).サウンドプロパティ名

**カテゴリ:** プロパティシステム

現在のゴーストが管理しているメディアのうち、ID番目のものから情報を取得。<br />
IDは新しく開かれたものから順に0,1,2...となる。範囲外のIDを指定した場合は取得失敗となる。<br />
サウンドプロパティ名は[後述](sound-property/sound.name.md)。書き込みが可能なものと、その際の注意点については[こちら](sound-property/notes_sound_propertyset.md)。

**対応:** SSP 2.8.72
