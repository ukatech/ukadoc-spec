# `\![execute,dumpsurface,ディレクトリ,スコープID,サーフェスリスト,prefix,イベントID,ゼロ位置切り出し,アニメーションID]`

**カテゴリ:** 未分類コマンド

合成済みのサーフェス画像を指定したディレクトリに出力する。<br />
イベントIDを指定しない場合は、処理が完了するまでスクリプトの実行は停止する。<br />
スコープID : `\s`タグに指定するものと同じIDを指定する。この指定で、着せ替え状態などのスコープに依存する処理が変わる。<br />
サーフェスリスト : [surface ID指定](../../../descript/shell-surfaces/surface-brace/caption_surfacebraceid.md)と同じ書式、または以下を指定する。<br />
\_\_system_surface_all\_\_ : シェルとして有効なサーフェスをすべて出力する<br />
\_\_system_surface_defined\_\_ : surfaces.txt内で定義されたサーフェスのみすべて出力する<br />
参考 SakuraScriptの大かっこパラメータ内でカンマを指定したい場合は " " で囲むと良い。<br />
prefix : (省略可) 出力したいファイルの頭につける文字列。省略した場合はsurface。<br />
イベントID : (省略可) これを指定するとSakuraScriptの続きを実行しながら出力を続け、終わり次第指定したイベントを発生させる。Reference0には出力に成功したファイル数が入る。<br />
ゼロ位置切り出し : 1を指定すると、アニメーション定義に関わらず必ず0,0からダンプし、負の座標部分を無視する。<br />
アニメーションID : (省略可) 指定すると、各サーフェスの通常の画像(prefix+サーフェス番号.png)に続けて、そのアニメーションを`\i[ID]`と同様に再生し、パターンが進むたびの画像を prefix+サーフェス番号\_0000.png から0始まり4桁の連番で出力する。指定できるIDは1つだけ。詳細は起動オプション --dump-animation と同じ。イベントのReference0には連番の画像も含めたファイル数が入る。\[2.9.05\]<br />
セキュリティ上の観点から、出力先は、SSP管理下のフォルダ(ghostフォルダ、balloonフォルダなど「フォルダ」設定で指定した場所)以下への展開に制限される。<br />
また、この制限は適宜強化される可能性があるため、ゴースト自身のデータが置かれているフォルダ以下に限定するのが無難。<br />
出力先が制限範囲外の場合は何も出力せず、エラーログに記録される。

\[2.9.08\] 以下の形式でも指定できる。--で始まる引数は順不同で、上記の各引数による指定と混在してもよい（--で始まらない引数は、現れた順にディレクトリ・スコープID・サーフェスリスト・prefix・イベントID・ゼロ位置切り出し・アニメーションIDとみなす）。<br />
ディレクトリ以外は省略でき、スコープIDの省略時は0になる。

- **--dir=ディレクトリ**: 出力先のディレクトリ。
- **--scope=スコープID**: スコープID。
- **--surface=サーフェスリスト**: サーフェスリスト。カンマを含む場合は"--surface=0,10"のように引数全体をダブルクォートで囲むこと。
- **--prefix=prefix**: 出力ファイル名の頭につける文字列。
- **--event=イベントID**: イベントID。--async=でも同じ。
- **--fromzero=真偽値**: ゼロ位置切り出し。
- **--animation=アニメーションID**: アニメーションID。

**対応:** SSP \[2.5.98\]

## 記述例

```sakurascript
\0のサーフェス0～9をdumpフォルダに出力する。\![execute,dumpsurface,--dir=dump,--scope=0,"--surface=0-9"]
```
