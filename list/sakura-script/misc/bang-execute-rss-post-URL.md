# `\![execute,rss-post,URL,オプション,オプション,オプション...]`

**カテゴリ:** 未分類コマンド

[※オプション](bang-execute-http-options-URL.note.md)付きでhttp post リクエストを行い、レスポンスをRSS/Atomフィードとして解析したのち、解析結果をイベントとして通知する。<br />
解析・通知・[絞り込み](bang-execute-rss-post-URL.note.md)の仕様は[rss-get](bang-execute-rss-get-URL.md)と同じ。パラメータ群の指定はhttp-postと同じ。

**対応:** SSP
