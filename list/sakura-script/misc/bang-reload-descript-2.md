# `\![reload,descript,パラメータ]`

**カテゴリ:** 未分類コマンド

指定したdescript.txtをリロードする。<br />
半角スペース区切りで複数指定可能。<br />
ghost shell balloon headline plugin language calendar.skin calendar.plugin

calendar.skinはカレンダースキン、calendar.pluginはスケジュールセンサ（[install.txtのtype](../../../descript/install/install-txt/type.md)と同じ区分）。<br />
install.txtと同じ「calendar skin」「calendar plugin」表記も受け付けるが、パラメータの区切りが半角スペースなので、ドット表記の方を推奨。

**対応:** SSP

## 記述例

```sakurascript
\![reload,descript,shell balloon]シェルとバルーンのdescript.txtをリロードする。
```
