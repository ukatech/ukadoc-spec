# `\![execute,filewatch,パス,オプション...]`

**カテゴリ:** 未分類コマンド

指定したファイルまたはディレクトリの監視を始め、変化があるたびに[OnExecuteFileWatchChange](../../shiori-event/other-communication/OnExecuteFileWatchChange.md)で通知する。監視を始められなかった場合や、監視中に監視先のディレクトリが無くなった場合は[OnExecuteFileWatchFailure](../../shiori-event/other-communication/OnExecuteFileWatchFailure.md)で通知され、その監視は終わる。SSTPなど外部から送られたスクリプトでは実行できない。<br />
パラメータは以下の通り。

- パス……監視するファイルまたはディレクトリ。相対パス指定の場合はghost/master/以下の相対パスと解釈される。
- --async=イベントまたは識別子……Onではじまる文字列を指定すると(後述のイベントの替わりに)そのイベントが起きる
- --debounce=ミリ秒……変化の通知が止んでからこの時間だけ待ち、その間に次の変化が無ければ通知する。変化が続く間は待ち続けるので、書き込み途中の連続した変化は1回の通知にまとまる。ただし変化が止まなくても、最初の変化から指定時間の3倍が経てば通知する。省略時は500。0を指定すると待たずに通知する。

ファイルを指定した場合は、更新・作成・削除を通知する。まだ存在しないファイルも指定でき、作成されると通知される。ただし、そのファイルを置くディレクトリは存在している必要がある。<br />
ディレクトリを指定した場合は、直下でファイルやディレクトリの作成・削除・名前変更・更新があったことだけを通知する。どのファイルが変わったかは通知されず、サブディレクトリの中の変化も通知されない。ディレクトリとして監視するには、実行時にそのディレクトリが存在している必要がある（存在しないパスはファイルとして監視される）。<br />
同じパスをもう一度指定すると、以前の指定は置き換えられる。監視はゴーストの終了時にすべて解除される。

**対応:** SSP 2.8.91

## 記述例

```sakurascript
\![execute,filewatch,config.json,--async=OnConfigChanged]ghost/master/config.jsonが変化するたびに、OnConfigChangedイベントが起きる。
```
