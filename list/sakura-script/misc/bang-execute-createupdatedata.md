# `\![execute,createupdatedata,出力先ファイル]`

**カテゴリ:** 未分類コマンド

スクリプトを実行したゴースト自身の更新定義ファイル(updates2.dau/updates.txt)を作る。<br />
出力先ファイル : 省略可。ゴーストのghost/masterフォルダからの相対パス、または絶対パスで指定する。\[2.8.98\]<br />
指定した場合はそのファイルに1つだけ作り、既に同名のファイルがある場合は上書きする。ファイル名が.dauで終わる場合はupdates2.dauと同じ形式、それ以外の場合はupdates.txtの形式で出力する。<br />
このとき通常の出力先(ゴーストのルートとghost/master)のupdates2.dau/updates.txtは作成・削除とも行わない。出力先がゴーストのフォルダ内の場合、そのファイル自身は更新定義に含まれない。

**対応:** SSP 2.5.08
