# `\![execute,dumpballoon,ディレクトリ,スコープID,prefix,イベントID]`

**カテゴリ:** 未分類コマンド

指定したスコープのバルーンの、現在の描画内容を画像として指定したディレクトリに出力する。<br />
サーフェスと異なり状態を指定して描き直すことはできず、その時点でバルーンに描かれている内容がそのまま出力される。拡大縮小や半透明(フェード含む)は適用前の等倍の画像になる。<br />
バルーンが非表示でも、描画内容が残っていれば出力される。<br />
出力ファイル名は prefix+スコープID+.png となる(例 : balloon0.png)。<br />
スコープID : `\s`タグに指定するものと同じIDを指定する。<br />
prefix : (省略可) 出力したいファイルの頭につける文字列。省略した場合はballoon。<br />
イベントID : (省略可) 出力が終わり次第指定したイベントを発生させる。Reference0には出力に成功したファイル数(0または1)が入る。<br />
出力先の制限は`\![execute,dumpsurface]`と同じ。制限範囲外の場合は何も出力せず、エラーログに記録される。

\[2.9.08\] 以下の形式でも指定できる。--で始まる引数は順不同で、上記の各引数による指定と混在してもよい（--で始まらない引数は、現れた順にディレクトリ・スコープID・prefix・イベントIDとみなす）。<br />
ディレクトリ以外は省略でき、スコープIDの省略時は0になる。

- **--dir=ディレクトリ**: 出力先のディレクトリ。
- **--scope=スコープID**: スコープID。
- **--prefix=prefix**: 出力ファイル名の頭につける文字列。
- **--event=イベントID**: イベントID。--async=でも同じ。
- **--hide=項目**: 指定した項目を描かずに描き直したものを出力する。表示中のバルーンには影響しない。複数指定する場合は"--hide=balloonmarker,balloonnum"のようにカンマで区切り、引数全体をダブルクォートで囲むこと。<br />
  balloonmarker : SSTPマーカー（`\![set,balloonmarker]`の表示や、SSTPで受信したスクリプトの送信元表示）<br />
  balloonnum : `\![set,balloonnum]`の表示<br />
  この指定がある場合は、その時点の描画内容ではなく、その時点の状態から描き直した内容が出力される（`\![lock,balloonrepaint]`中でも描き直す）。

**対応:** SSP 2.9.02

## 記述例

```sakurascript
SSTPマーカーとballoonnumを除いて、\0のバルーンをdumpフォルダに出力する。\![execute,dumpballoon,--dir=dump,--scope=0,"--hide=balloonmarker,balloonnum"]
```
