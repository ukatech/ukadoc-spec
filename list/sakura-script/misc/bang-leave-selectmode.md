# `\![leave,selectmode]`

**カテゴリ:** 未分類コマンド

上記を解除する。実行後[OnSelectModeComplete](../../shiori-event/select-region-mode/OnSelectModeComplete.md)が実行される。<br />
当たり判定領域が無効(未選択)などの場合は[OnSelectModeCancel](../../shiori-event/select-region-mode/OnSelectModeCancel.md)になる。

**対応:** SSP

## 記述例

```sakurascript
\![leave,selectmode]セレクトモードを解除する。
```
