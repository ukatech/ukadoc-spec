# `\![set,balloonmarker,マーカー表示文字列]`

**カテゴリ:** バルーン、テキストコマンド

SSTP受信時に表示するマーカー文字列を表示する。<br />
表示先は現在のスコープが所属するバルーン。<br />
表示文字列は省略可。消去する場合は引数を省略するか空欄にする。

ゴースト終了か、SSTP受信など本来この部分を使う機能が発動するまで有効。

消去は「このタグで指定した文字列を取り消す」という意味で、マーカーそのものを隠すものではない。SSTPで受信したスクリプトの再生中に消去すると、既定の送信元表示（from 送信元）に戻る。<br />
また、SSTPやSHIORIのMarkerヘッダでマーカー文字列が指定されている場合はそちらが優先され、このタグの指定は表示されない。<br />
画像として出力する際にマーカーを除きたい場合は、[`\![execute,dumpballoon]`](../misc/bang-execute-dumpballoon-ID-prefix-ID.md)の--hide=balloonmarkerを使う。

**対応:** SSP 2.6.67
