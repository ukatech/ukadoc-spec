# `\_b[ファイルパス,x,y,opaque]`

**カテゴリ:** バルーン、テキストコマンド

画像をバルーンのXY座標に貼り付ける。画像は文字の下に表示される。<br />
左上の色を透過しないで表示する。<br />
\[実行したゴーストのフォルダ\]/ghost/masterが基準のフォルダとなる。<br />
※ファイル名の代わりにbase64エンコードやexe/dllのリソースを画像として指定可能、[※下記参照](note-1.md#補足)。

**対応:** SSP

## 記述例

```sakurascript
\_b[..\..\shell\master\surface0.png,0,15,opaque]本体側バルーンに、[実行したゴーストのフォルダ]/shell\masterフォルダにあるsurface0.pngを、バルーン内座標X:0,Y:15に、透過せずに表示する。
```
