# `\_b`\[ファイルパス,inline,[オプション](note-1.md#_bファイルパスについて),オプション...\]

**カテゴリ:** バルーン、テキストコマンド

バルーンのテキスト行内に1文字分扱いとして画像を貼り付ける。<br />
\[実行したゴーストのフォルダ\]/ghost/masterが基準のフォルダとなる。<br />
※ファイル名の代わりにbase64エンコードやexe/dllのリソースを画像として指定可能、[※下記参照](note-1.md#補足)。

指定できるオプションについては[※下記参照](note-1.md#_bファイルパスについて)。

## 記述例

```sakurascript
本体側バルーンに、[実行したゴーストのフォルダ]/ghost/masterフォルダにあるtest.png\_b[test.png,inline,--option=use_self_alpha,--clipping=100 30 150 90]を、文字扱い、ファイルの透過情報付きpngとして、画像の横100～150pixel縦30～90pixelの範囲を表示する。
```

**対応:** SSP
