# `\_b[ファイルパス,inline]`

**カテゴリ:** バルーン、テキストコマンド

バルーンのテキスト行内に1文字分扱いとして画像を貼り付ける。<br />
\[実行したゴーストのフォルダ\]/ghost/masterが基準のフォルダとなる。<br />
※ファイル名の代わりにbase64エンコードやexe/dllのリソースを画像として指定可能、[※下記参照](note-1.md#補足)。

**対応:** SSP / Ninix

## 記述例

```sakurascript
本体側バルーンに、[実行したゴーストのフォルダ]/ghost/masterフォルダにあるtest.png\_b[test.png,inline]を、現在のバルーン内の文字表示位置に、左上のドットを透過色として、表示する。
```
