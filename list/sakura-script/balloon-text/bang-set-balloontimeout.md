# `\![set,balloontimeout,時間]`

**カテゴリ:** バルーン、テキストコマンド

バルーン表示のタイムアウトの時間を指定する。単位はミリ秒。<br />
タイムアウトの時間はスクリプトの表示が終わってからカウントされる。0または負数でタイムアウトなし。<br />
そのスクリプト中のみ有効。

時間指定を省略：デフォルト値に戻す<br />
時間指定が0か-1：タイムアウトしない

**対応:** SSP

## 記述例

```sakurascript
\![set,balloontimeout,3000]このトークは、喋り終わってから3秒でバルーンが閉じる。
```
