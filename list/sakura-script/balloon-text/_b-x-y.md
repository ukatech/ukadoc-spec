# `\_b[ファイルパス,x,y]`

**カテゴリ:** バルーン、テキストコマンド

画像をバルーンのXY座標に貼り付ける。画像は文字の下に表示される。<br />
左上ピクセルの色が透過色となる。<br />
\[実行したゴーストのフォルダ\]/ghost/masterが基準のフォルダとなる。<br />
※SSPのみファイル名の代わりにbase64エンコードやexe/dllのリソースを画像として指定可能、[※下記参照](note-1.md#補足)。<br />
※SSPのみ画像URLを指定可能。<br />
※SSPのみプラグインフォルダ内のファイルも探索する。

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\_b[image\test.png,50,100]本体側バルーンに、[実行したゴーストのフォルダ]/ghost/master/imageフォルダにあるtest.pngを左上のpixelを透過色として、バルーン内座標X:50,Y:100に表示する。
```
