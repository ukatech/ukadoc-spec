# `\c[line,数値]`

**カテゴリ:** バルーン、テキストコマンド

現スコープ側の、バルーンのカーソル位置から指定行数をクリア。<br />
トークを`\_l[x,y]`,`\n`,`\n[half]`,`\n[パーセント]`で分割したものが「行」の扱い。ただし、`\n`\\nなど、`\_l[x,y]`以外で分割された内容のないものは行とみなされない。<br />
`\c[char,数値]`と同様に、スクリプト内の出現順が参照される。

**対応:** SSP

## 記述例

```sakurascript
トークを1行削除。\nこの行が削除される。\c[line,1]削除終了。\nこの行は削除される。\n\n\n\n\n\c[line,1]削除終了。\nこの行は削除されない。\_l[0,0]\c[line,1]削除終了。
```
