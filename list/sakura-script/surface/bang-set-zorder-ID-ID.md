# `\![set,zorder,スコープID,スコープID,...]`

**カテゴリ:** サーフェスコマンド

指定スコープのウインドウを左側から順に手前側に配置する。<br />
例：`\![set,zorder,1,0]`と指定すると、必ず`\1`が`\0`ウインドウより手前に表示される。

バルーンもあわせたZ順制御をしたい場合は、以下の例に従うこと。<br />
例：`\![set,zorder,balloon1,surface1,balloon0,surface0]`<br />
例(省略記法)：!\[set,zorder,b1,s1,b0,s0\]<br />
これを指定すると、`\1`のバルーン - `\1`の立ち絵 - `\0`のバルーン - `\0`の立ち絵、の順に厳密に制御される。

それぞれスコープIDの違うタグを複数回実行すると、複数のグループが作れる。<br />
例：`\![set,zorder,1,0]` `\![set,zorder,3,2]` と実行すると、`\1`が`\0`より前、`\p[3]`が`\p[2]`より前に表示される。<br />
バルーンもあわせた記法の場合も同じ。

指定できるスコープIDの数に制限はないが、大量に指定するとちょっと重くなるので、2～3個程度が望ましい。<br />
すでにペアにしたスコープIDを含むタグを実行するとエラーとなる。組み合わせを変える場合は`\![reset]`タグを使ってからやり直すこと。

特定のキャラクターだけを最前面・最背面に置きたい場合は、スコープIDの前に`front`または`back`を付ける。キャラクターが多いゴーストで、全員を列挙せずに済む。<br />
例：`\![set,zorder,front,0]`と指定すると、`\0`が他のすべてのキャラクターより手前に表示される。<br />
例：`\![set,zorder,back,3]`と指定すると、`\p[3]`が他のすべてのキャラクターより奥に表示される。<br />
複数のスコープIDを書いた場合は、書いた順に手前から並ぶ。`front`と`back`は続けて書ける。<br />
例：`\![set,zorder,front,1,0,back,3,2]`と指定すると、手前から`\1`、`\0`、(それ以外のキャラクター)、`\p[3]`、`\p[2]`の順になる。

`front`または`back`を指定すると、それ以外のキャラクターは、スコープIDが小さいものほど手前になる順に並ぶ。<br />
`front`と`back`は、それぞれ複数回に分けて実行してもよい。実行した順に、それぞれの末尾へ追加される。すでに指定したスコープIDを、もう一度指定し直すと、その位置へ移る。前面と背面の両方に指定することはできず、後から指定したほうになる。<br />
バルーンは、スコープIDだけを並べる記法と同じく、いちばん手前のキャラクターより手前に並ぶ。<br />
`front`・`back`は、スコープIDだけを並べる記法やs,b記法と併用できない。後から実行したほうの記法に切り替わり、前の指定は捨てられる。

ゴースト終了まで有効。

**対応:** SSP 2.3.77/2.7.34(s,b記法)/2.9.35(front,back記法)

## 記述例

```sakurascript
\![set,zorder,1,0]相方側が、必ず本体側の手前に表示される。
```
