# `\![set,sticky-window,スコープID,スコープID,...]`

**カテゴリ:** サーフェスコマンド

指定スコープのウインドウをドラッグ中やmoveタグを実行中にセットで動くようにする。<br />
例えば1,0と指定すると、マウスのドラッグ移動などを実行した時、`\0`(相方側)と`\1`(本体側)ウインドウがセットで移動するようになる。

それぞれスコープIDの違うタグを複数回実行すると、複数のグループが作れる。<br />
例：`\![set,sticky-window,1,0]` `\![set,sticky-window,3,2]` と実行すると、`\1`と`\0`がセット、`\p[3]`と`\p[2]`がセットになる。

指定できるスコープIDの数に制限はないが、大量に指定すると**ずいぶん**重くなるので、2～3個程度が望ましい。<br />
すでにペアにしたスコープIDを含むタグを実行するとエラーとなる。組み合わせを変える場合は`\![reset]`タグを使ってからやり直すこと。

`\![set,alignmenttodesktop]`などでウインドウ位置に制限がある場合は、その制限が優先され、X,Yのうち自由に動かせるものだけが追従する。<br />
`\![move]`タグでグループ化したウインドウ内の1つを動かした場合でも、他のウインドウも追従する。<br />
ただし、moveタグの --option=ignore-sticky-window で単独移動可能になる。

ゴースト終了まで有効。

**対応:** SSP 2.3.77

## 記述例

```sakurascript
\![set,sticky-window,1,0]相方側が、本体側とセットで動く。
```

```sakurascript
\![set,sticky-window,0,1,2]本体側と相方側と3人目がセットで動く。
```

```sakurascript
\1\![move,40,100,0,0,left.top,left.top]相方側の左上を、本体側の左上に合わせた後、右へ40pixel下へ100pixel移動させる。\![set,sticky-window,1,0]その状態で、相方側と本体側をセットで動くようにする。
```
