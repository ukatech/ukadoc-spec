# `\![change,calendarskin,カレンダースキン名]`

**カテゴリ:** イベントコマンド

カレンダーのスキンを切り替える。カレンダーのメニューからスキンを選んだ場合と同じ。<br />
該当するカレンダースキンがなかった場合は無視される。<br />
カレンダーを一度も開いていない場合は設定だけが変更され、次にカレンダーを開いたときに反映される。

カレンダースキン名をlastinstalledにすると最後にインストールしたカレンダースキンに切り替え。ただしSSPを一度終了した場合は無効。<br />
カレンダースキン名をrandomにするとランダムに切り替え。<br />
カレンダースキン名は[installedcalendarskinname](../../shiori-event/notify/installedcalendarskinname.md)で通知される。

**対応:** SSP 2.8.93
