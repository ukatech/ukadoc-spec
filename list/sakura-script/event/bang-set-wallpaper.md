# `\![set,wallpaper,ファイル名,オプション]`

**カテゴリ:** イベントコマンド

指定したファイルを壁紙にする。<br />
ファイル名には、絶対パスの他、相対パスが使用可能。相対パスは\[実行したゴーストのフォルダ\]/ghost/master、\[実行したゴーストのフォルダ\]、SSPのフォルダの順に探す。<br />
先頭が!の場合はSSPのフォルダから、\\または/の場合はSSPのあるドライブのルートからの相対パスとみなす。<br />
ファイル名を指定しないか空にすると壁紙設定が解除される(壁紙のない、背景色だけの状態になる)。<br />
オプションは以下の通り。

- **center**: 中央表示（省略時デフォルト）
- **tile**: 並べて表示する（タイリング）
- **stretch**: 画像の縦横比を無視して、モニタいっぱいに拡大する。
- **stretch-x**: 画像の横幅をモニタ幅いっぱいに合わせるようにして、縦横比を考慮して拡大する。Windows 7以降のみ。
- **stretch-y**: 画像の高さをモニタ高さいっぱいに合わせるようにして、縦横比を考慮して拡大する。Windows 7以降のみ。
- **fit**: 画像の縦横比を保ったまま、画像全体がモニタに収まるように拡大縮小する。余白には背景色が表示される。
- **fill**: 画像の縦横比を保ったまま、モニタ全体を覆うように拡大縮小する。はみ出した部分は表示されない。
- **span**: マルチモニタ環境において、全モニタに渡るように拡大する。Windows 10以降のみ。

\[2.8.93\] 以下の形式でも指定できる。--で始まる引数は順不同で、上記のファイル名・オプションによる指定と混在してもよい（--で始まらない引数は、現れた順にファイル名・オプションとみなす）。

- **--file=ファイル名**: 壁紙にするファイル。上記のファイル名と同じ。
- **--position=配置**: 画像の配置。上記のオプションと同じ値を指定する。省略時はcenter。
- **--color=色指定**: 背景色（画像の余白や、画像を指定しない場合の単色背景に使われる色）。[文字色指定の方法](../choice-marker/note-1.md#形状指定の方法)のうち、R,G,B・R%,G%,B%・16進数カラーコード・定義済みキーワードが使用可能。<br />
  R,G,Bのようにカンマを含む書式は、"--color=255,128,0"のように引数全体をダブルクォートで囲むこと。<br />
  色として解釈できない値を指定した場合、このタグは何もしない。

\[2.8.93\] ファイル名と--colorの有無によって、以下のように動作する。

- **ファイル名のみ**: 画像を壁紙にする。背景色は変更しない。
- **ファイル名と--color**: 画像を壁紙にし、背景色も変更する。
- **--colorのみ**: 画像なしの、指定色の単色背景にする。
- **どちらもなし**: 壁紙設定を解除する（壁紙を外し、背景色だけの状態にする。背景色は変更しない）。

\[2.8.93\] ウインドウモードで動作中は、OSの壁紙を変更せず、そのゴーストが表示されているウインドウモードのウインドウの背景を変更する（全ゴーストで1つのウインドウを共有している場合は、全ゴーストの背景が変わる）。<br />
背景の設定は「背景 - 画像」扱いになり、SSP終了後も保持される。<br />
配置はspanのみfillと同じ扱いになる。--colorを省略した場合、背景色は画像の主な色になる。<br />
ファイル名も--colorも指定しない場合は、背景を「背景 - デスクトップ」（OSの壁紙を再現する設定）に戻す。<br />
画像ファイルのドラッグ＆ドロップによる壁紙変更も、同様にウインドウモードの背景を変更する。

**対応:** SSP / Ninix

## 記述例

```sakurascript
Emily/Phase4.5のサムネイルを壁紙にする。\![set,wallpaper,ghost/emily4/thumbnail.png]
```

```sakurascript
画像全体が収まるように表示し、余白を紺色にする。\![set,wallpaper,--file=ghost/emily4/thumbnail.png,--position=fit,--color=navy]
```

```sakurascript
画像なしの単色背景にする。\![set,wallpaper,"--color=32,64,96"]
```
