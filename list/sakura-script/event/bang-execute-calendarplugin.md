# `\![execute,calendarplugin,カレンダープラグイン名]`

**カテゴリ:** イベントコマンド

カレンダープラグイン(スケジュールセンサ)の予定取得を開始する。カレンダーのメニューからプラグインを選んだ場合と同じ。<br />
カレンダーを表示していない場合も実行される。<br />
カレンダープラグイン名をrandomにするとランダムに選択。<br />
lastinstalledにすると最後にインストールされたカレンダープラグインを実行。ただしSSPを一度終了した場合は無効。<br />
該当するカレンダープラグインがなかった場合は無視される。<br />
カレンダープラグイン名は[installedcalendarpluginname](../../shiori-event/notify/installedcalendarpluginname.md)で通知される。

**対応:** SSP 2.8.93
