# `\_`+

**カテゴリ:** イベントコマンド

次の順番のゴーストに切り替わる(シーケンシャルチェンジ)。ゴーストエクスプローラで下側にいるゴーストに切り替わる。<br />
リストの一番下だった場合、リストの一番上のゴーストに切り替わる。<br />
このスクリプトによる切り替えではSHIORIイベント[OnGhostChanging](../../shiori-event/boot-close-change/OnGhostChanging.md)は通知されない。

**対応:** Materia / SSP / Ninix

## 記述例

```sakurascript
リストの次のゴーストへチェンジ。\_+
```
