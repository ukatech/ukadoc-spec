# `\![set,trayballoon,オプション,オプション,オプション...]`

**カテゴリ:** イベントコマンド

トレイアイコンからバルーンを表示する。<br />
バルーンをクリックして消した時にOnTrayBalloonClickが発生。<br />
タイムアウトした時や閉じるボタンで閉じた時にOnTrayBalloonTimeoutが発生。<br />
指定できるオプションは以下。

Windows 10以降で、ファイルの関連付けの設定が「ショートカットのみ」以上の場合(キオスクモード・読み取り専用モードを除く。設定の変更は次回起動から反映)は、バルーンの代わりにトースト通知で表示し、通知センターに残るようになる。この場合トレイアイコン側には表示しない。条件を満たさない場合や表示に失敗した場合は従来どおりバルーンで表示する。<br />
トースト通知では、クリックした時にOnTrayBalloonClick、閉じるボタンで閉じた時や時間切れで通知センターに移った時にOnTrayBalloonTimeoutが発生する。通知センターに移った後にクリックしてもイベントは発生しない。\[2.9.14\]

- **--text=テキスト**: バルーンに表示する文字列、複数指定で複数行に。(必須)
- **--title=タイトル**: バルーンのタイトル。
- **--icon=アイコン設定名**: バルーンに表示されるアイコンの設定。<br />
  トースト通知では、アイコンは本文の左に表示される。\[2.9.14\]
- **info**: 情報アイコン
- **error**: エラーアイコン
- **warning**: 警告アイコン
- **none**: なし
- **--timeout=秒数**: バルーンの表示時間(単位＝秒)。10～30秒の間でのみ指定可。Windows 7以降では無視される。トースト通知でも無視される。\[2.9.14\]

**対応:** SSP

## 記述例

```sakurascript
\![set,trayballoon,--text=何らかのエラーにより、処理が失敗しました,--title=エラーが発生しました,--icon=error]
```
