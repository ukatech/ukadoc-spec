# `\__q[ID,...]`

**カテゴリ:** 選択肢コマンド

`\__q`がくるまでの範囲を選択肢とする。<br />
ID仕様は、Onやscript:で始まるものが特別扱いされる点や、ID引数の扱いまで含めて`\q`と同じ。<br />
実行後に発生するSHIORI Eventも同様。<br />
`\q[]`タグと異なり、自動改行も行われる。

**対応:** SSP / Ninix

## 記述例

```sakurascript
\__q[OnTest,testreference]間にさくらスクリプトも挟める。\n改行、\_l[50,50]カーソル移動も可能で、画像を貼れば画像が選択肢になる。\__qこの例の場合、IDが「On」から始まっているため、選択時にOnTestイベントが発生し、reference0には「testreference」が格納されている。
```
