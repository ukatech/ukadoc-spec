# `\_a[OnID,r0,r1...]`

**カテゴリ:** 選択肢コマンド

`\_a`がくるまでの範囲をアンカーとする。選択肢タイムアウトしないが、通常トーク同様バルーンタイムアウトする。<br />
上記のようにIDが"On"で始まっている場合は、クリックするとSHIORIイベントOnID(書いた通りのイベント)が開始される。<br />
IDに続く引数が順番にReference0以降に格納される。

**対応:** SSP / Ninix

## 記述例

```sakurascript
\_a[OnHint,0]ヒント\_aが欲しいならクリックしよう。\_a[OnHint,1]ほらほら早く\_a。この2つのアンカーは、クリックするとSHIORIイベントOnHintが通知されるが、クリックしたものによってReference0の値が「0」か「1」に変わる。
```
