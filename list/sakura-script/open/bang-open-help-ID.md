# `\![open,help,ダイアログID]`

**カテゴリ:** オープンコマンド

SSPヘルプを開く。<br />
ダイアログIDに設定ダイアログのID名(※[OnConfigurationDialogHelpのReference0参照](../../shiori-event/dialogbox/OnConfigurationDialogHelp.md))で、その設定ダイアログについてのヘルプを展開。省略時はインデックスページを開く。

**対応:** SSP

## 記述例

```sakurascript
\![open,help,talk]ブラウザで、http://ssp.shillest.net/ukadoc/ssphelp/の喋り/バルーンのページを開く。
```
