# `\j[ID]`

**カテゴリ:** オープンコマンド

IDにジャンプする。<br />
http://～でURLジャンプする。<br />
file:///～でOSに関連付けられた拡張子でファイルを実行する。ファイル名には、絶対パスの他、\[実行したゴーストのフォルダ\]/ghost/masterからの相対パスが使用可能。<br />
※SSPのみ mailto:～でその宛先の新規メールを作成する

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\j[http://ssp.shillest.net/]ばぐとら研究所をブラウザを立ち上げて表示する。
```

```sakurascript
\j[file:///descript.txt][実行したゴーストのフォルダ]/ghost/masterフォルダにあるdescript.txtを開く。
```
