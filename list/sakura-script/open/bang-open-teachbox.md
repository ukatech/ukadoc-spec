# `\![open,teachbox]`

**カテゴリ:** オープンコマンド

TeachBoxを開く。実行と同時に[OnTeachStart](../../shiori-event/inputbox/OnTeachStart.md)が通知され、TeachBoxのOKボタンを押すと[OnTeach](../../shiori-event/inputbox/OnTeach.md)、閉じると[OnTeachInputCancel](../../shiori-event/inputbox/OnTeachInputCancel.md)が通知される。

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\![open,teachbox]TeachBoxを開く。
```
