# `\![open,configurationdialog,ダイアログID]`

**カテゴリ:** オープンコマンド

設定ダイアログ(オーナードローメニューの「本体設定」)を開く。<br />
ダイアログIDで初期表示する画面を指定できる(省略時は前回開いた画面)。<br />
SHIORI Event ※[OnConfigurationDialogHelp](../../shiori-event/dialogbox/OnConfigurationDialogHelp.md)のReference0参照。

**対応:** Materia / SSP / CROW / Ninix

## 記述例

```sakurascript
\![open,configurationdialog,talk]SSP本体設定ダイアログの喋り/バルーンのタブを開く。
```
