# `\f[align,寄せる側]`

**カテゴリ:** 文字変更コマンド

文字列の右寄せ(`\f[align,right]`)・中央揃え(`\f[align,center]`)・左寄せ(`\f[align,left]`)を設定する。<br />
この設定は、次の`\n`や`\_l`などの「意図的な改行」が来るまで影響する。<br />
また、文字等の追加の途中でこのコマンドを実行すると、すでに追加された同じ行に属する文字列も移動される。<br />
`\_l`タグが来た場合は左寄せに戻る。<br />
また、`\_l`タグで移動後に`\f[align]`タグで中央揃えを設定した場合、`\_l`タグのX座標分インデント処理されたと仮定して中央揃え処理される。<br />
縦書きモードの場合は、left＝上寄せ、right＝下寄せ、center＝縦中央寄せとなる。

**対応:** SSP 2.5.31

## 記述例

```sakurascript
\f[align,center]これは中央揃え。\n\f[align,right]これは右揃え。\n\f[align,left]左揃えのつもりが\w9\w9\f[align,right]右揃えに。
```
