# `\f[height,数値]`

**カテゴリ:** 文字変更コマンド

これテキストを指定した文字サイズに変更する。<br />
+や-による相対的な変更が可能。<br />
スタイルシートのサイズ指定も可能。<br />
defaultを指定するとバルーン設定の標準に戻る。

**対応:** SSP / Ninix

## 記述例

```sakurascript
\f[height,15]15pixelで表示。\f[height,+3]3pixel大きくする。\f[height,200%]デフォルトサイズの200%で表示。\f[height,default]元のサイズに戻す。
```
