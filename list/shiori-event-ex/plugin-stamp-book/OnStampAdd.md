# OnStampAdd

**カテゴリ:** プラグイン「スタンプ帳」

スタンプを押すためにraisepluginでスタンプ帳へ送信するイベント。

- **Reference0**: スタンプの画像ファイルのパス。
- **Reference1**: スタンプのタイトル。<br />
  さくらスクリプトを含まない文字列（除去される）を指定。<br />
  省略可。
- **Reference2**: スタンプのコメント。<br />
  さくらスクリプトを含まない文字列（除去される）を指定。<br />
  &lt;br\>（&lt;BR\>、＜br＞、＜BR＞）で改行可能。<br />
  省略可。
