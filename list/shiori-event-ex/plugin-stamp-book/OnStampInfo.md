# OnStampInfo

**カテゴリ:** プラグイン「スタンプ帳」

スタンプに関する情報を通知するイベント。<br />
ゴースト起動時、プラグインのロード・アンロードおよびOnStampInfoCallを送信した任意のタイミングで発生。

- **Reference0**: スタンプ総数。
- **Reference1**: 当該ゴーストのスタンプが存在するか否か。あれば1、なければ0。<br />
  複数ゴースト起動していると信用性が薄くなるので、確実に知りたい場合はOnStampInfoCallによって当イベントを能動的に発生させる事が推奨される。
- **Reference2**: プラグインのパス。
- **Reference3**: 全スタンプ情報。ゴースト名・スタンプ画像ファイル名・スタンプのタイトル・スタンプのコメント・スタンプを押した時刻がバイト値１区切りで、それがスタンプの数だけ各セットバイト値２区切りで入っている。
- **Reference4**: このプラグインが動いていれば1、さもなくば0。
