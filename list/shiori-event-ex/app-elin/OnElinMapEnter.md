# OnElinMapEnter

- **Reference1**: 敵NPCの情報
- **Reference2**: 中立NPCの情報

- **Reference4**: 味方NPCの情報

- **Reference6**: 街かどうか
- **Reference7**: ネフィアかどうか
- **Reference8**: PCの所有物件(?)かどうか
- **Reference9**: 固定ネフィアかどうか
- **Reference10**: 何も無いフィールドマップかどうか
