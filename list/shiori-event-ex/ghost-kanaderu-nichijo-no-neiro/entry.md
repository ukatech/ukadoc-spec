# 可変名の返信イベント

**カテゴリ:** ゴースト「奏でる日常の音色」

OnKanadeTeaPartyInfomationRequestを受信したゴーストが、*奏でる日常の音色に対して*raiseotherで*通知する*イベント。<br />
イベント名はOnKanadeTeaPartyInfomationRequestのreference2で通知されている。

- **Reference0**: ゴーストの対応するお茶会バージョン番号
- **Reference1**: ゴーストの本体側名
- **Reference2**: [※お茶会バージョンへの対応情報](note-1.md#補足)
