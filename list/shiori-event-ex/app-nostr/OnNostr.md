# OnNostr

**カテゴリ:** Nostr通知イベント

## Nostr/0.5における通知情報

- **Reference0**: バージョン（Nostr/0.5）
- **Reference1**: Nostrイベントのkind(数値)(1:note, 7:reaction, ...)
- **Reference2**: Nostrイベントのcontent
- **Reference3**: Nostrイベント署名者のkind0のname
- **Reference4**: Nostrイベント署名者のkind0のdisplay_name
- **Reference5**: Nostrイベント署名者のkind0のpicture
- **Reference6**: NostrイベントのidのNIP-19エンコード(note1...またはnevent1...)
- **Reference7**: Nostrイベント署名者の公開鍵のNIP-19エンコード(npub1...)
- **Reference8**: Nostrイベントのgタグの値
- **Reference9**: Nostrイベントのnタグの値
- **Reference10**: Nostrイベントのtタグの値
