# tooltip

**カテゴリ:** ツールチップ系

シェルにおけるツールチップ内容の取得。<br />
シェルのサーフェスにマウスカーソルが乗った際に通知。<br />
[シェル側設定](../../../descript/shell-surfaces/tooltip-brace/entry.md)がある場合はそちらが優先される。

- **Reference0**: マウスカーソルの x 座標（ローカル座標）
- **Reference1**: マウスカーソルの y 座標（ローカル座標）
- **Reference2**: 常に0。
- **Reference3**: 本体の場合は0、相方の場合は1。SSP/CROWでは2以降もある。
- **Reference4**: 当たり判定の識別子。
- **Reference5**: 常に0。

**対応:** SSP
