# PLUGIN Eventリスト

このページでは、ベースウェアからプラグイン*に対して*通知されるイベントについてまとめています。

PLUGIN/2.0の通信仕様そのものについて等は、[PLUGIN/2.0](../../spec/plugin.md)のページにあります。

*\[NOTIFY\]*の表示があるイベントは、必ずNOTIFYコマンドで通知されます。<br />
NOTIFYコマンドで通知されたイベントにスクリプトを返却しても一切無視されます。

特に表示がないイベントは、状況によってNOTIFY、GETのいずれでも通知される可能性があります。
