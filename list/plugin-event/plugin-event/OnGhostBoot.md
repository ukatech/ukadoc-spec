# OnGhostBoot

**カテゴリ:** PLUGIN Event

ゴースト起動時に発生。

- **Reference0**: バイト値1区切りで、起動したゴーストの`\0`以降各キャラクターウィンドウのHWND。<br />
  未構築の場合等、0が入る場合がある。
- **Reference1**: 起動したゴースト名。
- **Reference2**: 起動したゴーストの現在のシェル名。
- **Reference3**: 起動したゴーストのID (Owned SSTPで送られるものと同じ）。
- **Reference4**: 起動したゴーストのフルパス。

**対応:** SSP
