# OnChoiceSelect(Ex)/OnAnchorSelect(Ex)/`\q`等に指定された任意名イベント

**カテゴリ:** PLUGIN Event

選択肢・アンカー選択時に発生するSHIORI Eventのプラグイン側フック。<br />
プラグインがゴーストに送信したスクリプトおよび、プラグインがゴーストに通知したイベントに対してゴーストから返信されたスクリプトに、選択肢・アンカー系のさくらスクリプトタグが含まれる場合、その一回に限って選択肢・アンカー選択時にSHIORI側に通知されるのと同じイベントが、プラグイン側にも横流し通知される。

- **Reference\***: 発生した選択肢・アンカー系SHIORI EventのReference。

**対応:** SSP
