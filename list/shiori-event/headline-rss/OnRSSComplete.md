# OnRSSComplete

**カテゴリ:** ヘッドライン/RSSセンスイベント

ヘッドラインセンスが正常に終了した際に発生。本イベントに反応しない場合は、表示に適切なスクリプトを生成しヘッドライン完了系イベントが呼び出される。

- **Reference0**: 更新が無い時：no update　[※終了理由](caption_headlinesenseresult.md)<br />
  更新が無い時はReference0のみでかつ"no update"という文字列のみ<br />
  更新が有る時：RSS配信サイト名。
- **Reference1**: 更新が有る時のみ：RSSの配信元URL(フィードそのものではなく配信サイトを指すもの)
- **Reference2～**: 更新が有る時のみ：タイトル \[`\1`\] URL \[`\1`\] 更新日時（フォーマットはカンマ区切り：年,月,日,時,分,秒）\[`\1`\] 作者名 \[`\1`\] 内容または要約<br />
  更新がある時はRSSの要素数分Reference0,1,2～と続く<br />
  \[`\1`\]はバイト値1

**対応:** SSP 作者名・内容 2.4.10～
