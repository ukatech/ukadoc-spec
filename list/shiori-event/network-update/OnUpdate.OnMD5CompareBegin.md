# OnUpdate.OnMD5CompareBegin

**カテゴリ:** ネットワーク更新イベント

MD5の照合開始の際に発生。

- **Reference0**: 比較するファイル名。
- **Reference1**: 正しいMD5値。
- **Reference2**: 落としたファイルのMD5値。
- **Reference3**: SSP　[※更新対象種別](caption_updatetype.md)
- **Reference4**: SSP 2.3：[※更新実行理由](caption_updatereason.md)。

**対応:** Materia / SSP / CROW / Ninix
