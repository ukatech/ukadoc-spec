# ネットワーク失敗理由

- **timeout**: タイムアウトした。
- **too slow**: *SSPではtimeoutになるため不出*。回線が非常に重い。
- **md5 miss**: MD5が一致しなかった。
- **artificial**: ユーザ操作による更新中断。
- **404 等**: そのステータスコードでの失敗。
- **fileio**: ※SSPのみ。容量不足による更新対象への書き込み失敗。
- **readonly**: ※SSPのみ。読み取り専用フラグによる更新対象への書き込み失敗。ファイルやフォルダに読み取り専用フラグがついていると発生。
- **virusdetect**: ※SSPのみ。データ内にウイルスを検出した可能性がある。 \[2.5.15\]
- **toomanyredirect**: ※SSPのみ。リダイレクトが発生しすぎたので処理を中止した。 \[2.5.15\]
- **executing**: ※SSPのみ。すでに更新を実行中のため、二重起動を阻止した。 \[2.5.26\]
- **parse**: ※SSPのみ。取得はできたが、内容の解析に失敗した。rss-get/rss-post・ical-get/ical-postで発生する。
- **downloading**: ※SSPのみ。同じURLの取得がすでに進行中のため、二重取得を阻止した。execute-http/rss/icalで発生する。 \[2.8.90\]
- **paramerror**: ※SSPのみ。更新実行タグの設定ミスにより更新を実行できなかった。 \[2.5.26\]
