# OnUpdate.OnDownloadBegin

**カテゴリ:** ネットワーク更新イベント

ファイルダウンロード開始の際に発生。

- **Reference0**: ダウンロードするファイル名。
- **Reference1**: （CROW以外）ダウンロード中の更新ファイルの番号（0から始まる連番）。
- **Reference2**: （CROW以外）更新を行うファイルの総数から1引かれたもの（0から始まる連番）。
- **Reference3**: （SSPのみ）[※更新対象種別](caption_updatetype.md)。
- **Reference4**: SSP 2.3：[※更新実行理由](caption_updatereason.md)。

**対応:** Materia / SSP / CROW / Ninix
