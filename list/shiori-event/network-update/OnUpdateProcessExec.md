# OnUpdateProcessExec

**カテゴリ:** ネットワーク更新イベント

メニューなどから更新を実行する指示がなされた場合に発生する。<br />
このイベントに対して何かスクリプトを返すと、更新処理をカスタマイズできる。<br />
イベントを無視した場合は標準の更新処理に自動的に移行する。

- **Reference0**: manual : メニューから更新の操作をした。<br />
  auto : あらかじめ設定した定期自動更新処理が動いた。<br />
  testonly : 開発用パレットのUpdate Full Checkを実行した。

**対応:** SSP 2.6.23
