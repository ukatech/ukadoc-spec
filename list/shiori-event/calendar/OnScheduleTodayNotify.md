# OnScheduleTodayNotify

**カテゴリ:** カレンダーイベント

本体カレンダー機能の「今日の予定」の内容が変化した際に発生。*\[NOTIFY\]*<br />
日付が変わった時、予定を追加・削除した時、スケジュールセンサの取得結果が変わった時など。変化が無ければ発生しない。<br />
特定のゴーストではなく起動中の全ゴーストに通知される。

Reference0以降が更新後の「今日の予定」1件ずつ。各Referenceの中はバイト値1（以下\[`\1`\]）で区切られている。<br />
予定が1件も無くなった場合はReferenceが1つも無い状態で発生する。

- **Reference0～**: イベントの[タイプ](caption_scheduletype.md) \[`\1`\] イベントの内容(caption) \[`\1`\] 追加データ(subtitle) \[`\1`\] スクリプト(script) \[`\1`\] 開始日時 \[`\1`\] 終了日時 \[`\1`\]<br />
  予定の数だけReference0,1,2～と続く。末尾にも区切りの\[`\1`\]が付く点に注意。<br />
  開始日時・終了日時はカンマ区切りの「年,月,日,時,分,秒」形式。時刻を設定していない予定は時・分・秒が空になり「2026,9,10,,,」のようになる。<br />
  終了日時は終了時刻を設定した予定にのみ入る。設定が無ければ空。<br />
  caption・subtitle・scriptは本体カレンダーに登録された文字列そのままで、さくらスクリプト用のエスケープは行われない。

**対応:** SSP 2.8.90
