# OnGhostCalled

**カテゴリ:** 起動・終了・切り替えイベント

他のゴーストから呼び出された際に発生。<br />
SSPでは、このイベントにスクリプトが返されなかった（204）場合、続けて[OnBoot](OnBoot.md)が発生する。

- **Reference0**: 呼び出したゴーストの本体側の名前。
- **Reference1**: 呼び出したゴーストの呼び出し時のスクリプト。
- **Reference2**: 呼び出したゴーストの名前。
- **Reference3**: 呼び出したゴーストのパス。
- **Reference7**: *呼び出されたゴーストの*シェル名。

**対応:** SSP
