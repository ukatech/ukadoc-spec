# OnWindowStateMinimize

**カテゴリ:** 起動・終了・切り替えイベント

最小化が指示された際に発生。<br />
※SSPのみ設定で喋らせることが可能。

- **Reference0**: （SSPのみ）最小化された理由。<br />
  system : OSからの強制的な最小化操作（タスクバーから最小化された場合を含む）<br />
  script : SakuraScriptから<br />
  sakuraapi : Sakura APIから<br />
  user : メニュー操作

**対応:** Materia / SSP / CROW / Ninix
