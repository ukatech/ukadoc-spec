# OnOtherObjectDropping

**カテゴリ:** ファイルドロップイベント

「ファイル」として扱えないもののカーソルがゴースト上に乗った際に発生。例：Windowsの「マイコンピュータ」など

- **Reference0**: ドロップされたキャラクターのスコープ番号。本体側0、相方1、3人目以降は2以降。

- **Reference1**: ドロップされたものの名前(OSの言語設定に影響される)。<br />
  複数ある場合はバイト値1区切り。

- **Reference2**: ドロップされたもののOSの言語設定に識別されないIDのようなもの。<br />
  複数ある場合はバイト値1区切り。以下はWindows上の例。

  - PC(マイコンピュータ) = ::\{20D04FE0-3AEA-1069-A2D8-08002B30309D\}
  - ゴミ箱 = ::\{645FF040-5081-101B-9F08-00AA002F954E\}
  - (マイ)ネットワーク = ::\{F02C1A0D-BE21-4350-88B0-7367FC96EF3C\}

**対応:** SSP 2.6.41
