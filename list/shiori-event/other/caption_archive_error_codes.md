# アーカイブ操作エラーコード

- **none**: エラーなし（正常）
- **invalid parameter**: 無効なパラメータ
- **file not found**: ファイルが見つからない
- **directory not found**: ディレクトリが見つからない
- **create directory failed**: ディレクトリの作成に失敗
- **open failed**: ファイルを開くのに失敗
- **getfileinfo failed**: ファイル情報の取得に失敗
- **goto failed**: ファイル位置の移動に失敗
- **corrupted**: アーカイブが破損している
- **crc**: CRCエラー（データの整合性エラー）
- **stream**: ストリームエラー
- **unknown method**: 不明な圧縮方式
- **password required**: パスワードが必要
- **password mismatch**: パスワードが一致しない
- **close failed**: ファイルのクローズに失敗
