# OnOffscreen

**カテゴリ:** 見切れ・重なりイベント

キャラクター（サーフェス）のウインドウがモニタ（作業領域）外にひっかかった、あるいは出た時に発生。見切れ。<br />
見切れ状態が変わった際に逐次通知されるので、「見切れなくなった」も工夫すれば検出できる。

- **Reference0**: ID \[`\1`\] ID \[`\1`\] ID ...<br />
  \[`\1`\] はバイト値1<br />
  例：1 \[`\1`\] 2 で、1番ウインドウと2番ウインドウが見切れていることを示す。
- **Reference1**: Reference0と同じフォーマットで、状態が変わる前（＝1回前のイベント発生時のReference0）が通知される。

**対応:** SSP / Ninix
