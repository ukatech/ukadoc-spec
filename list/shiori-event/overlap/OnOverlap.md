# OnOverlap

**カテゴリ:** 見切れ・重なりイベント

キャラクター（サーフェス）のウインドウが重なった時に発生。<br />
重なり状態が変わった際に逐次通知されるので、「重ならなくなった」も工夫すれば検出できる。

- **Reference0**: ID-ID \[`\1`\] ID-ID \[`\1`\] ID-ID ...<br />
  \[`\1`\] はバイト値1<br />
  例：0-1 \[`\1`\] 0-2 で、0番ウインドウと1番ウインドウ、0番ウインドウと2番ウインドウが重なっていることを示す。
- **Reference1**: Reference0と同じフォーマットで、状態が変わる前（＝1回前のイベント発生時のReference0）が通知される。

**対応:** SSP / Ninix
