# OnInstallRefuse

**カテゴリ:** インストールイベント

インストールするファイルが他のゴーストを指名していた際に発生。

- **Reference0**: 指定されたゴーストの本体側名（install.txtの[accept](../../../descript/install/install-txt/accept.md)指定、つまり本来渡すべき相手）。
- **Reference1**: インストールしようとした物の[※識別子](caption_install-identifier.md)。
- **Reference2**: インストールしようとした物の名前。

**対応:** Materia / SSP Ref1以降は2.4.85 / CROW / Ninix
