# OnInstallCompleteEx

**カテゴリ:** インストールイベント

インストールが正常終了した際に発生。<br />
このイベントが無かった場合OnInstallCompleteが発生。

- **Reference0**: インストールした物の[※識別子](caption_install-identifier.md)。複数の場合はバイト値1区切り。
- **Reference1**: インストールした物の名前。複数の場合はバイト値1区切り。
- **Reference2**: インストールした場所。複数の場合はバイト値1区切り。

**対応:** SSP / Ninix
