# OnTrayBalloonTimeout

**カテゴリ:** トレイバルーンイベント

トレイアイコンのバルーンをタイムアウトや閉じるボタンで消した際に発生。<br />
バルーンの代わりにトースト通知で表示した場合([`\![set,trayballoon]`](../../sakura-script/event/bang-set-trayballoon.md)参照)は、トーストを閉じるボタンで閉じた際や、時間切れで通知センターに移った際に発生。\[2.9.14\]

- **Reference0**: タイトル文字列。
- **Reference1**: 表示テキスト。

**対応:** SSP
