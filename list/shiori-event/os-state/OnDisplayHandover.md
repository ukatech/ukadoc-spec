# OnDisplayHandover

**カテゴリ:** OS状態イベント

スクリーン間を跨いでウインドウを移動させた際に発生。*\[NOTIFY/他GET\]*

- **Reference0**: init (位置初期化完了時) か update (初期化後の更新) 。<br />
  initは起動後ウインドウの位置が決定した際に通知され、OnBootより前とは限らない。
- **Reference1**: 本体の場合は0、相方の場合は1。SSP/CROWでは2以降もある。
- **Reference2**: 移動前　左,上,右,下,ビット深度,プライマリモニタかどうか(0/1)　init時は空欄<br />
  例： 0,0,1600,900,32,1
- **Reference3**: 移動後　左,上,右,下,ビット深度,プライマリモニタかどうか(0/1)

**対応:** SSP 2.4.09
