# OnOSUpdateInfo

**カテゴリ:** OS状態イベント

OSの更新確認日時・更新実行日時と、履歴情報の通知。<br />
起動直後にNOTIFY(喋れない)で通知され、更新が実行された時に少し遅れてGET(喋れる)で通知される。

- **Reference0**: 確認日時 年,月,日,時,分,秒 半角カンマ区切り ローカル時刻
- **Reference1**: 実行日時 年,月,日,時,分,秒 半角カンマ区切り ローカル時刻
- **Reference2～**: 以下のフォーマットで更新履歴情報が後ろに続く。\[`\1`\]はバイト値1。<br />
  状態\[`\1`\]エラーコード\[`\1`\]更新時刻\[`\1`\]更新内容(タイトル)<br />
  状態：not_started(未実行)・in_progress(更新中)・success(成功)・success_with_errors(一応成功したがエラーあり)・fail(失敗)・abort(中断)・unknown(不明)のいずれか<br />
  エラーコード：更新時にエラーがあれば非0、なければ0。Windowsの場合は16進8桁。<br />
  更新時刻：年,月,日,時,分,秒 半角カンマ区切り ローカル時刻

**対応:** SSP 2.5.02
