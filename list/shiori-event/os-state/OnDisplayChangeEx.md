# OnDisplayChangeEx

**カテゴリ:** OS状態イベント

スクリーンの解像度／色深度が変更された際に発生。マルチモニタ対応。*\[起動時NOTIFY/他GET\]*

- **Reference0**: init (起動時通知) か update (起動後の更新)
- **Reference1～**: 左,上,右,下,ビット深度,プライマリモニタかどうか(0/1),タスクバーの位置(left,top,right,bottom,unknown),タスクバーと作業領域の区切り座標<br />
  例： 0,0,1600,900,32,1,bottom,1560<br />
  [ウインドウモード](OnWindowModeChange.md)では、コンテナのクライアント領域を1枚の画面とした1件だけになる(例： 0,0,1280,720,32,1,unknown,0)。実モニタの変更では発生せず、コンテナのサイズ変更やウインドウモードの切り替えで発生する。

**対応:** SSP 2.4.09/タスクバーは2.6.35
