# OnExecuteFileWatchChange

**カテゴリ:** その他通信イベント

[`\![execute,filewatch]`](../../sakura-script/misc/bang-execute-filewatch.md)で監視しているファイルまたはディレクトリが変化した際に発生。

--asyncでOnから始まるIDを指定した場合は、そのIDがイベント名になる。

ファイルへの書き込みは短い間に何度も起きることがあるため、変化が止んでから--debounceで指定した時間（省略時は500ミリ秒）だけ待ち、まとめて1回発生する。それより長い間隔を空けて書き込まれた場合や、変化が止まないまま最初の変化から指定時間の3倍が経った場合は、1回の保存で複数回発生することがある。

- **Reference0**: --asyncで指定した文字列そのもの（無ければ空）
- **Reference1**: 指定したパスの文字列そのもの
- **Reference2**: 変化の種類<br />
  ファイルの場合 : modified（更新）、created（作成）、deleted（削除）<br />
  ディレクトリの場合 : changed（直下で作成・削除・名前変更・更新のいずれかがあった）、deleted（ディレクトリ自体が無くなった）
- **Reference3**: 監視しているファイルまたはディレクトリのフルパス

**対応:** SSP 2.8.91
