# OnExecuteScheduleGetComplete

**カテゴリ:** その他通信イベント

[`\![execute,schedule-get]`](../../sakura-script/misc/bang-execute-schedule-get.md)で、ゴースト用の予定表を読み出した際に発生。

--eventでOnから始まるIDを指定した場合は、そのIDがイベント名になる。

- **Reference0～**: [OnExecuteICalCompleteと同じ](OnExecuteICalComplete.md)。<br />
  対象はゴースト用の予定表だけで、ユーザーが登録した予定やスケジュールセンサの予定は含まれない。

**対応:** SSP 2.8.91
