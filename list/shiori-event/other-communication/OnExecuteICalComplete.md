# OnExecuteICalComplete

**カテゴリ:** その他通信イベント

[`\![execute,ical-get/ical-post]`](../../sakura-script/misc/bang-execute-ical-get-URL.md)で正常に取得・解析完了した際に発生。

Reference0がカレンダー全体の情報、Reference1以降が予定1件ずつ。各Referenceの中はバイト値1（以下\[`\1`\]）で区切られている。<br />
どの予定がいくつ並ぶかは[iCal絞り込みオプション](../../sakura-script/misc/notes_executeical.md)で決まる。

- **Reference0**: カレンダー名(X-WR-CALNAME) \[`\1`\] タイムゾーン(X-WR-TIMEZONE) \[`\1`\] 暦法(CALSCALE。通常はGREGORIAN) \[`\1`\] このイベントで返した予定の件数 \[`\1`\] ファイル中の予定の総数 \[`\1`\] 絞り込み期間の開始日 \[`\1`\] 絞り込み期間の終了日<br />
  期間の開始日・終了日は「年,月,日,,,」形式。--from・--to・--expand・--limitをいずれも指定しなかった場合は空。
- **Reference1～**: UID \[`\1`\] 開始日時 \[`\1`\] 終了日時 \[`\1`\] タイトル(SUMMARY) \[`\1`\] 説明(DESCRIPTION) \[`\1`\] 場所(LOCATION) \[`\1`\] URL \[`\1`\] 状態(STATUS) \[`\1`\] 分類(CATEGORIES) \[`\1`\] 繰り返し規則(RRULEの原文) \[`\1`\] 終日フラグ \[`\1`\] 発生日<br />
  予定の数だけReference1,2,3～と続く。<br />
  開始日時・終了日時・発生日は、RSSと同じカンマ区切りの「年,月,日,時,分,秒」形式。終日予定は時・分・秒が空になり「2026,9,10,,,」のようになる。<br />
  終了日時はその予定の最終日（DTENDの日付値は排他指定なので、1日戻した値が入る）。DTENDの代わりにDURATIONで長さを書いた予定は、開始日時に長さを足した値が入る（終日予定なら同様に1日戻す）。<br />
  分類は複数ある場合カンマ区切り。分類名そのものに含まれるカンマと区切りのカンマは区別されない。<br />
  終日フラグは終日予定なら1、時刻付きなら0。<br />
  発生日は、--from・--to・--expandのいずれかを指定した場合のみ入る。--expandありなら展開した1回ぶんの発生日、--expandなしなら期間内で最初に発生する日。指定が無い場合は空。<br />
  RRULEは原文のまま渡されるので、SSPの展開を使わず自前で解釈することもできる。<br />
  タイトル・説明・場所・URL・分類・カレンダー名は、さくらスクリプトとして解釈されないようエスケープされている（\\→\\\\、%→\\%、改行とタブ→半角空白）。

**対応:** SSP 2.8.90
