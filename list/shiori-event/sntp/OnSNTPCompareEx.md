# OnSNTPCompareEx

**カテゴリ:** 時計合わせイベント

サーバに接続が確立された際に発生。修正を実行したい場合は[`\6`タグ](../../sakura-script/event/6.md)を含むスクリプトを返すこと。

- **Reference0**: 接続先サーバ名。
- **Reference1**: カンマでセパレートされたサーバ側の現時刻 : 年,月,日,時,分,秒,ミリ秒
- **Reference2**: カンマでセパレートされたローカル側の現時刻 : 年,月,日,時,分,秒,ミリ秒
- **Reference3**: サーバとローカルの時刻のずれ。秒単位かつ小数点以下あり。正の値がローカル時刻遅れ、負の値がローカル時刻進み状態。
- **Reference4**: サーバとローカルの時刻のずれ。ミリ秒単位の整数。

**対応:** SSP 2.5.66
