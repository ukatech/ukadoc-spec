# OnSNTPCorrectEx

**カテゴリ:** 時計合わせイベント

[`\6`タグで](../../sakura-script/event/6.md)ローカル時刻をサーバ時刻に修正した際に発生。

- **Reference0**: 接続先サーバ名。
- **Reference1**: カンマでセパレートされたサーバ側の現時刻 : 年,月,日,時,分,秒,ミリ秒
- **Reference2**: カンマでセパレートされたローカル側の現時刻 : 年,月,日,時,分,秒,ミリ秒
- **Reference3**: サーバとローカルの時刻のずれ。秒単位かつ小数点以下あり。正の値がローカル時刻がサーバ時刻より遅れ、負の値がローカル時刻がサーバより進んだ状態。
- **Reference4**: サーバとローカルの時刻のずれ。ミリ秒単位の整数。正負はReference3と同様。

**対応:** SSP 2.5.66
