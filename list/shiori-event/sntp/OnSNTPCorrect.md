# OnSNTPCorrect

**カテゴリ:** 時計合わせイベント

[`\6`タグで](../../sakura-script/event/6.md)ローカル時刻をサーバ時刻に修正した際に発生。

- **Reference0**: 接続先サーバ名。
- **Reference1**: カンマでセパレートされたサーバ側の現時刻 : 年,月,日,時,分,秒 (差が1秒未満はローカル時刻と同じ)
- **Reference2**: カンマでセパレートされたローカル側の現時刻 : 年,月,日,時,分,秒
- **Reference3**: サーバとローカルの時刻のずれ。秒単位の整数。正の値がローカル時刻遅れ、負の値がローカル時刻進み状態。
- **Reference4**: ※SSPのみ　サーバとローカルの時刻のずれ。ミリ秒単位の整数。

**対応:** Materia / SSP / CROW
