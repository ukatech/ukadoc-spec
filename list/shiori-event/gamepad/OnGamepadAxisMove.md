# OnGamepadAxisMove

**カテゴリ:** ゲームパッドイベント

ゲームパッドのアナログスティックやトリガーの値が前回通知時から大きく変化した場合に発生。<br />
微小な揺れではイベントは発生しない。スティック中央付近やトリガーの遊び部分（デッドゾーン）の値は自動的に0に丸められる。<br />
スティックやトリガーが中央位置（ニュートラル）に戻った場合は、変化量に関わらず必ず発生する。<br />
イベントは起動中の全ゴーストに同時にブロードキャストされる。<br />
軸イベントはスティック操作中に高頻度で発生する可能性があるため、重い処理を行う場合はゴースト側で頻度制御を検討すること。

- **Reference0**: [パッドインデックス](caption_gamepad_padindex.md)。
- **Reference1**: [軸名](caption_gamepad_axis.md)。
- **Reference2**: 生値（整数）。範囲はベースウェアの実装に依存する。
- **Reference3**: 正規化値（小数）。スティックは-1.0～1.0、トリガーは0.0～1.0の範囲。通常はこちらを使用する。

**対応:** SSP 2.7.54
