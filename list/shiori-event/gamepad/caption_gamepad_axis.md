# 軸名一覧

- **LeftStickX**: 左スティック水平（右が正、左が負）。正規化値の範囲は-1.0～1.0。
- **LeftStickY**: 左スティック垂直（上が正、下が負）。正規化値の範囲は-1.0～1.0。
- **RightStickX**: 右スティック水平（右が正、左が負）。正規化値の範囲は-1.0～1.0。
- **RightStickY**: 右スティック垂直（上が正、下が負）。正規化値の範囲は-1.0～1.0。
- **LeftTrigger**: 左トリガー（引くほど大きい）。正規化値の範囲は0.0～1.0。
- **RightTrigger**: 右トリガー（引くほど大きい）。正規化値の範囲は0.0～1.0。
