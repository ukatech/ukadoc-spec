# ボタン名一覧

- **A**: フェイスボタン下
- **B**: フェイスボタン右
- **X**: フェイスボタン左
- **Y**: フェイスボタン上
- **LB**: 左バンパー（L1相当）
- **RB**: 右バンパー（R1相当）
- **LSB**: 左スティック押込み（L3相当）
- **RSB**: 右スティック押込み（R3相当）
- **Start**: スタートボタン
- **Back**: バック / セレクトボタン
- **DPadUp**: 十字キー上
- **DPadDown**: 十字キー下
- **DPadLeft**: 十字キー左
- **DPadRight**: 十字キー右

十字キーの斜め入力は、2つのボタンイベントとして個別に発生する（例：右上ならDPadUpとDPadRight）。
