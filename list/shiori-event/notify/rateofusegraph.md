# rateofusegraph

**カテゴリ:** Notifyイベント

使ってるぞグラフの情報を通知。*\[NOTIFY\]*

- **Reference\***: バイト値1区切りにされた以下の情報。

- **1番目**: ゴースト名。
- **2番目**: sakura名。
- **3番目**: kero名。
- **4番目**: 起動回数。
- **5番目**: 起動時間。(分)
- **6番目**: 起動時間割合。(％)
- **7番目**: 状態。<br />
  boot(起動中)<br />
  install(インストールされている)<br />
  vanish(アンインストールした情報が残ってる)<br />
  のいずれか。
- **8番目**: 起動回数。(週報、今日から7日前までの集計) \[以下SSP 2.8.54～\]
- **9番目**: 起動時間。(週報、分)
- **10番目**: 起動時間割合。(週報、％)
- **11番目**: 起動回数。(月報、今日から30日前までの集計)
- **12番目**: 起動時間。(月報、分)
- **13番目**: 起動時間割合。(月報、％)

**対応:** SSP
