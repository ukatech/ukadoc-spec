# OnNotifyInternationalInfo

**カテゴリ:** Notifyイベント

タイムゾーン、ロケール(言語)名など、国際化関連の情報を通知する。*\[NOTIFY\]*

- **Reference0**: UTCからの時刻のずれ。単位は分。負の値＝早い　正の値＝遅い<br />
  たとえば、日本標準時の場合、9時間早いので、-540になる。
- **Reference1**: 夏時間が有効か否か。有効=1 無効=0
- **Reference2**: [ISO3166準拠の2文字国名](https://ja.wikipedia.org/wiki/ISO_3166-1)。
- **Reference3**: [ISO639準拠の2文字言語](https://ja.wikipedia.org/wiki/ISO_639-1%E3%82%B3%E3%83%BC%E3%83%89%E4%B8%80%E8%A6%A7)名。

**対応:** SSP
